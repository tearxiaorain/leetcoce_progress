# 48. 旋转图像

## 题目描述
> 给定一个 n x n 的二维矩阵，将其顺时针旋转 90 度。要求**原地**旋转，不能使用额外矩阵。

## 解法一: 先转置再水平翻转
### 思路
顺时针旋转 90 度 = 先转置（沿主对角线翻转）+ 再水平翻转（每行反转）。

```
原始:        转置后:       水平翻转后(结果):
1 2 3       1 4 7         7 4 1
4 5 6  →   2 5 8    →    8 5 2
7 8 9       3 6 9         9 6 3
```

转置：`swap(matrix[i][j], matrix[j][i])`，j 从 i+1 开始避免重复交换。
水平翻转：`swap(matrix[i][j], matrix[i][n-1-j])`。

### 复杂度
- 时间复杂度: O(n²)，两次遍历矩阵
- 空间复杂度: O(1)，原地操作

### 代码
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // 转置
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                swap(matrix[i][j], matrix[j][i]);
        // 水平翻转
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n / 2; j++)
                swap(matrix[i][j], matrix[i][n - 1 - j]);
    }
};
```

## 解法二: 四位置轮换法
### 思路
将矩阵分为四块，每旋转 90 度，四个对应位置的元素循环交换：

```
(i, j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i) → (i, j)
```

只需遍历矩阵的四分之一即可完成旋转。

### 复杂度
- 时间复杂度: O(n²)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n / 2; i++) {
            for (int j = 0; j < (n + 1) / 2; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[n - 1 - j][i];
                matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j];
                matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i];
                matrix[j][n - 1 - i] = temp;
            }
        }
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 思路 |
|------|------|------|------|
| 转置+翻转 | O(n²) | O(1) | 分解为两个简单操作，易理解 |
| 四位置轮换 | O(n²) | O(1) | 直接原地旋转，一步到位 |

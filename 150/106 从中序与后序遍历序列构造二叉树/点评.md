# 106. 从中序与后序遍历序列构造二叉树 — 代码点评
## 使用的方法（实际代码内容）
当前 test.cpp 与 105 题完全一致：函数签名为 `buildTree(vector<int>& preorder, vector<int>& inorder)`，实现的是「前序 + 中序」构造二叉树的递归 + 拷贝子数组写法，与本题要求的「中序 + 后序」不符。

## 复杂度分析（用户代码）
- 时间复杂度：O(n²)。沿用 105 的逻辑，每个节点线性扫描中序区间定位根 + 每层拷贝子数组，链状树最坏 O(n²)。
- 空间复杂度：O(n²)。递归栈 + 每层 4 个 vector 子数组拷贝，链状树沿递归路径总长度 O(n²)。

（注意：以上复杂度分析的是代码「实际在做什么」，并非本题的正确解法复杂度。）

## 代码评价

**致命问题**：
- 本题给定的是 `inorder` 与 `postorder`（后序遍历），但代码参数是 `preorder` 与 `inorder`，直接复用了 105 题的代码，属于复制粘贴未改。
- 对于 106 的输入，`preorder[0]`（前序首元素）并不等于树的根；后序的根是 `postorder[n-1]`（末元素）。用 `preorder[0]` 当根会导致构造结果错误，甚至下标越界/逻辑错误。
- 因此该代码**无法通过 106 题**，不能算完成本题。

**正确的改造方向**：
- 把签名改为 `buildTree(vector<int>& inorder, vector<int>& postorder)`。
- 根取 `postorder[postEnd]`（后序末元素），在中序中定位 root_index。
- 递归构造时**先右后左**：后序 `[左子树..., 右子树..., 根]`，右子树区间为 `postorder[postStart+leftSize .. postEnd-1]`，左子树为 `postorder[postStart .. postStart+leftSize-1]`。
- 同理，可用 `unordered_map<int,int>` 记录中序「值 → 下标」，改用下标区间避免拷贝，得到 O(n) 时间 / O(n) 空间的最优解。

**风格**：
- 基础编码习惯无问题，但「套用上一题的模板未核对题目输入」是本题最需要警惕的问题。

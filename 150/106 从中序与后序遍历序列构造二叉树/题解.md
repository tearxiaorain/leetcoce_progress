# 106. 从中序与后序遍历序列构造二叉树
## 题目描述
> 给定两个整数数组 inorder 和 postorder，其中 inorder 是二叉树的中序遍历，postorder 是同一棵树的后序遍历，请构造二叉树并返回其根节点。题目保证数组中没有重复元素。

## 核心思路
- **后序遍历**：`[左子树..., 右子树..., 根]`，最后一个元素一定是当前树的根节点。
- **中序遍历**：`[左子树..., 根, 右子树...]`，根节点把中序序列分成左右两部分。
- 因此：取 postorder 末元素作为根 → 在中序序列中定位该根 → 左侧是左子树的中序，右侧是右子树的中序 → 根据左右子树长度切分后序序列 → 递归构造。
- **注意**：后序序列中「根在最后」，所以递归时需**先构造右子树、再构造左子树**（因为后序从后往前读是「根 → 右 → 左」）。

## 解法一: 递归 + 哈希表（最优）
**思路**：用哈希表 `unordered_map<int,int>` 记录中序序列中「值 → 下标」的映射，从而 O(1) 定位根节点位置。

**复杂度**：
- 时间复杂度：O(n)，每个节点恰好构造一次，每次定位 O(1)。
- 空间复杂度：O(n)，哈希表占用 O(n)，递归栈深度最坏为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    unordered_map<int, int> indexMap;

    TreeNode* build(vector<int>& inorder, int inStart, int inEnd,
                    vector<int>& postorder, int postStart, int postEnd) {
        if (inStart > inEnd || postStart > postEnd) return nullptr;

        int rootVal = postorder[postEnd];
        TreeNode* root = new TreeNode(rootVal);

        int rootIdx = indexMap[rootVal];       // 根在中序中的位置
        int leftSize = rootIdx - inStart;      // 左子树节点个数

        root->left  = build(inorder, inStart, rootIdx - 1,
                            postorder, postStart, postStart + leftSize - 1);
        root->right = build(inorder, rootIdx + 1, inEnd,
                            postorder, postStart + leftSize, postEnd - 1);
        return root;
    }

    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        int n = inorder.size();
        for (int i = 0; i < n; ++i) indexMap[inorder[i]] = i;
        return build(inorder, 0, n - 1, postorder, 0, n - 1);
    }
};
```

## 解法二: 递归 + 线性查找
**思路**：不建立哈希表，每次在中序区间内线性扫描寻找根节点位置，逻辑与解法一一致。

**复杂度**：
- 时间复杂度：O(n²)，每层递归线性扫描一次中序区间，最坏情况（链状树）为 O(n²)。
- 空间复杂度：O(h)，仅递归栈，最坏 O(n)。

```cpp
class Solution {
public:
    TreeNode* build(vector<int>& inorder, int inStart, int inEnd,
                    vector<int>& postorder, int postStart, int postEnd) {
        if (inStart > inEnd) return nullptr;

        int rootVal = postorder[postEnd];
        TreeNode* root = new TreeNode(rootVal);

        int rootIdx = inStart;
        while (inorder[rootIdx] != rootVal) ++rootIdx; // 线性定位根

        int leftSize = rootIdx - inStart;
        root->left  = build(inorder, inStart, rootIdx - 1,
                            postorder, postStart, postStart + leftSize - 1);
        root->right = build(inorder, rootIdx + 1, inEnd,
                            postorder, postStart + leftSize, postEnd - 1);
        return root;
    }

    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        return build(inorder, 0, inorder.size() - 1,
                     postorder, 0, postorder.size() - 1);
    }
};
```

## 解法三: 迭代 + 栈（逆向构造）
**思路**：后序序列「从后往前」读等价于「根 → 右子树 → 左子树」的逆前序。因此可以像前序 + 中序的迭代解法一样处理，只是构造顺序变为「先右后左」。用栈维护「尚未确定左孩子的节点」，用指针 inIdx 从右向左扫描中序序列。

**复杂度**：
- 时间复杂度：O(n)，每个节点入栈出栈各一次。
- 空间复杂度：O(n)，栈最多存储 O(n) 个节点。

```cpp
class Solution {
public:
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        if (postorder.empty()) return nullptr;
        int n = postorder.size();
        TreeNode* root = new TreeNode(postorder[n - 1]);
        stack<TreeNode*> stk;
        stk.push(root);
        int inIdx = n - 1;

        for (int i = n - 2; i >= 0; --i) {
            TreeNode* node = stk.top();
            if (node->val != inorder[inIdx]) {
                node->right = new TreeNode(postorder[i]);
                stk.push(node->right);
            } else {
                while (!stk.empty() && stk.top()->val == inorder[inIdx]) {
                    node = stk.top();
                    stk.pop();
                    --inIdx;
                }
                node->left = new TreeNode(postorder[i]);
                stk.push(node->left);
            }
        }
        return root;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 + 哈希表 | O(n) | O(n) | 哈希表 O(1) 定位根，先右后左递归 |
| 递归 + 线性查找 | O(n²) | O(h) | 每次线性扫描中序区间定位根 |
| 迭代 + 栈 | O(n) | O(n) | 后序逆序变逆前序，栈模拟构造 |

> 推荐解法一（递归 + 哈希表），是标准最优解。核心易错点在于后序「根在最后」，递归构造必须先右后左，注意切分下标别算错。

# 79. 单词搜索

## 题目描述

> 给定 `m × n` 的字符网格 `board` 和一个字符串 `word`，判断 `word` 是否存在于网格中。单词必须由**相邻格子**（上下左右）的字母按顺序连接而成，且**同一个格子不能重复使用**。
> 例：`board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"` → `true`；`word = "ABCB"` → `false`。
> 数据范围：1 ≤ m, n ≤ 6，1 ≤ |word| ≤ 15。

## 解法一：DFS 回溯 + visited 访问标记

### 思路
枚举每个格子作为起点，从这个格子开始 `DFS(k)`：当前需要匹配 `word[k]`。

1. 若当前格越界、已被访问、或字符不等于 `word[k]`，剪枝返回；
2. 若 `k == word.size() - 1`，说明单词已全部匹配，返回 true；
3. 标记当前格已访问，向上下左右四个方向递归匹配 `word[k+1]`；
4. 四个方向都失败时**撤销访问标记**（回溯），换一条路继续试。

关键是第 4 步：不撤销标记的话，一条失败路径会"占用"格子，导致其他分支被误判为不可行。

### 复杂度
- 时间复杂度: O(m·n·3^L)（L = |word|；每个起点最多 4 个方向，之后每步最多 3 个方向可选）
- 空间复杂度: O(m·n)（visited 标记）+ O(L) 递归栈

### 代码
```cpp
int m, n, L;
int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};

bool dfs(vector<vector<char>>& board, vector<vector<int>>& used,
         int i, int j, int k, const string& word) {
    if (i < 0 || i >= m || j < 0 || j >= n) return false;   // 越界
    if (used[i][j] || board[i][j] != word[k]) return false; // 已用 / 字符不符
    if (k == L - 1) return true;                            // 全部匹配
    used[i][j] = 1;                                         // 占用当前格
    for (int d = 0; d < 4; d++) {
        if (dfs(board, used, i + dir[d][0], j + dir[d][1], k + 1, word))
            return true;
    }
    used[i][j] = 0;                                         // 回溯：撤销占用
    return false;
}

bool exist(vector<vector<char>>& board, string word) {
    m = board.size(); n = board[0].size(); L = word.size();
    vector<vector<int>> used(m, vector<int>(n, 0));
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (dfs(board, used, i, j, 0, word)) return true;
    return false;
}
```

## 解法二：原地修改棋盘（省掉 visited）

### 思路
`visited` 数组其实可以省掉：进入某个格子时把 `board[i][j]` 改成一个**棋盘上不可能出现的字符**（如 `'#'`），这既占用格子又表示"已访问"；回溯时再改回原来的字母。

在此基础上还可以加两个常用剪枝，让搜索树大幅变小：

- **字符计数**：先统计 `board` 与 `word` 的字符频次，若 `word` 中某个字符出现次数超过棋盘，直接返回 false；同时可以统计 `word` 的首尾字符在棋盘上的数量，把出现次数少的那个字符作为**搜索起点**（倒着搜索单词），能显著减少起始分支。
- **提前终止**：一旦某分支成功立即逐层返回 true，不再继续尝试其他方向。

### 复杂度
- 时间复杂度: O(m·n·3^L)（与解法一相同，剪枝只优化常数与剪枝率）
- 空间复杂度: O(L)（只有递归栈，棋盘被原地复用）

### 代码
```cpp
int m, n, L;
int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};

bool dfs(vector<vector<char>>& board, int i, int j, int k, const string& word) {
    if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != word[k])
        return false;
    if (k == L - 1) return true;
    char saved = board[i][j];
    board[i][j] = '#';                                     // 原地标记已访问
    for (int d = 0; d < 4; d++) {
        if (dfs(board, i + dir[d][0], j + dir[d][1], k + 1, word))
            return true;
    }
    board[i][j] = saved;                                   // 回溯还原
    return false;
}

bool exist(vector<vector<char>>& board, string word) {
    m = board.size(); n = board[0].size(); L = word.size();

    vector<int> cnt(128, 0);                               // 剪枝 1: 字符频次
    for (auto& row : board)
        for (char c : row) cnt[c]++;
    for (char c : word)
        if (--cnt[c] < 0) return false;

    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (dfs(board, i, j, 0, word)) return true;
    return false;
}
```

> 进阶：若 `word` 尾字符在棋盘上比首字符更稀有，可先 `reverse(word)` 再搜索；若首尾频次差异很大，这能把起点数量降到最低。

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| DFS + visited | O(m·n·3^L) | O(m·n) | 结构清晰，回溯语义一目了然 |
| 原地标记 + 计数剪枝 | O(m·n·3^L) | O(L) | 省掉 visited，配合频次剪枝更快 |

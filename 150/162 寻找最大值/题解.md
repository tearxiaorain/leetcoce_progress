# 162. 寻找峰值

> 说明：本目录取名为「162 寻找最大值」，对应 LeetCode 162（Find Peak Element），官方题面要求的"最大值"是**局部峰值**——返回任意一个峰值元素的下标，下文按官方题面书写。

## 题目描述

> 峰值元素指**严格大于**左右相邻元素的元素。给定整数数组 `nums`，相邻元素互不相等，返回**任意一个**峰值元素所在的下标。
> 可以假定 `nums[-1] = nums[n] = -∞`，即数组两端之外视为负无穷，所以只要某个元素大于其一侧的邻居，沿着上升方向一定能找到峰值。
> 例：`nums = [1,2,3,1]` → 返回下标 `2`（元素 3）；`nums = [1,2,1,3,5,6,4]` → 返回 `1` 或 `5`。
> 要求算法时间复杂度 O(log n)。

## 解法一：线性扫描

### 思路
从左到右扫一遍，返回第一个满足 `nums[i] > nums[i+1]` 的下标（把两端视为 -∞）。因为相邻元素互不相等，第一个"下降点"一定是峰值；若一直不下降，则最后一个元素是峰值。

这是最直观的写法，也是判断二分结果是否正确的对照实现，但复杂度是 O(n)，不满足题目要求。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
int findPeakElement(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n - 1; i++) {
        if (nums[i] > nums[i + 1]) return i;   // 第一个下降点即峰值
    }
    return n - 1;                              // 一直上升，末尾是峰值
}
```

## 解法二：二分爬坡（推荐）

### 思路
关键在于：只要比较 `nums[mid]` 与 `nums[mid+1]`，就能知道峰值在**哪一侧**。

- `nums[mid] < nums[mid+1]`：处于上升段，峰值一定在**右半区**（`mid` 右侧的某处一定存在比它高的元素，继续往右总能遇到下降点）；
- 否则 `nums[mid] > nums[mid+1]`：处于下降段，峰值一定在**左半区（含 mid）**。

于是可以二分收缩：`l = 0, r = n - 1`，每次把不含峰值的半边丢掉，直到 `l == r`，该位置就是峰值。因为两端视为 -∞，这个"半边一定含峰值"的论断始终成立，不需要额外的边界特判。

> 小技巧：`mid + 1` 最多取到 `n`，可能越界；当 `l == r` 时循环已经结束，所以让循环条件为 `while (l < r)`、`mid = l + (r - l) / 2`（向下取整）恰好保证 `mid + 1 <= r <= n - 1`，不会越界。

### 复杂度
- 时间复杂度: O(log n)
- 空间复杂度: O(1)

### 代码
```cpp
int findPeakElement(vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;             // mid + 1 <= r，不会越界
        if (nums[mid] < nums[mid + 1])
            l = mid + 1;                       // 上坡，峰值在右边
        else
            r = mid;                           // 下坡，峰值在左边(含 mid)
    }
    return l;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 线性扫描 | O(n) | O(1) | 找第一个下降点，简单但不能用 |
| 二分爬坡 | O(log n) | O(1) | 只比较 mid 与 mid+1，往"上坡"方向收缩 |

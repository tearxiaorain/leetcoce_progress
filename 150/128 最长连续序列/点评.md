# 128. 最长连续序列 — 代码点评

## 使用的方法
使用有序 map 去重并存储元素，然后遍历 map，只从序列起点（`num-1` 不在 map 中）开始 while 循环向后扩展统计连续长度。

## 复杂度分析
- 时间复杂度: O(n log n)，map 的插入和查找均为 O(log n)，遍历 n 个元素，每个元素最多参与一次扩展
- 空间复杂度: O(n)，map 存储 n 个元素

## 代码评价
- 优点: 核心算法思路正确——利用"只从序列起点扩展"来避免重复计算；用 map 实现了去重的效果。
- 可改进之处:
  1. 使用 `map`（红黑树）而非 `unordered_set`（哈希表），导致时间复杂度为 O(n log n) 而非题目要求的 O(n)。应改用 `unordered_set`。
  2. `vector<int> counts(n, 0)` 声明后从未使用，属于冗余代码。
  3. `count` 变量逻辑可简化：`count` 在 while 扩展中递增，结束时与 `max` 比较后归零，可以直接将 while 内的计数逻辑整合，避免不必要的置零操作。
  4. while(1) + if-break 模式可改为 `while (m.find(j + 1) != m.end())`，更清晰。
  5. main 函数中测试数据与最长连续序列无关，包含字母异位词等无关内容。
- 代码风格: 结构尚可，但有未使用变量和无用头文件（`<stack>`），建议清理。

## 总结
> 算法思路正确，但由于使用了有序 map 而非哈希表，时间复杂度为 O(n log n)，未满足 O(n) 要求。建议改用 `unordered_set`。

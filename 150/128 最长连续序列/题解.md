# 128. 最长连续序列

## 题目描述
> 给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求时间复杂度 O(n)。

## 解法一: 排序 + 线性扫描
### 思路
先将数组排序，然后遍历排序后的数组，统计最长的连续递增子序列长度。注意跳过重复元素。

### 复杂度
- 时间复杂度: O(n log n)，排序主导
- 空间复杂度: O(1) 或 O(log n)（取决于排序算法）

### 代码
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        if (nums.empty()) return 0;
        
        sort(nums.begin(), nums.end());
        
        int maxLen = 1;
        int curLen = 1;
        
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i - 1]) {
                // 跳过重复
                continue;
            } else if (nums[i] == nums[i - 1] + 1) {
                curLen++;
            } else {
                maxLen = max(maxLen, curLen);
                curLen = 1;
            }
        }
        
        return max(maxLen, curLen);
    }
};
```

## 解法二: 哈希集合 O(n)
### 思路
将所有数字放入哈希集合。对每个数字，仅当它是连续序列的起点（即 `num - 1` 不在集合中）时，才开始向后查找 `num + 1`, `num + 2`, ... 并统计长度。每个数字最多被访问两次（一次检查起点，一次在连续序列中），因此总时间复杂度为 O(n)。

### 复杂度
- 时间复杂度: O(n)，每个元素最多访问两次
- 空间复杂度: O(n)，哈希集合存储所有元素

### 代码
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end());
        int maxLen = 0;
        
        for (int num : st) {
            // 只从序列起点开始查找
            if (!st.count(num - 1)) {
                int cur = num;
                int curLen = 1;
                
                while (st.count(cur + 1)) {
                    cur++;
                    curLen++;
                }
                
                maxLen = max(maxLen, curLen);
            }
        }
        
        return maxLen;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n log n) | O(1) | 排序后线性扫描连续序列 |
| 解法二 | O(n) | O(n) | 哈希集合 + 只从起点扩展 |

解法二虽然额外使用 O(n) 空间，但满足了题目的 O(n) 时间要求。关键在于只从序列起点（`num-1` 不在集合中）开始扩展，避免重复计算。

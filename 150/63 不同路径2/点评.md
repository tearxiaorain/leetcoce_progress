# 63. 不同路径 II — 代码点评

## 使用的方法
**一维滚动数组 DP**。用两个 `int*` 数组 `arr`（上一行）和 `brr`（当前行），逐行滚动 + `swap` 交换指针，将空间从 O(m×n) 压缩到 O(n)。

## 复杂度分析
- 时间复杂度: **O(m×n)** — 遍历每个格子一次
- 空间复杂度: **O(n)** — 两个长度为 n 的数组

## 代码评价

### 优点
- 空间优化到位，用双数组 + swap 实现了 O(n) 空间
- 障碍物处理正确：直接置 0
- 第一行初始化逻辑清晰

### 可改进之处
1. **内存泄漏**: `new int[n]` 分配后未 `delete[]`，函数返回前应释放
2. **可用 `vector` 替代**: `vector<int> arr(n)` 更安全，无需手动管理内存
3. **初始化可简化**: 第一行 `arr[i] = brr[i] = arr[i-1]` 重复赋值，`arr` 初始化完再 copy 或直接用 vector 处理更干净
4. **`brr[0]` 更新有遗漏**: 第 30 行 `brr[0] = arr[0]` 后若 `obstacleGrid[i][0] == 1` 才置 0，但当 `arr[0]` 本身已为 0 且无障碍时，`brr[0]` 应为 0（因为第一列只能从上方来，上方若是 0 则当前也是 0）。实际上逻辑正确 — `arr[0]` 已经存储了上一行第一列的正确值

### 代码风格
- 指针命名 `arr`/`brr` 可读性一般，建议用 `prev`/`cur`
- `1 - obstacleGrid[0][0]` 写法巧妙但不够直观
- 冗余 include（stack、map、set 等）

## 总结
> 一维滚动 DP 空间优化正确，小瑕疵是内存泄漏和命名。整体逻辑没问题。

# 63. 不同路径 II

## 题目描述
> 给定一个 `m x n` 的网格，初始位于左上角，目标是右下角。每次只能向右或向下移动一步。网格中有障碍物（`1` 表示障碍，`0` 表示空）。求从左上到右下的不同路径数。

## 解法一: 动态规划（二维）

### 思路
`dp[i][j]` 表示到达 `(i, j)` 的路径数：
- 若 `grid[i][j] == 1`（障碍），`dp[i][j] = 0`
- 否则 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`
- 第一行/第一列遇到障碍前都是 1，遇到障碍后都是 0

### 复杂度
- 时间复杂度: O(m×n)
- 空间复杂度: O(m×n)

### 代码
```cpp
int uniquePathsWithObstacles(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n, 0));
    for (int i = 0; i < m && grid[i][0] == 0; i++) dp[i][0] = 1;
    for (int j = 0; j < n && grid[0][j] == 0; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (grid[i][j] == 0)
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
    return dp[m-1][n-1];
}
```

## 解法二: 动态规划（一维优化）

### 思路
`dp[j]` 表示当前行第 j 列的路径数，逐行滚动更新。遇到障碍物直接置 0。

### 复杂度
- 时间复杂度: O(m×n)
- 空间复杂度: O(n)

### 代码
```cpp
int uniquePathsWithObstacles(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<int> dp(n, 0);
    dp[0] = (grid[0][0] == 0);
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) dp[j] = 0;
            else if (j > 0) dp[j] += dp[j-1];
        }
    }
    return dp[n-1];
}
```

## 总结

| 解法 | 时间 | 空间 |
|------|------|------|
| 二维DP | O(m×n) | O(m×n) |
| 一维DP | O(m×n) | O(n) |

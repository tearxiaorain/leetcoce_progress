# 117. 填充每个节点的下一个右侧节点 II
## 题目描述
> 给定一个二叉树，其每个节点有一个 `next` 指针。填充它的每个 `next` 指针，让这个指针指向其下一个右侧节点；如果找不到下一个右侧节点，则将 `next` 指针设置为 `NULL`。初始状态下，所有 `next` 指针都被设置为 `NULL`。
>
> **注意**：本题是"二叉树"（非完美二叉树，区别于 116 题），每个节点可能没有左右孩子。

## 解法一: BFS 层序遍历（队列逐层连接）
**思路**：按层遍历，对同一层内的相邻节点建立 `next` 连接。每轮处理一层：弹出本层节点时，把当前节点的 `next` 指向队首（若还有下一个本层节点），最后层尾节点的 `next` 保持 `nullptr`。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(n)，队列最多保存最宽一层。

```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* left;
    Node* right;
    Node* next;

    Node() : val(0), left(NULL), right(NULL), next(NULL) {}
    Node(int _val) : val(_val), left(NULL), right(NULL), next(NULL) {}
    Node(int _val, Node* _left, Node* _right, Node* _next)
        : val(_val), left(_left), right(_right), next(_next) {}
};
*/
class Solution {
public:
    Node* connect(Node* root) {
        if (root == nullptr) return nullptr;
        queue<Node*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            for (int i = 0; i < sz; ++i) {
                Node* node = q.front(); q.pop();
                // 本层还有下一个节点时连接
                if (i < sz - 1) node->next = q.front();
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return root;
    }
};
```

## 解法二: 利用已有 next 指针（层链表，O(1) 额外空间）
**思路**：不借助队列。维护"上一层已连接好的链表"，用一个 `dummy` 哨兵节点串起**下一层**的节点：
- 遍历上一层链表（从 `cur` 开始），把 `cur->left`、`cur->right` 依次追加到 `dummy` 链尾（即给下一层节点建立 `next`）；
- 一层处理完后，`cur` 跳到 `dummy->next`（下一层表头），重复。

由于每层已经用 `next` 连成链表，无需队列即可定位每层所有节点。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(1)，只用常数个指针。

```cpp
class Solution {
public:
    Node* connect(Node* root) {
        Node* cur = root; // 当前层链表表头
        while (cur != nullptr) {
            Node dummy(0);      // 下一层的哨兵表头
            Node* tail = &dummy; // 下一层链尾
            // 遍历当前层链表，串起下一层
            for (Node* p = cur; p != nullptr; p = p->next) {
                if (p->left)  { tail->next = p->left;  tail = tail->next; }
                if (p->right) { tail->next = p->right; tail = tail->next; }
            }
            cur = dummy.next; // 进入下一层
        }
        return root;
    }
};
```

## 解法三: BFS 层序遍历（双端队列 / 记录 prev）
**思路**：与解法一同理，只是不依赖 `q.front()` 判断"下一个"，而是用 `prev` 指针记录上一个节点并连接。适合不熟悉 `q.front()` 提前窥视的场景。

**复杂度**：
- 时间复杂度：O(n)。
- 空间复杂度：O(n)。

```cpp
class Solution {
public:
    Node* connect(Node* root) {
        if (root == nullptr) return nullptr;
        queue<Node*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            Node* prev = nullptr;
            for (int i = 0; i < sz; ++i) {
                Node* node = q.front(); q.pop();
                if (prev) prev->next = node;
                prev = node;
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return root;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| BFS 队列 | O(n) | O(n) | 逐层连接，最直观 |
| 层链表（哨兵） | O(n) | O(1) | 利用 next 串层，空间最优 |
| BFS + prev | O(n) | O(n) | prev 记录上一节点 |

> 推荐解法二（层链表 + 哨兵），O(1) 空间是本题最亮眼的解法（进阶要求）。解法一 BFS 简单易懂，可作为首选保底写法。本题对任意二叉树成立，因此也适用于 116 完美二叉树。

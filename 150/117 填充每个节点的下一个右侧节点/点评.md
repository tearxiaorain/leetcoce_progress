# 117. 填充每个节点的下一个右侧节点 II — 代码点评
## 使用的方法
BFS 双队列（节点 + 层号）逐层连接。用 `q1` 存节点、`q2` 存对应层号，同一层内维护指针 `f` 指向"当前层最后一个非空节点"，遇到同一层后续非空节点 `t` 就执行 `f->next = t` 并推进 `f`，实现层内 next 连接。空节点也入队但跳过连接。

## 复杂度分析
- 时间复杂度：O(n)，每个节点（含空指针）入队、出队各一次，总计 O(n)。
- 空间复杂度：O(n)，两个队列保存最宽一层节点及其层号，最坏（满二叉树叶子层的空孩子）为 O(n)。

## 代码评价

**优点**：
- 思路正确，用"层号相等"判断同层，`f` 指针跳过空节点只连接非空节点，能正确处理层首为 null、层中夹 null 等任意二叉树情形。
- 空节点也入队但通过 `if(t)` 跳过连接，逻辑上覆盖了 II（非完美二叉树）的要求。

**可改进**：
- 用两个队列（`q1` 节点 + `q2` 层号）维护层信息，代码显著复杂；单队列 + `int sz = q.size()` 分层即可，省去 `q2` 和内外双层 while。
- 空指针入队（第 60-61、76-77 行未判空）带来冗余开销，应 `if (t->left) ... if (t->right) ...`。
- `f` 的判空与连接逻辑（第 81-92 行 `if(!f) f=t; else if(t) f->next=t;`）较绕，可读性一般；用"哨兵 dummy 串下一层"的标准层链表写法可做到 O(1) 空间且更清晰。
- 第 66 行 `Node *f = t;` 当层首 `t` 为空时 `f` 也为空，随后依赖 `if(!f) f=t;` 纠正，逻辑正确但可读性差。
- 缺少 `root == nullptr` 显式处理（依赖空指针入队后循环自然结束）。
- 头文件包含未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`。

**风格**：
- 符合 ACM 风格，`using namespace std;`。
- 变量名 `f`、`l`、`t` 单字母偏简，建议 `prev`、`level`、`node`。

## 总结
> AC ✓

代码正确实现了任意二叉树的 next 连接，采用"双队列 + 层号"的 BFS 思路无误，复杂度 O(n)/O(n)。主要问题是双队列和空指针入队导致的复杂度与可读性冗余，进阶可改为单队列 `q.size()` 分层，或 O(1) 空间的哨兵层链表法。

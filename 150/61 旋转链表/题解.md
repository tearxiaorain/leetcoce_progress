# 61. 旋转链表

## 题目描述

> 给定一个链表头节点 `head`，将链表**每个节点向右移动 k 个位置**（k 为非负整数），返回新链表头。
> 输入输出示意：`head = [1,2,3,4,5], k = 2` → `[4,5,1,2,3]`；`head = [0,1,2], k = 4` → `[2,0,1]`。

## 解法一: 暴力——每次右移一位

### 思路
右旋 k 次等价于把尾节点搬到头部做 k 次。循环 k 次：先走到倒数第二个节点，把尾节点摘下来插到 head 前面，同时更新 head。先做 `k %= 长度` 避免无谓循环。

数据大时每位移一次都要 O(n) 找尾，总代价 O(kn)，容易超时——仅作为最直观的暴力参照。

### 复杂度
- 时间复杂度: O(k·n)（k 为实际移动次数）
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* rotateRight(ListNode* head, int k) {
    if (!head || !head->next) return head;
    int n = 1;
    ListNode* t = head;
    while (t->next) { n++; t = t->next; }   // 求长度，t 停在尾
    k %= n;
    while (k--) {
        ListNode* pre = head;
        while (pre->next->next) pre = pre->next; // 倒数第二
        ListNode* last = pre->next;
        pre->next = nullptr;                    // 摘尾
        last->next = head;                      // 尾搬到头部
        head = last;
    }
    return head;
}
```

## 解法二: 计数 + 成环剪断（O(n)）

### 思路
右旋 k 位的结果是：新头 = 原链第 `n - k%n` 个节点（从 1 数）。利用环形一步定位断点：
1. 先数长度 `n`，并让尾节点 `tail->next = head` 成环；
2. `k %= n`；若 `k == 0` 直接返回原头；
3. 从 head 出发**走 `n - k - 1` 步**到达"新尾"（新头的前一个节点）；
4. 新尾的 `next` 即为新头，把新尾 `next` 置空剪断，返回新头。

关键点：断点步数是 `n - k - 1` 而不是 `n - k`——因为要停在**新头前面**那个节点上再剪。k 是长度的整数倍时 `k=0`，直接返回原链表即可。

### 复杂度
- 时间复杂度: O(n)（数长度 + 走断点各一遍）
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* rotateRight(ListNode* head, int k) {
    if (k == 0 || !head) return head;
    ListNode* h = head;
    int n = 0;
    if (h) n = 1; else return nullptr;
    while (h->next) { n++; h = h->next; }  // h 停在尾节点
    h->next = head;                        // 成环

    int r = k % n;
    if (r == 0) return head;               // 整数倍：不变
    r = n - r - 1;                         // 走 n-k-1 步到新尾
    h = head;
    while (r--) h = h->next;
    ListNode* res = h->next;               // 新头
    h->next = nullptr;                     // 剪断
    return res;
}
```

# 21. 合并两个有序链表

## 题目描述

> 将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

## 解法一: 迭代法（双指针）

### 思路
使用双指针同时遍历两个链表，每次比较两个指针所指节点的值，将较小的节点接入结果链表。类似归并排序的 merge 阶段。

1. 创建 dummy 头节点简化边界处理
2. 用 `cur` 指针指向当前结果链表的尾部
3. 当 `l1` 和 `l2` 都不为空时，取较小值接入，对应指针后移
4. 最后将剩余非空链表直接接上

### 复杂度
- 时间复杂度: **O(m + n)** — 遍历两个链表各一次
- 空间复杂度: **O(1)** — 只用了常量指针

### 代码
```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* cur = &dummy;
    while (l1 && l2) {
        if (l1->val < l2->val) {
            cur->next = l1;
            l1 = l1->next;
        } else {
            cur->next = l2;
            l2 = l2->next;
        }
        cur = cur->next;
    }
    cur->next = l1 ? l1 : l2;
    return dummy.next;
}
```

## 解法二: 递归法

### 思路
递归地定义合并操作：两个链表头中较小的那个节点，其 `next` 应该是剩余部分合并的结果。

1. 若 l1 为空返回 l2，若 l2 为空返回 l1
2. 若 `l1->val < l2->val`，递归合并 `l1->next` 和 `l2`，结果接到 l1 后面
3. 否则对称处理

### 复杂度
- 时间复杂度: **O(m + n)** — 每个节点访问一次
- 空间复杂度: **O(m + n)** — 递归调用栈深度

### 代码
```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    if (!l1) return l2;
    if (!l2) return l1;
    if (l1->val < l2->val) {
        l1->next = mergeTwoLists(l1->next, l2);
        return l1;
    } else {
        l2->next = mergeTwoLists(l1, l2->next);
        return l2;
    }
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 推荐 |
|------|-----------|-----------|------|
| 迭代 | O(m+n) | O(1) | ✅ 推荐（无栈溢出风险） |
| 递归 | O(m+n) | O(m+n) | 代码简洁，长链表不适用 |

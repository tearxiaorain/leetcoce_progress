# 219. 存在重复元素 II — 代码点评

## 使用的方法
用户使用**哈希表记录最近位置法**：通过 `map<int, int>` 记录每个元素最近一次出现的下标，当再次遇到相同元素时检查下标差是否在 k 以内。

## 复杂度分析
- 时间复杂度: O(n log n) —— 遍历数组 O(n)，每次 map 查找/插入操作 O(log n)
- 空间复杂度: O(n) —— map 最多存储 n 个不同元素

## 代码评价
- 优点: 逻辑正确，使用 map 记录最近位置，发现距离超过 k 时更新位置而非直接放弃，确保了后续仍能匹配；边界逻辑处理清晰
- 可改进之处: 使用 `map` 导致每次查找 O(log n)，可改用 `unordered_map` 降至 O(1)；与题目无关的 strs 数组初始化在 main 中冗余
- 代码风格: 代码结构清晰，条件分支简洁（`it == m.end()` 区分首次出现和重复），变量命名合理

## 总结
> 实现正确，更新位置的逻辑保证了跨窗口匹配的准确性，改用 unordered_map 可获得 O(n) 时间。

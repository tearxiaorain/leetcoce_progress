# 148. 排序链表

## 题目描述

> 给你链表的头结点 `head`，请将其按 **升序** 排列并返回排序后的链表。
> 要求：在 **O(n log n) 时间** 和 **O(1) 常数级空间**（除返回结果外）内完成。
> 示例：`head = [4,2,1,3]` → `[1,2,3,4]`

因为要求 `O(n log n)`，暴力 `O(n²)` 的插入排序不可用；又因是**单链表**无法下标随机访问，快排/堆也不直观，**归并排序**是标准答案。

## 解法一：自顶向下归并排序（递归）

### 思路

1. **分割**：快慢指针找到链表中点，把链表切成两半（`slow` 每次走一步、`fast` 走两步，`fast` 到尾部时 `slow` 即中点）
2. **递归**：对左右两半分别排序
3. **合并**：写一个合并两个有序链表的函数（哑结点法），把两半归并

递归版空间为 `O(log n)`（递归栈），是"能 AC、写法清晰"的版本。

### 复杂度
- 时间复杂度: O(n log n)，每层合并 O(n)，共 log n 层
- 空间复杂度: O(log n)，递归调用栈深度（非最优 O(1)，见解法二）

### 代码
```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;          // 空或单节点
        // 1. 快慢指针找中点
        ListNode *slow = head, *fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        // 2. 切断成两半
        ListNode* mid = slow->next;
        slow->next = nullptr;
        // 3. 递归排序两半后合并
        ListNode* l = sortList(head);
        ListNode* r = sortList(mid);
        return merge(l, r);
    }
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy(0), *p = &dummy;
        while (a && b) {
            if (a->val <= b->val) { p->next = a; a = a->next; }
            else                  { p->next = b; b = b->next; }
            p = p->next;
        }
        p->next = a ? a : b;
        return dummy.next;
    }
};
```

## 解法二：自底向上归并排序（迭代，O(1) 空间）

### 思路

递归版的空间开销来自调用栈，迭代版用**子链表长度倍增**消除递归，达到真正的 O(1) 空间：

1. 先求链表长度 `len`
2. 外层循环 `size` 从 1 倍增到 `len`，表示当前待合并子链的长度
3. 内层每两个相邻的、长度为 `size` 的有序子链合并成一个长度为 `2*size` 的有序子链
4. 全程只断开、重接 `next` 指针，不新建节点

需要写一个 `split(head, k)`：切出前 k 个节点返回其头，并返回剩余链头。

### 复杂度
- 时间复杂度: O(n log n)
- 空间复杂度: O(1)，仅常数个指针

### 代码
```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;
        int len = 0;
        for (ListNode* p = head; p; p = p->next) ++len;

        ListNode dummy(0); dummy.next = head;
        for (int size = 1; size < len; size <<= 1) {
            ListNode *pre = &dummy, *cur = dummy.next;
            while (cur) {
                ListNode* a = cur;                          // 第一段头
                ListNode* b = cut(a, size);                 // 切出第一段，b 指向第二段头
                cur = cut(b, size);                         // 切出第二段，cur 指向剩余部分
                pre->next = merge(a, b);                    // 合并两段，接到已排序区
                while (pre->next) pre = pre->next;          // pre 走到已排序区末尾
            }
        }
        return dummy.next;
    }
    // 切下 head 起前 k 个节点，返回剩余链头（并把该段尾部 next 置空）
    ListNode* cut(ListNode* head, int k) {
        if (!head) return nullptr;
        while (--k && head->next) head = head->next;
        ListNode* rest = head->next;
        head->next = nullptr;
        return rest;
    }
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy(0), *p = &dummy;
        while (a && b) {
            if (a->val <= b->val) { p->next = a; a = a->next; }
            else                  { p->next = b; b = b->next; }
            p = p->next;
        }
        p->next = a ? a : b;
        return dummy.next;
    }
};
```

## 总结

- 链表排序首选 **归并**：天然适配"只能顺序访问"的数据结构。
- 面试通常先写"自顶向下递归"（简单清晰），再补一句"可改为自底向上把空间压到 O(1)"以展示对空间的把控。
- 快慢指针找中点时 `fast` 从 `head->next` 出发，可保证偶数长度时切分稳定。

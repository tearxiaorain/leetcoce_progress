# 30. 串联所有单词的子串

## 题目描述

> 给定一个字符串 `s` 和一个字符串数组 `words`（其中每个单词**长度相同**）。找出 `s` 中恰好可以由 `words` 中所有单词串联形成子串的起始位置（顺序任意、每个单词用一次、串联结果内部单词不重叠）。
> 输入输出示意：`s = "barfoothefoobarman", words = ["foo","bar"]` → `[0,9]`；`s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]` → `[]`（word 需出现两次但只有一次）。记单词个数为 `m`、单词长度为 `w`。

## 解法一: 枚举起点 + 滑动窗口字典匹配

### 思路
设总长 `L = m*w`。对每个可能的起点 `start`（`0 ≤ start ≤ n - L`），从该起点开始按 `w` 切分出一系列单词，用哈希表计数比较：
1. 先用 `need` 统计 `words` 中每个单词的需求次数；
2. 每切出一个单词，若它不在 `words` 里则直接判失败，否则计数；一旦某个单词出现次数超过需求也判失败；
3. 恰好匹配满 `m` 个单词即得到一组答案。

该写法在同一个窗口上会反复重新统计，最坏 O(n·m·w)。

### 复杂度
- 时间复杂度: O(n · m · w)，每个起点都要重建计数并扫描窗口
- 空间复杂度: O(m·w)，哈希表

### 代码
```cpp
class Solution {
public:
    vector<int> findSubstring(string s, vector<string>& words) {
        vector<int> res;
        int n = s.size(), m = words.size(), w = words[0].size();
        unordered_map<string, int> need;
        for (auto& x : words) need[x]++;
        for (int st = 0; st + m * w <= n; ++st) {
            unordered_map<string, int> cur = need;   // 拷贝需求
            int ok = m;
            for (int i = st; i < st + m * w; i += w) {
                string t = s.substr(i, w);
                if (cur.count(t) && cur[t] > 0) {    // 命中且还有配额
                    cur[t]--; ok--;
                } else break;
            }
            if (ok == 0) res.push_back(st);
        }
        return res;
    }
};
```

## 解法二: 按偏移量分桶的滑动窗口（O(n·w)）

### 思路
起点真正的取值不必遍历 `n` 个：长度为 `w` 的窗口每次右移一格仍会重复切分，不如把窗口按 `w` 对齐。做法：
1. 按偏移量 `k = 0, 1, …, w-1` 分组处理，每组里以 `k` 为起点、以 `w` 为步长遍历 `s`；
2. 在每一组内维护一个**恰好 m 个单词**的滑动窗口：窗口右端加词、超长时左端丢词；用 `missing` 记录还差多少个合法单词；
3. 窗口大小恰好达到 `m*w` 且 `missing == 0` 时，左端就是答案起点。

这样每个字符至多进出一次窗口，总代价约 O(n·w)（每组扫一遍，共 w 组，但每组扫描长度约 n/w）。相比解法一省去了"每个起点重建计数"的重复劳动。

### 复杂度
- 时间复杂度: O(n·w)（每个单词仅进出一次，需按 w 分桶）
- 空间复杂度: O(m·w)，哈希表计数

### 代码
```cpp
class Solution {
public:
    vector<int> findSubstring(string s, vector<string>& words) {
        vector<int> res;
        int n = s.size(), m = words.size(), w = words[0].size();
        if (n < m * w) return res;
        unordered_map<string, int> need;
        for (auto& x : words) need[x]++;

        for (int k = 0; k < w; ++k) {                 // 按偏移量分桶
            unordered_map<string, int> cnt;           // 窗口内实际计数
            int missing = m;                          // 还差多少个合法单词
            // [l, r) 为当前覆盖的单词区间，l、r 均以 w 为步长
            for (int l = k, r = k; r + w <= n; r += w) {
                string in = s.substr(r, w);
                if (need.count(in)) {                 // 右端进窗口
                    if (cnt[in] < need[in]) missing--;
                    cnt[in]++;
                }
                // 窗口单词数超过 m 时，左端丢词
                if ((r - l) / w + 1 > m) {
                    string out = s.substr(l, w);
                    if (need.count(out)) {
                        cnt[out]--;
                        if (cnt[out] < need[out]) missing++;
                    }
                    l += w;
                }
                if ((r - l) / w + 1 == m && missing == 0)
                    res.push_back(l);
            }
        }
        return res;
    }
};
```

# 202. 快乐数

## 题目描述
> 编写一个算法来判断一个数 `n` 是不是快乐数。快乐数的定义为：对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和，然后重复这个过程直到这个数变为 1（快乐数），或者无限循环但始终变不到 1（不快乐数）。如果 `n` 是快乐数就返回 `true`，否则返回 `false`。

## 解法一: 哈希集合检测循环
### 思路
使用哈希集合记录已经出现过的数字。重复进行"各位数字平方和"的计算，如果结果为 1 则返回 true；如果结果已经出现在集合中（说明进入循环），则返回 false。
### 复杂度
- 时间复杂度: O(log n * log n) —— 每次计算平方和需要 O(log n)（数字的位数），循环次数由数学性质保证不超过一定范围（实际上最多约 243 次以内）
- 空间复杂度: O(log n) —— 哈希集合存储过程中出现的数字
### 代码
```cpp
class Solution {
public:
    int getSum(int n) {
        int sum = 0;
        while (n) {
            int digit = n % 10;
            sum += digit * digit;
            n /= 10;
        }
        return sum;
    }

    bool isHappy(int n) {
        unordered_set<int> seen;
        while (n != 1 && !seen.count(n)) {
            seen.insert(n);
            n = getSum(n);
        }
        return n == 1;
    }
};
```

## 解法二: 快慢指针法（Floyd 判圈）
### 思路
将每次计算平方和看作链表的 next 操作，问题转化为检测链表中是否有环（且环是否为 1）。使用快慢指针：慢指针每次走一步，快指针每次走两步。如果快指针到达 1 则返回 true；如果快慢指针相遇且不在 1，说明进入循环，返回 false。

### 复杂度
- 时间复杂度: O(log n) —— 与解法一相同
- 空间复杂度: O(1) —— 只使用两个指针变量
### 代码
```cpp
class Solution {
public:
    int getSum(int n) {
        int sum = 0;
        while (n) {
            int digit = n % 10;
            sum += digit * digit;
            n /= 10;
        }
        return sum;
    }

    bool isHappy(int n) {
        int slow = n, fast = getSum(n);
        while (fast != 1 && slow != fast) {
            slow = getSum(slow);
            fast = getSum(getSum(fast));
        }
        return fast == 1;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 哈希集合 | O(log n) | O(log n) | 实现简单直观 | 需要额外空间存储 |
| 快慢指针 | O(log n) | O(1) | 空间复杂度最优 | 需要理解 Floyd 判圈思想 |

# 55. 跳跃游戏

## 题目描述

> 给定一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。
> 输入输出示意：`nums = [2,3,1,1,4]` → true（先跳 1 步到下标 1，再跳 3 步到末尾）；`nums = [3,2,1,0,4]` → false（下标 3 处为 0，无法越过）。

## 解法一: 自顶向下记忆化/回溯模拟

### 思路
从位置 `0` 出发 DFS，枚举从当前位置能跳到的所有位置，看能否抵达 `n-1`。直接回溯会指数爆炸，需用 `memo[i]` 记忆"从 i 出发能否到达"，`-1/0/1` 表示未访问/不可达/可达。该写法思路直观，适合当跳棋问题的通用模板。

### 复杂度
- 时间复杂度: O(n²)，每个位置至多被访问一次，但每个位置要枚举可达区间
- 空间复杂度: O(n)，记忆化数组 + 递归栈

### 代码
```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n = nums.size();
        vector<int> memo(n, -1);
        memo[n - 1] = 1;
        return dfs(nums, 0, memo) == 1;
    }
    int dfs(vector<int>& nums, int i, vector<int>& memo) {
        if (memo[i] != -1) return memo[i];
        int far = min((int)nums.size() - 1, i + nums[i]);
        for (int j = i + 1; j <= far; ++j) {
            if (dfs(nums, j, memo) == 1) return memo[i] = 1;
        }
        return memo[i] = 0;
    }
};
```

## 解法二: 贪心维护最远可达（O(n)）

### 思路
只需要关心"我当前能覆盖到的最右下标" `far`，不需要关心具体怎么走：
1. 从 `0` 开始遍历每个位置 `i`；
2. 若 `i > far`，说明前面的格子已经够不到 `i`，提前返回 false；
3. 否则更新 `far = max(far, i + nums[i])`；一旦 `far >= n-1` 即可返回 true。

关键在"能到的最远处"，某一段区间内只要存在一个跳得够远的位置，覆盖区就整体右移。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int far = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (i > far) return false;          // 到不了 i
            far = max(far, i + nums[i]);
            if (far >= (int)nums.size() - 1) return true;
        }
        return true;
    }
};
```

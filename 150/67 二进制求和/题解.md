# 67. 二进制求和

## 题目描述

> 给定两个二进制字符串 `a` 和 `b`（只含 `'0'`、`'1'`），返回它们的和，结果同样用二进制字符串表示。
> 例：`a = "11", b = "1"` → `"100"`；`a = "1010", b = "1011"` → `"10101"`。
> 数据范围：字符串长度可达 10⁴，远超 `long long` 的表示范围，**不能转成整数再做加法**，必须按位模拟。

## 解法一：双指针从低位相加 + 反转结果

### 思路
模拟竖式加法：两个指针分别指向 `a`、`b` 的末尾（最低位），一起向左移动。每一位的和是「`a` 的当前位 + `b` 的当前位 + 进位」，结果的当前位是 `sum % 2`，新的进位是 `sum / 2`。某个串先走完时，缺失的位按 0 计算；两个串都走完且进位为 1 时，再补一个最高位的 `'1'`。

因为是从低位往高位算，结果字符是按低位在前的顺序压入的，最后需要 `reverse` 一次。

### 复杂度
- 时间复杂度: O(max(m, n))（逐位一次）
- 空间复杂度: O(max(m, n))（结果串）

### 代码
```cpp
string addBinary(string a, string b) {
    string res;
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {          // 进位也要继续处理
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        res.push_back(char('0' + (sum & 1)));    // 当前位
        carry = sum >> 1;                        // 进位
    }
    reverse(res.begin(), res.end());             // 低位在前 → 翻转
    return res;
}
```

## 解法二：复用较长字符串原地相加

### 思路
第一种写法额外开了一个结果串。其实可以**把答案写回较长的那个字符串**：参数是值传递（副本），直接 `swap` 让 `a` 保存长串、`b` 保存短串即可。

从两个串的末尾对齐向左走，逐位把 `a[i]` 更新为「当前和的最低位」，进位继续往左传。走完 `a` 之后若仍有进位，说明最高位溢出，在 `a` 的头部 `insert` 一个 `'1'`。由于 `a` 足够长，只有最高位可能溢出一次，`insert` 摊还代价很小。

### 复杂度
- 时间复杂度: O(max(m, n))（最高位 `insert` 为 O(max(m, n))，只在溢出时发生一次）
- 空间复杂度: O(1)（除返回值外不额外开数组；`swap` 交换的是两个副本的指针）

### 代码
```cpp
string addBinary(string a, string b) {
    if (a.size() < b.size()) swap(a, b);         // 保证 a 是较长串，答案写在 a 上
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    for (; i >= 0; i--, j--) {
        int sum = (a[i] - '0') + carry + (j >= 0 ? b[j] - '0' : 0);
        a[i] = char('0' + (sum & 1));
        carry = sum >> 1;
    }
    if (carry) a.insert(a.begin(), '1');         // 最高位溢出，补一位
    return a;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 双指针 + 反转 | O(max(m,n)) | O(max(m,n)) | 最直观，结果独立成串 |
| 复较长串原地相加 | O(max(m,n)) | O(1) | 省掉结果串，注意进位溢出要 `insert` |

# 190. 颠倒二进制位

## 题目描述

> 颠倒给定的 **32 位无符号整数** 的二进制位，返回颠倒后的整数。
> 例：输入 `00000010100101000001111010011100` → 输出 `00111001011110000010100101000000`。
> 提示：Java 等语言没有无符号整数类型，因此输入在 LeetCode 上以「有符号整数的二进制表示」给出，但在 C++ 中应把参数当作 `uint32_t` 处理，右移是逻辑右移。

## 解法一：逐位搬运（循环 32 次）

### 思路
结果初始为 0，循环 32 次，每次：把结果的低位腾出来（`res <<= 1`），把 `n` 的最低位（`n & 1`）放到结果的低位（`res |= n & 1`），然后 `n >>= 1` 丢掉这一位。

因为 32 位全部走一遍，最高位被搬到最低位、最低位被搬到最高位，正好完成颠倒。注意必须循环满 32 次而不能用 `while (n)`——`n` 高位是 0 时仍需把它们搬到结果低位。

### 复杂度
- 时间复杂度: O(32) = O(1)
- 空间复杂度: O(1)

### 代码
```cpp
uint32_t reverseBits(uint32_t n) {
    uint32_t res = 0;
    for (int i = 0; i < 32; i++) {
        res = (res << 1) | (n & 1);   // 结果左移后接上 n 的最低位
        n >>= 1;                      // 无符号右移，逻辑移位
    }
    return res;
}
```

## 解法二：分治位交换（掩码法）

### 思路
把"整体颠倒 32 位"拆成逐步交换：先两两相邻位互换，再 2 位为一组互换，再 4 位、8 位一组互换，最后交换高 16 位与低 16 位。每一步用掩码取出需要移动的位，左移或右移后合并：

| 步骤 | 掩码 | 操作 |
|------|------|------|
| 相邻位互换 | `0x55555555`（0101…） | `(n & m) << 1 | (n >> 1) & m` |
| 2 位组互换 | `0x33333333`（0011…） | `(n & m) << 2 | (n >> 2) & m` |
| 4 位组互换 | `0x0F0F0F0F` | `(n & m) << 4 | (n >> 4) & m` |
| 8 位组互换 | `0x00FF00FF` | `(n & m) << 8 | (n >> 8) & m` |
| 高低 16 位互换 | — | `(n << 16) | (n >> 16)` |

每步都是常数次位运算，总共 5 步，没有循环。

### 复杂度
- 时间复杂度: O(1)（固定 5 组位运算，与输入无关）
- 空间复杂度: O(1)

### 代码
```cpp
uint32_t reverseBits(uint32_t n) {
    n = ((n & 0x55555555) << 1) | ((n >> 1) & 0x55555555);   // 相邻 1 位交换
    n = ((n & 0x33333333) << 2) | ((n >> 2) & 0x33333333);   // 每 2 位一组交换
    n = ((n & 0x0F0F0F0F) << 4) | ((n >> 4) & 0x0F0F0F0F);   // 每 4 位一组交换
    n = ((n & 0x00FF00FF) << 8) | ((n >> 8) & 0x00FF00FF);   // 每 8 位一组交换
    return (n << 16) | (n >> 16);                            // 高 16 位与低 16 位交换
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 逐位搬运 | O(32) | O(1) | 最直白，必写 32 轮 |
| 分治位交换 | O(1) | O(1) | 5 步掩码运算，无循环，面试加分项 |

> 补充：若该函数被**多次调用**（例如反转 10⁵ 个数），还可以用「8 位查表」把每次调用降到 4 次查表 + 3 次移位或运算，属于工程优化。

# 28. 找出字符串中第一个匹配项的下标

## 题目描述
> 给定两个字符串 haystack 和 needle，在 haystack 中找出 needle 第一次出现的位置（下标从 0 开始）。如果 needle 不是 haystack 的一部分，返回 -1。即实现字符串匹配（strStr 函数）。

## 解法一: 暴力匹配
### 思路
从 haystack 的每个位置开始，逐个字符与 needle 比较。如果完全匹配则返回当前起始下标，否则从下一个位置重新开始。

### 复杂度
- 时间复杂度: O(m * n)，其中 m = haystack.size(), n = needle.size()。最坏情况每次都需要比较到最后一个字符才发现不匹配。
- 空间复杂度: O(1)。

### 代码
```cpp
#include <iostream>
#include <string>
using namespace std;

int strStr(string haystack, string needle) {
    int m = haystack.size(), n = needle.size();
    if (n == 0) return 0;
    
    for (int i = 0; i <= m - n; i++) {
        int j = 0;
        while (j < n && haystack[i + j] == needle[j]) {
            j++;
        }
        if (j == n) return i;
    }
    return -1;
}
```

## 解法二: KMP 算法
### 思路
KMP 算法的核心是利用部分匹配表（next 数组 / prefix table）避免暴力法中的回退。先预处理 needle，计算 next 数组（记录 needle 每个位置的最长相等的真前缀和真后缀的长度），然后在主串上滑动匹配，利用 next 数组实现失配后的快速跳转。

### 复杂度
- 时间复杂度: O(m + n)，m 为 haystack 长度，n 为 needle 长度。构建 next 数组 O(n)，匹配过程 O(m)。
- 空间复杂度: O(n)，next 数组。

### 代码
```cpp
int strStr(string haystack, string needle) {
    int n = needle.size();
    if (n == 0) return 0;
    
    // 构建 next 数组
    vector<int> next(n, 0);
    for (int i = 1, j = 0; i < n; i++) {
        while (j > 0 && needle[i] != needle[j]) {
            j = next[j - 1];
        }
        if (needle[i] == needle[j]) {
            j++;
        }
        next[i] = j;
    }
    
    // KMP 匹配过程
    int m = haystack.size();
    for (int i = 0, j = 0; i < m; i++) {
        while (j > 0 && haystack[i] != needle[j]) {
            j = next[j - 1];
        }
        if (haystack[i] == needle[j]) {
            j++;
        }
        if (j == n) {
            return i - n + 1;
        }
    }
    return -1;
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 暴力匹配 | O(m * n) | O(1) | 简单直接，适合小规模 |
| KMP 算法 | O(m + n) | O(n) | 线性时间，面试重点 |

# 112. 路径总和
## 题目描述
> 给你二叉树的根节点 `root` 和一个表示目标和的整数 `targetSum`。判断该树中是否存在一条「根节点到叶子节点」的路径，这条路径上所有节点值相加等于目标和 `targetSum`。叶子节点是指没有子节点的节点。

## 解法一: 递归（DFS 减法思想）
**思路**：从根节点开始，每次用 `targetSum - node->val` 得到剩余需要凑出的和，向下递归。当走到叶子节点时，判断剩余和是否恰好为 0。递归出口：
- 当前节点为空 → 返回 false；
- 当前是叶子节点 → 判断 `node->val == targetSum`（即剩余和减到 0）；
- 否则递归检查左子树或右子树是否存在满足剩余和的路径。

**复杂度**：
- 时间复杂度：O(n)，最坏情况需要遍历所有节点。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) return false;
        // 到达叶子节点，判断剩余和是否为 0
        if (root->left == nullptr && root->right == nullptr) {
            return root->val == targetSum;
        }
        int remain = targetSum - root->val;
        return hasPathSum(root->left, remain) || hasPathSum(root->right, remain);
    }
};
```

## 解法二: 迭代（栈 DFS，携带剩余和）
**思路**：用栈模拟递归，栈中同时保存「节点指针」和「到达该节点的剩余和」。每次弹出后：
- 若是叶子且剩余和等于节点值 → 返回 true；
- 否则把左右子节点（携带更新后的剩余和）压栈。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，最坏情况栈中同时保存较多节点（或 O(h) 若按深度优先分析栈深）。

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) return false;
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, targetSum});
        while (!stk.empty()) {
            auto [node, remain] = stk.top(); stk.pop();
            if (node->left == nullptr && node->right == nullptr) {
                if (node->val == remain) return true;
            }
            if (node->right != nullptr)
                stk.push({node->right, remain - node->val});
            if (node->left != nullptr)
                stk.push({node->left, remain - node->val});
        }
        return false;
    }
};
```

## 解法三: 迭代（队列 BFS，携带剩余和）
**思路**：与解法二思路一致，改用队列进行广度优先遍历。队列元素为「节点 + 剩余和」，逐层判断。BFS 对于"找到即返回"的路径类问题同样有效。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列中最多保存一层的节点数。

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) return false;
        queue<pair<TreeNode*, int>> q;
        q.push({root, targetSum});
        while (!q.empty()) {
            auto [node, remain] = q.front(); q.pop();
            if (node->left == nullptr && node->right == nullptr) {
                if (node->val == remain) return true;
            }
            if (node->left != nullptr)
                q.push({node->left, remain - node->val});
            if (node->right != nullptr)
                q.push({node->right, remain - node->val});
        }
        return false;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 DFS | O(n) | O(h) | 减法思想，叶子处判 0 |
| 迭代 DFS | O(n) | O(n) | 栈携带剩余和 |
| 迭代 BFS | O(n) | O(n) | 队列携带剩余和 |

> 推荐解法一（递归），代码最简洁，是路径和类问题的标准模板。若担心深树爆栈，可改用解法二的迭代 DFS。

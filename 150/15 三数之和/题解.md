# 15. 三数之和

## 题目描述

> 给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。
> 注意：答案中不可以包含重复的三元组。

## 解法一: 排序 + 双指针

### 思路
1. 先将数组排序，方便去重和双指针移动
2. 固定第一个数 `nums[i]`，然后在 `[i+1, n-1]` 范围内使用双指针 `left` 和 `right` 寻找两数之和等于 `-nums[i]` 的组合
3. 核心去重策略：
   - 固定第一个数时，跳过与上一个相同的 `nums[i]`
   - 找到一组解后，同时跳过左侧重复值和右侧重复值
4. 双指针移动规则：若三数之和 < 0，`left++`；若 > 0，`right--`；若 == 0，记录结果并同时移动 `left` 和 `right`

### 复杂度
- 时间复杂度: **O(n²)** —— 排序 O(n log n)，外层循环 O(n)，内层双指针 O(n)，总 O(n²)
- 空间复杂度: **O(1)** —— 排序栈空间 O(log n)，不计入返回结果

### 代码
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        int n = nums.size();
        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 2; i++) {
            // 跳过重复的第一个数
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            // 剪枝：最小的三个数之和都大于0，后面不可能再有解
            if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
            // 剪枝：当前数与最大的两个数之和小于0，跳过当前i
            if (nums[i] + nums[n - 1] + nums[n - 2] < 0) continue;

            int left = i + 1, right = n - 1;
            int target = -nums[i];

            while (left < right) {
                int sum = nums[left] + nums[right];
                if (sum < target) {
                    left++;
                } else if (sum > target) {
                    right--;
                } else {
                    res.push_back({nums[i], nums[left], nums[right]});
                    // 跳过左侧重复值
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    // 跳过右侧重复值
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++;
                    right--;
                }
            }
        }
        return res;
    }
};
```

## 解法二: 排序 + 哈希表

### 思路
1. 同样先排序，固定第一个数 `nums[i]`
2. 在剩余范围内，将两数之和问题转化为哈希表查找：遍历 `[i+1, n-1]`，用 `unordered_set` 记录已访问元素，检查 `-nums[i] - nums[j]` 是否在 set 中
3. 需要额外去重：用 `set<vector<int>>` 存储结果，或用跳过策略

### 复杂度
- 时间复杂度: **O(n²)** —— 排序 O(n log n)，双层遍历 O(n²)，哈希查找 O(1)
- 空间复杂度: **O(n)** —— 哈希集合存储元素

### 代码
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        set<vector<int>> uniqueRes;
        int n = nums.size();
        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            unordered_set<int> seen;
            int target = -nums[i];
            for (int j = i + 1; j < n; j++) {
                int complement = target - nums[j];
                if (seen.count(complement)) {
                    uniqueRes.insert({nums[i], complement, nums[j]});
                }
                seen.insert(nums[j]);
            }
        }
        return vector<vector<int>>(uniqueRes.begin(), uniqueRes.end());
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 排序 + 双指针 | O(n²) | O(1) | 空间最优，去重逻辑内置于指针移动 | 需要理解双指针剪枝 |
| 排序 + 哈希表 | O(n²) | O(n) | 思路直观（两数之和扩展） | 需要额外 set 去重，常数较大 |

双指针法是本题的最优解，时间复杂度 O(n²) 已是理论下界（必须枚举所有可能的三元组），而空间复杂度仅 O(1)。

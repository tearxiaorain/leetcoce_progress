# 209. 长度最小的子数组

## 题目描述

> 给定一个含有 `n` 个正整数的数组和一个正整数 `target`。找出该数组中满足其和 **≥ target** 的长度最小的 **连续子数组**，并返回其长度；如果不存在符合条件的子数组，返回 `0`。
> 输入输出示意：`target = 7, nums = [2,3,1,2,4,3]` → 2（子数组 `[4,3]`）；`target = 4, nums = [1,4,4]` → 1。所有元素为正整数，这保证了滑动窗口的正确性。

## 解法一: 暴力前缀和（或双重循环）

### 思路
用前缀和数组 `pre`，`pre[i]` 表示 `nums[0..i-1]` 的和，则 `nums[i..j]` 的和 = `pre[j+1] - pre[i]`。枚举所有 `i < j` 的子数组，找和 ≥ target 的最短长度。也可不要前缀和，直接双重循环累加。

### 复杂度
- 时间复杂度: O(n²)，枚举所有区间
- 空间复杂度: O(n)，前缀和数组（直接双重循环则 O(1)）

### 代码
```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size(), ans = INT_MAX;
        vector<int> pre(n + 1, 0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + nums[i];
        for (int i = 0; i < n; ++i)
            for (int j = i; j < n; ++j)
                if (pre[j + 1] - pre[i] >= target)
                    ans = min(ans, j - i + 1);
        return ans == INT_MAX ? 0 : ans;
    }
};
```

## 解法二: 双指针滑动窗口（O(n)）

### 思路
窗口 `[l, r]` 维护一个"和 ≥ target 时尽量短"的子数组：
1. 右指针 `r` 不断扩展，把 `nums[r]` 加入窗口和；
2. 当窗口和 ≥ target 时，窗口已经满足条件，更新 `ans`，然后**左指针右移缩小窗口**（减去 `nums[l]`）——由于数组全正，缩小后和变小，可能再次不满足，因此用 `while` 持续收缩到刚好不满足为止，收缩过程中每次都更新答案。
3. 右指针到头即结束。

每个元素最多被左右指针各经过一次，所以是线性。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int l = 0, sum = 0, ans = INT_MAX;
        for (int r = 0; r < (int)nums.size(); ++r) {
            sum += nums[r];                      // 扩展右端
            while (sum >= target) {              // 满足条件就收缩，找更短
                ans = min(ans, r - l + 1);
                sum -= nums[l];
                ++l;
            }
        }
        return ans == INT_MAX ? 0 : ans;
    }
};
```

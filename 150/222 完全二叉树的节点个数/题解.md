# 222. 完全二叉树的节点个数

## 题目描述

> 给定一棵**完全二叉树**的根节点 `root`，求出该树的节点个数。
> 完全二叉树的定义：除最底层外，其余各层都是满的，且最底层的节点全部**集中在左侧**。
> 例：`root = [1,2,3,4,5,6]` → `6`；`root = []` → `0`；`root = [1]` → `1`。
> 进阶要求：遍历整棵树需要 O(n)，能否设计出**优于 O(n)**（如 O(log²n)）的算法？

## 解法一：任意遍历（DFS / BFS 数节点）

### 思路
完全不利用"完全二叉树"这个条件，把每个节点数一遍即可：递归地返回 `1 + 左子树节点数 + 右子树节点数`。（换成 BFS 一层层数也一样。）

写法最简单，但必须访问所有节点，O(n)。在完全二叉树中 n 可达 5×10⁴，能过，但拿不到"优于 O(n)"的加分。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(h)（递归栈；BFS 写法则是 O(n) 队列）

### 代码
```cpp
int countNodes(TreeNode* root) {
    if (!root) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}
```

## 解法二：利用完全二叉树性质，每次砍掉一棵满子树（推荐）

### 思路
完全二叉树有一点非常关键：**任意节点的左右子树中，至少有一棵是满二叉树**。于是可以用"高度比较"来决定砍哪边：

- 沿**最左链**分别求左、右子树的高度（完全二叉树的左子树一定也是完全二叉树，右子树也是）；
- 若 `leftHeight == rightHeight`：说明左子树是一棵**满**二叉树（高度为 `leftHeight`），节点数 `2^leftHeight - 1`，加上根节点正好 `2^leftHeight`，答案 = `2^leftHeight + 递归右子树`；
- 否则（`leftHeight > rightHeight`）：说明右子树是满的，答案 = `2^rightHeight + 递归左子树`。

每层递归只往一侧走，深度 O(log n)；每层还要 O(log n) 数高度，因此总共 O(log²n)。这就是题目进阶要求的做法。

### 复杂度
- 时间复杂度: O(log²n)（递归深度 O(log n) × 每层求高度 O(log n)）
- 空间复杂度: O(log n)（递归栈）

### 代码
```cpp
int leftHeight(TreeNode* node) {          // 完全二叉树：沿最左链走到底即高度
    int h = 0;
    while (node) { h++; node = node->left; }
    return h;
}

int countNodes(TreeNode* root) {
    if (!root) return 0;
    int lh = leftHeight(root->left);
    int rh = leftHeight(root->right);
    if (lh == rh)
        // 左子树是满的：节点数 2^lh - 1，加上根本身 → 2^lh，再递归右子树
        return (1 << lh) + countNodes(root->right);
    else
        // 左子树比右子树高 1，说明右子树是满的（高度 rh）
        return (1 << rh) + countNodes(root->left);
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 朴素遍历 | O(n) | O(h) | 不利用完全二叉树性质，最容易写 |
| 高度比较 + 砍满子树 | O(log²n) | O(log n) | 进阶要求的解法，每层递归只往一侧走 |

> 另一种同量级思路：先数出总高度 `h`，再在最后一行上二分"第几个位置存在节点"，用二进制位从根走一遍判断该位置是否为空，同样是 O(log²n)。三种写法都可以，解法二代码最短。

# 57. 插入区间

## 题目描述
> 给定一个无重叠的、按区间起始端点排序的区间列表，插入一个新区间并合并可能的重叠，返回结果列表。

## 解法一: 三段扫描法
### 思路
由于原区间列表已排序且无重叠，可以分成三个阶段处理：
1. **左边不重叠部分**: 所有 `end < new_start` 的区间直接加入结果
2. **中间重叠部分**: 所有与新区间重叠的区间合并为一个 `[min_start, max_end]`，加入结果
3. **右边不重叠部分**: 所有 `start > new_end` 的区间直接加入结果

**图解：**
```
原区间: [1,2] [3,5] [6,7] [8,10] [12,16]
新区间: [4,8]

阶段1: [1,2]  (2 < 4, 不重叠)
阶段2: [3,5] [6,7] [8,10] 与 [4,8] 重叠 → 合并为 [3,10]
阶段3: [12,16] (12 > 8, 不重叠)

结果: [1,2] [3,10] [12,16]
```

### 复杂度
- 时间复杂度: O(n)，单次遍历
- 空间复杂度: O(1)，不计输出

### 代码
```cpp
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, 
                                vector<int>& newInterval) {
        vector<vector<int>> ans;
        int n = intervals.size(), i = 0;
        // 阶段1: 左边不重叠
        while (i < n && intervals[i][1] < newInterval[0]) {
            ans.push_back(intervals[i]);
            i++;
        }
        // 阶段2: 合并重叠区间
        int L = newInterval[0], R = newInterval[1];
        while (i < n && intervals[i][0] <= R) {
            L = min(L, intervals[i][0]);
            R = max(R, intervals[i][1]);
            i++;
        }
        ans.push_back({L, R});
        // 阶段3: 右边不重叠
        while (i < n) {
            ans.push_back(intervals[i]);
            i++;
        }
        return ans;
    }
};
```

## 解法二: 直接插入 + 调用 56 题合并
### 思路
将新区间插入原列表末尾，然后直接调用"合并区间"（题 56）的排序+合并算法。虽然正确，但未利用"原区间已排序无重叠"的性质。

### 复杂度
- 时间复杂度: O(n log n)，排序开销
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, 
                                vector<int>& newInterval) {
        intervals.push_back(newInterval);
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> ans;
        for (auto& inv : intervals) {
            if (ans.empty() || ans.back()[1] < inv[0])
                ans.push_back(inv);
            else
                ans.back()[1] = max(ans.back()[1], inv[1]);
        }
        return ans;
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 三段扫描法 | O(n) | O(1) | 利用已排序性质，最优 | 需处理三段边界 |
| 插入+合并 | O(n log n) | O(1) | 代码复用 | 未利用有序性，多了排序 |

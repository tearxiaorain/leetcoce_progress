# 42. 接雨水

## 题目描述
> 给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 解法一: 按列求 — 暴力法
### 思路
对于每一列 i（不包括最左和最右），它能接的雨水量取决于它左右两边最高柱子的较小值减去自身高度：

```
water[i] = max(0, min(left_max[i], right_max[i]) - height[i])
```

遍历每个位置 i，分别向左和向右扫描找出最大值。

**图解：**
```
height:  [0,1,0,2,1,0,1,3,2,1,2,1]
对于 i=2, h=0: left_max=1, right_max=3 → min=1 → water=1
对于 i=5, h=0: left_max=2, right_max=3 → min=2 → water=2
```

### 复杂度
- 时间复杂度: O(n²)，每个位置都要扫描左右
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        int ans = 0;
        for (int i = 1; i < n - 1; i++) {
            int left_max = 0, right_max = 0;
            for (int j = 0; j <= i; j++)
                left_max = max(left_max, height[j]);
            for (int j = i; j < n; j++)
                right_max = max(right_max, height[j]);
            ans += min(left_max, right_max) - height[i];
        }
        return ans;
    }
};
```

## 解法二: 动态规划 — 前缀/后缀最大值
### 思路
暴力法中每个位置都要重新扫描左右最大值，可以用两个数组提前计算：
- `left_max[i]`: 从左到右，height[0..i] 的最大值
- `right_max[i]`: 从右到左，height[i..n-1] 的最大值

然后一次遍历求每个位置的水量。

### 复杂度
- 时间复杂度: O(n)，三次遍历
- 空间复杂度: O(n)，两个辅助数组

### 代码
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n == 0) return 0;
        vector<int> left_max(n), right_max(n);
        left_max[0] = height[0];
        for (int i = 1; i < n; i++)
            left_max[i] = max(left_max[i-1], height[i]);
        right_max[n-1] = height[n-1];
        for (int i = n - 2; i >= 0; i--)
            right_max[i] = max(right_max[i+1], height[i]);
        int ans = 0;
        for (int i = 0; i < n; i++)
            ans += min(left_max[i], right_max[i]) - height[i];
        return ans;
    }
};
```

## 解法三: 双指针（最优解）
### 思路
用双指针从两端向中间收缩，只需 O(1) 额外空间。维护 `left_max` 和 `right_max`：

- 当 `height[left] < height[right]` 时，`left_max` 一定小于 `right_max`（因为 `right_max >= height[right] > height[left]`），此时左指针处的水量 = `left_max - height[left]`
- 否则右指针处的水量 = `right_max - height[right]`

**图解：**
```
初始: left=1, right=10
height: [0,1,0,2,1,0,1,3,2,1,2,1]
         L                   R

left_max=0, right_max=1
height[L]=1 >= height[R]=1 → 处理右侧: right_max - height[R] = 1-1 = 0, right--, right_max=max(1,2)=2

继续推进直到 left 和 right 相遇。
每一步都只处理较矮的一侧，因为矮侧决定了水位上限。
```

### 复杂度
- 时间复杂度: O(n)，一次遍历
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        int left = 0, right = n - 1;
        int left_max = 0, right_max = 0;
        int ans = 0;
        while (left < right) {
            left_max = max(left_max, height[left]);
            right_max = max(right_max, height[right]);
            if (height[left] < height[right]) {
                ans += left_max - height[left];
                left++;
            } else {
                ans += right_max - height[right];
                right--;
            }
        }
        return ans;
    }
};
```

## 解法四: 单调栈
### 思路
维护一个单调递减栈（存下标）。当遇到一个更高的柱子时，它和栈顶之间形成一个"凹槽"：

1. 当前高度 > 栈顶高度时，弹出栈顶作为"坑底"
2. 新的栈顶作为"左墙"，当前柱子作为"右墙"
3. 水量 = (min(左墙, 右墙) - 坑底) * 宽度

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)

### 代码
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        stack<int> st;
        int ans = 0;
        for (int i = 0; i < height.size(); i++) {
            while (!st.empty() && height[i] > height[st.top()]) {
                int bottom = height[st.top()];
                st.pop();
                if (st.empty()) break;
                int left = st.top();
                int w = i - left - 1;
                int h = min(height[left], height[i]) - bottom;
                ans += w * h;
            }
            st.push(i);
        }
        return ans;
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 核心思想 |
|------|------|------|---------|
| 暴力法 | O(n²) | O(1) | 每个位置向两侧扫描最大值 |
| 动态规划 | O(n) | O(n) | 前缀/后缀数组预计算 |
| 双指针 | O(n) | O(1) | 从两端向中间收缩，维护左右最大值 |
| 单调栈 | O(n) | O(n) | 横向分层计算，按凹槽累加水 |

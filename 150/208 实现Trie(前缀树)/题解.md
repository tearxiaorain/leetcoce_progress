# 208. 实现 Trie（前缀树）

## 题目描述

> 实现一个 Trie（前缀树），包含 `insert(word)`、`search(word)`、`startsWith(prefix)` 三个操作。`search` 要求完整匹配一个已插入的单词；`startsWith` 只要存在以 `prefix` 为前缀的单词即返回 true。所有字符为小写英文字母。
> 输入输出示意：`["Trie","insert","search","search","startsWith","insert","search"]`，插入 "apple" 后 `search("apple")=true`、`search("app")=false`、`startsWith("app")=true`。

## 解法一: 数组子节点 Trie（标准实现）

### 思路
每个节点持有一个长度为 26 的子节点指针数组 `next[26]`（按字符 `c` 定位 `next[c-'a']`）和一个结束标记 `isEnd`。
- `insert`：从根沿 word 逐字符走，子节点不存在就新建，最后把末尾节点 `isEnd = true`；
- `search`：逐字符沿 next 走，中途断链返回 false，走完后还要检查末节点 `isEnd`；
- `startsWith`：与 search 相同但**不检查** `isEnd`，只要中途不断链即可。
数组定长 26、下标即字符映射，访问是严格的 O(1)，是 Trie 最常用写法。节点总量 ≤ 所有插入单词的字符总数（前缀共享）。

### 复杂度
- 时间复杂度: 三个操作均为 O(len(word))，与已插入单词数无关
- 空间复杂度: O(总字符数 × 26)（每个节点最多 26 个指针，最坏情形；实际通常远小于 26×N，因大量子树为空）

### 代码
```cpp
class Trie {
    struct Node {
        Node* next[26] = {};
        bool isEnd = false;
    };
    Node* root;
    Node* find(const string& s) {          // 沿 s 走，返回走完时的节点，断链返回 nullptr
        Node* p = root;
        for (char c : s) {
            if (!p->next[c - 'a']) return nullptr;
            p = p->next[c - 'a'];
        }
        return p;
    }
public:
    Trie() { root = new Node(); }
    void insert(string word) {
        Node* p = root;
        for (char c : word) {
            int i = c - 'a';
            if (!p->next[i]) p->next[i] = new Node();
            p = p->next[i];
        }
        p->isEnd = true;
    }
    bool search(string word) {
        Node* p = find(word);
        return p && p->isEnd;
    }
    bool startsWith(string prefix) {
        return find(prefix) != nullptr;
    }
};
```

## 解法二: 哈希表子节点 Trie（省内存）

### 思路
把定长数组换成 `unordered_map<char, Node*>` 子节点表，只对实际存在的分支分配。对字符集小、前缀稀疏的场景更省内存；代价是每次查子节点由 O(1) 数组下标变成哈希查询（平均仍 O(1)，常数更大）。适合需要动态字符集或超大字集的场景。

### 复杂度
- 时间复杂度: 三个操作均为 O(len(word))（哈希平均 O(1)/字符）
- 空间复杂度: O(总字符数)（只为真实分支建节点，省去空数组槽位）

### 代码
```cpp
class Trie {
    struct Node {
        unordered_map<char, Node*> next;
        bool isEnd = false;
    };
    Node* root;
public:
    Trie() { root = new Node(); }
    void insert(string word) {
        Node* p = root;
        for (char c : word) {
            if (!p->next.count(c)) p->next[c] = new Node();
            p = p->next[c];
        }
        p->isEnd = true;
    }
    bool search(string word) {
        Node* p = root;
        for (char c : word) {
            if (!p->next.count(c)) return false;
            p = p->next[c];
        }
        return p->isEnd;
    }
    bool startsWith(string prefix) {
        Node* p = root;
        for (char c : prefix) {
            if (!p->next.count(c)) return false;
            p = p->next[c];
        }
        return true;
    }
};
```

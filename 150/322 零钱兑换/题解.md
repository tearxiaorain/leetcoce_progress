# 322. 零钱兑换
## 题目描述
> 给你一个整数数组 coins，表示不同面额的硬币；以及一个整数 amount，表示总金额。计算并返回可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1。你可以认为每种硬币的数量是无限的。

## 解法一: 暴力回溯
**思路**：从金额 amount 开始，每次尝试减去一枚硬币的面额，递归求解剩余金额所需的最少硬币数。在所有可行方案中取最小值。

**复杂度**：
- 时间复杂度：O(k^n)，其中 k 是硬币种类数，最坏情况每次有 k 种选择，递归深度可达 n（amount）。
- 空间复杂度：O(n)，递归栈深度。

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        if (amount == 0) return 0;
        int ans = dfs(coins, amount);
        return ans == INT_MAX ? -1 : ans;
    }
    
    int dfs(vector<int>& coins, int remain) {
        if (remain < 0) return INT_MAX;
        if (remain == 0) return 0;
        int minCoins = INT_MAX;
        for (int coin : coins) {
            int res = dfs(coins, remain - coin);
            if (res != INT_MAX) {
                minCoins = min(minCoins, res + 1);
            }
        }
        return minCoins;
    }
};
```

## 解法二: 记忆化搜索
**思路**：用 memo 数组记录每个剩余金额所需的最少硬币数，避免重复计算相同的子问题。

**复杂度**：
- 时间复杂度：O(n * k)，每个金额计算一次，每次尝试 k 种硬币。
- 空间复杂度：O(n)，memo 数组 + 递归栈。

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> memo(amount + 1, -2); // -2 表示未计算
        memo[0] = 0;
        int ans = dfs(coins, amount, memo);
        return ans == INT_MAX ? -1 : ans;
    }
    
    int dfs(vector<int>& coins, int remain, vector<int>& memo) {
        if (remain < 0) return INT_MAX;
        if (memo[remain] != -2) return memo[remain];
        int minCoins = INT_MAX;
        for (int coin : coins) {
            int res = dfs(coins, remain - coin, memo);
            if (res != INT_MAX) {
                minCoins = min(minCoins, res + 1);
            }
        }
        memo[remain] = minCoins;
        return minCoins;
    }
};
```

## 解法三: 动态规划（完全背包）
**状态定义**：`dp[i]` 表示凑出金额 i 所需的最少硬币数。

**转移方程**：
> `dp[i] = min(dp[i], dp[i - coin] + 1)`  （对所有 `coin in coins` 且 `i >= coin`）

解释：凑出金额 i，可以看作先用最少的硬币凑出 `i - coin`，再加一枚面额为 coin 的硬币。

**初始化**：`dp[0] = 0`（金额 0 需要 0 枚硬币），其余 `dp[i] = amount + 1`（一个不可能的大数，表示尚未凑出）。

**复杂度**：
- 时间复杂度：O(n * k)，其中 n = amount，k 为硬币种类数。
- 空间复杂度：O(n)，dp 数组。

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, amount + 1);
        dp[0] = 0;
        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (i >= coin) {
                    dp[i] = min(dp[i], dp[i - coin] + 1);
                }
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
};
```

## 解法四: BFS（最短路径视角）
**思路**：将问题建模为无权图的最短路径：节点为金额 0 ~ amount，若金额 u 可以通过加一枚硬币变为金额 v，则存在边 u -> v。BFS 从 0 出发，首次到达 amount 的层数即最少硬币数。

**复杂度**：
- 时间复杂度：O(n * k)，最坏情况下每个节点访问一次。
- 空间复杂度：O(n)，队列和 visited 数组。

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        if (amount == 0) return 0;
        vector<bool> visited(amount + 1, false);
        queue<int> q;
        q.push(0);
        visited[0] = true;
        int steps = 0;
        while (!q.empty()) {
            int size = q.size();
            steps++;
            for (int i = 0; i < size; i++) {
                int cur = q.front(); q.pop();
                for (int coin : coins) {
                    long long next = (long long)cur + coin;
                    if (next == amount) return steps;
                    if (next < amount && !visited[next]) {
                        visited[next] = true;
                        q.push((int)next);
                    }
                }
            }
        }
        return -1;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 暴力回溯 | O(k^n) | O(n) | 指数级枚举每种硬币选择 |
| 记忆化搜索 | O(n * k) | O(n) | 自顶向下 + memo 缓存 |
| 动态规划 | O(n * k) | O(n) | 自底向上，完全背包模型 |
| BFS | O(n * k) | O(n) | 最短路径视角，层序遍历 |

> 零钱兑换是经典的"完全背包"型 DP 问题（每种物品无限取用）。dp[i] 定义为凑出金额 i 的最小硬币数，转移时遍历每种硬币即可。面试中 DP 解法是首选，但 BFS 视角也能展示对问题本质的深刻理解。

# 274. H 指数

## 题目描述

> 给你一个整数数组 `citations`，其中 `citations[i]` 表示研究者的第 `i` 篇论文被引用的次数。计算并返回该研究者的 **h 指数**。
> h 指数的定义：一名科研人员的 h 指数是指他（她）至少发表了 `h` 篇论文，并且**至少有 h 篇**论文的被引用次数 **≥ h**。
> 输入输出示意：`citations = [3,0,6,1,5]` → 3（有 3 篇论文引用数 ≥ 3）；`citations = [1,3,1]` → 1。

## 解法一: 排序 + 一次扫描

### 思路
将引用次数**降序**排序。h 指数的本质：排在前 `h` 篇的引用都 ≥ h，而第 `h+1` 篇（若有）引用 < h。降序后从左往右扫，统计"当前是第几篇"（即从 1 开始计数），只要 `citations[i] > i`（前 `i+1` 篇都至少被引 `i+1` 次……用 `citations[i] >= cnt` 判断），就更新答案为 `i+1`。更严谨的写法：升序后从大到小找第一个满足 `citations[n-h] >= h` 的 h。

### 复杂度
- 时间复杂度: O(n log n)，排序主导
- 空间复杂度: O(log n)（排序栈开销；可视为 O(1) 原地）

### 代码
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        sort(citations.rbegin(), citations.rend());   // 降序
        int h = 0;
        for (int i = 0; i < (int)citations.size(); ++i) {
            if (citations[i] >= i + 1) h = i + 1;     // 前 i+1 篇都被引 ≥ i+1
            else break;
        }
        return h;
    }
};
```

## 解法二: 计数数组（桶，O(n)）

### 思路
引用次数上界大但论文数有限，可用**桶计数**：论文引用超过 `n` 的直接按 `n` 计（因为 h 最大也就 n）。`cnt[x]` = 引用次数恰好为 x 的论文数。然后从高到低累加论文数 `total`，第一个使 `total >= x` 的 `x` 即为 h（至少有 x 篇引用 ≥ x）。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)

### 代码
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        vector<int> cnt(n + 1, 0);
        for (int c : citations) cnt[min(c, n)]++;   // 超过 n 记为 n
        int total = 0;
        for (int x = n; x >= 0; --x) {
            total += cnt[x];                        // 引用数 ≥ x 的论文总数
            if (total >= x) return x;
        }
        return 0;
    }
};
```

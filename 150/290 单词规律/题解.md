# 290. 单词规律

## 题目描述
> 给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。这里的规律指**双射**（一一对应）：`pattern` 中的每个字符对应 `s` 中的一个非空单词，且每个单词也只对应一个字符。

## 解法一: 双哈希表映射
### 思路
先将字符串 `s` 按空格分割为单词数组。使用两个哈希表分别记录 `pattern[i] -> word` 和 `word -> pattern[i]` 的双向映射。遍历每个位置：
- 如果 `pattern[i]` 已有映射但不是当前 word，返回 false
- 如果 word 已有映射但不是当前 `pattern[i]`，返回 false
- 否则建立双向映射

### 复杂度
- 时间复杂度: O(n + m)，其中 n 为 pattern 长度，m 为 s 的总长度（分割+遍历）
- 空间复杂度: O(n + m)，存储拆分后的单词数组和两个哈希表
### 代码
```cpp
class Solution {
public:
    bool wordPattern(string pattern, string s) {
        vector<string> words;
        istringstream iss(s);
        string word;
        while (iss >> word) {
            words.push_back(word);
        }
        if (pattern.size() != words.size()) return false;
        
        unordered_map<char, string> c2w;
        unordered_map<string, char> w2c;
        for (int i = 0; i < pattern.size(); i++) {
            char c = pattern[i];
            string w = words[i];
            if (c2w.count(c) && c2w[c] != w) return false;
            if (w2c.count(w) && w2c[w] != c) return false;
            c2w[c] = w;
            w2c[w] = c;
        }
        return true;
    }
};
```

## 解法二: 单哈希表 + 索引比较法
### 思路
类似同构字符串的数组索引法。用一个哈希表记录 pattern 中每个字符首次出现的位置，另一个记录每个单词首次出现的位置。如果同一位置的两个首次出现索引不一致，说明映射不成立。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)
### 代码
```cpp
class Solution {
public:
    bool wordPattern(string pattern, string s) {
        vector<string> words;
        istringstream iss(s);
        string word;
        while (iss >> word) words.push_back(word);
        if (pattern.size() != words.size()) return false;
        
        unordered_map<char, int> p_idx;
        unordered_map<string, int> w_idx;
        for (int i = 0; i < pattern.size(); i++) {
            char c = pattern[i];
            string w = words[i];
            if (p_idx.count(c) != w_idx.count(w)) return false;
            if (p_idx.count(c) && p_idx[c] != w_idx[w]) return false;
            p_idx[c] = i;
            w_idx[w] = i;
        }
        return true;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双哈希表映射 | O(n+m) | O(n+m) | 直观，易于理解 | 需要两个哈希表 |
| 索引比较法 | O(n+m) | O(n+m) | 与同构字符串思路统一 | 需要理解首次出现索引技巧 |

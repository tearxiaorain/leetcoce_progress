# 290. 单词规律 — 代码点评

## 使用的方法
用户使用**双哈希表（map）双向映射法**：`ptos` 记录 pattern 字符到单词的映射，`stop` 记录单词到 pattern 字符的映射。手动遍历 s 按空格分割单词，然后逐一检查双向映射的一致性。

## 复杂度分析
- 时间复杂度: O(n log n + m) —— 遍历字符串分割 O(m)，map 操作 O(log n)，总体 O(m + n log n)，其中 n 为 pattern 长度，m 为 s 长度
- 空间复杂度: O(n + m) —— 存储单词数组和两个 map

## 代码评价
- 优点: 正确实现了双向映射检查，确保了双射关系；手动分割字符串逻辑完整（包含末尾单词 push）；通过 `else if` 恰当地捕获了"单向映射不一致"的情况
- 可改进之处: 使用 `map` 而非 `unordered_map` 导致查找 O(log n) 而非 O(1)；手动分割字符串可用 `istringstream` 简化；双向验证条件 `itp->second!=its->first || its->second!=itp->first` 稍显绕，直接比较 `itp->second != words[i]` 更清晰；`flag` 变量实际并未发挥"累积"作用，每次赋值后直接 return；main 函数调用 `wordPattern("egg", "add")` 参数不当——pattern 期望字符到单词的映射，但 "add" 是单个单词，与 "egg" 的 3 个字符不匹配
- 代码风格: 结构清晰，但 `flag` 模式略显啰嗦；变量命名 `ptos`/`stop` 含义可辨识

## 总结
> 双射检查逻辑正确，手动分词和 map 使用均可优化，main 函数测试用例与题目语义不匹配。

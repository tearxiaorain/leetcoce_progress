# 135. 分发糖果 (Candy)

## 题目描述

`n` 个孩子站成一排。给你一个整数数组 `ratings` 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

- 每个孩子至少分配到 1 个糖果。
- 相邻两个孩子评分更高的孩子会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的**最少糖果数目**。

---

## 解法一：两次遍历（贪心）

### 思路

规则拆成两条独立的约束：
1. **左规则**：若 `ratings[i] > ratings[i-1]`，则 `i` 的糖果数 > `i-1` 的糖果数。
2. **右规则**：若 `ratings[i] > ratings[i+1]`，则 `i` 的糖果数 > `i+1` 的糖果数。

两次遍历即可同时满足两条规则：
- **从左到右**：只处理左规则。若 `ratings[i] > ratings[i-1]`，则 `candy[i] = candy[i-1] + 1`；否则 `candy[i] = 1`。
- **从右到左**：只处理右规则。若 `ratings[i] > ratings[i+1]`，则取 `max(candy[i], candy[i+1] + 1)`，确保同时满足左规则的结果。

最终结果是 `candy` 数组的总和。

### C++ 代码

```cpp
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> candies(n, 1);

        // 从左到右：处理左规则
        for (int i = 1; i < n; ++i) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        // 从右到左：处理右规则
        for (int i = n - 2; i >= 0; --i) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = max(candies[i], candies[i + 1] + 1);
            }
        }

        // 求和
        return accumulate(candies.begin(), candies.end(), 0);
    }
};
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 解法二：常数空间（峰谷法）

### 思路

将 ratings 看作一座山脉，由交替的上升段和下降段组成。遍历过程中维护：
- `up`：当前上升段的长度
- `down`：当前下降段的长度
- `peak`：上一个峰顶的糖果数
- `total`：糖果总数

规则：
- 上升（`ratings[i] > ratings[i-1]`）：`up++`，`down = 0`，`peak = up + 1`，`total += up + 1`
- 持平（`ratings[i] == ratings[i-1]`）：`up = down = 0`，`peak = 1`，`total += 1`
- 下降（`ratings[i] < ratings[i-1]`）：`down++`，`up = 0`，`total += down`；若 `down >= peak` 还需额外 `total += 1`（因为峰顶不够高了）

### C++ 代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        if (n <= 1) return n;

        int total = 1;   // 第一个孩子至少1颗
        int up = 0;      // 当前上升长度
        int down = 0;    // 当前下降长度
        int peak = 1;    // 上一个峰顶的糖果数

        for (int i = 1; i < n; ++i) {
            if (ratings[i] > ratings[i - 1]) {
                // 上升
                up++;
                down = 0;
                peak = up + 1;
                total += peak;
            } else if (ratings[i] == ratings[i - 1]) {
                // 持平
                up = down = 0;
                peak = 1;
                total += 1;
            } else {
                // 下降
                down++;
                up = 0;
                total += down;
                if (down >= peak) {
                    total += 1; // 峰顶补偿
                }
            }
        }

        return total;
    }
};
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

---

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 两次遍历 | O(n) | O(n) | 左右各扫一遍，分别满足相邻规则 |
| 峰谷法 | O(n) | O(1) | 识别上升/下降段，增量计算糖果数 |

两次遍历法直观易懂，适合面试快速写出；峰谷法优化了空间，但细节较多。

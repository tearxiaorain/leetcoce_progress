# 135. 分发糖果 — 代码点评

## 解法识别

代码实现了**两次遍历（贪心）**算法，对应题解中的解法一。

---

## 代码亮点

1. **增量计数**：直接用 `count` 累加糖果数，末尾不需要再 `accumulate` 求和，省去一次遍历。
2. **第二遍剪枝**：在从右向左遍历时，若 `can[i] > can[i+1]` 已经满足，则 `continue` 跳过，避免不必要的计算。

```cpp
if (can[i] > can[i + 1])
    continue;
c = can[i + 1] + 1 - can[i];
```

3. **`c` 变量的使用**：用 `c = can[i-1]+1 - can[i]` 计算需要增加的差值，逻辑等价但写法紧凑。

---

## 存在的问题

### 1. main 函数测试不完整（中等严重）

`brr` 数组只有 5 个元素，但循环推入了 7 次，越界访问未定义行为。

```cpp
int brr[9] = {1,2,2,5,1};   // 只有5个初始化值
for (int i = 0; i < 7; i++) {
    n.push_back(arr[i]);
    m.push_back(brr[i]);     // i>=5 时越界
}
```

**建议**：用 `vector<int> brr = {1,2,2,5,1}` 并用实际大小控制循环。

### 2. 未验证 m 对应的测试用例

构建了 `m` 向量但从未输出或断言 `candy(m)`，实际上 brr 的测试被遗漏。

### 3. 变量命名简略

`n`、`c`、`can`、`m` 等单字母/缩写命名降低可读性。建议用 `ratings`、`delta`、`candies` 等语义化命名。

# 102. 二叉树的层序遍历 — 代码点评
## 使用的方法
BFS 层序遍历（队列 + 按层计数）。用队列保存节点，每轮先取 `int n = q.size()` 记录本层节点数，循环 `n` 次弹出本层节点并收集到 `vector<int> r`，同时把孩子入队，最后把非空的 `r` 加入结果。

## 复杂度分析
- 时间复杂度：O(n)，每个节点（含被入队的空指针）被弹出处理一次，总计 O(n)。
- 空间复杂度：O(n)，队列保存最宽一层节点；因空指针也入队，最坏（满二叉树叶子层的空孩子）仍为 O(n)。

## 代码评价

**优点**：
- 思路正确，采用标准的"`q.size()` 按层分批处理"技巧，层与层之间边界清晰。
- 用 `if (r.size())` 过滤掉全为空的层，保证结果不包含空层。

**可改进**：
- 空指针也入队（第 49-50 行 `q.push(t->left); q.push(t->right);` 未判空），导致队列中混入大量 `nullptr`。虽然复杂度仍是 O(n)，但浪费时间和空间常数，应改为 `if (t->left) q.push(t->left); if (t->right) q.push(t->right);`。
- 缺少 `root == nullptr` 的显式判断（第 38 行直接 `q.push(root)` 把空指针入队），依赖后续 `if(t)` 兜底。逻辑上正确但不够清晰，建议开头 `if (!root) return res;`。
- 若改为"非空才入队"，则 `if (r.size())` 的判断可去掉直接 `res.push_back(r)`。
- 头文件包含未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`（实际用到 `<iostream>`、`<vector>`、`<queue>`）。

**风格**：
- 符合 ACM 风格，`using namespace std;`。
- 变量名 `n`、`r` 简洁但可读性一般，建议 `sz`、`level`。

## 总结
> AC ✓

代码正确实现了层序遍历，采用 BFS + 按层计数，复杂度 O(n)/O(n)。主要问题是空指针入队带来冗余开销，改为"非空才入队"即可更精简高效，这也是后续 103、199、637 等层序变种题可复用的标准模板。

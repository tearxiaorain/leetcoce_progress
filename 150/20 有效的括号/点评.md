# 20. 有效的括号 — 代码点评

## 使用的方法
栈匹配法。遍历字符串，遇到左括号压栈；遇到右括号时检查栈顶是否为匹配的左括号——匹配则弹出，不匹配或栈为空则返回 false。最后检查栈是否为空。

## 复杂度分析
- 时间复杂度: O(n)，遍历一次字符串，每个字符的栈操作都是 O(1)。
- 空间复杂度: O(n)，最坏情况下（全部是左括号）栈大小等于字符串长度。

## 代码评价
- 优点: 标准的栈解法，思路正确，逻辑清晰。用三个 if-else 分支处理三种右括号，每个分支的检查流程（先判空、再判匹配、否则返回 false）严格正确。
- 可改进之处: 
  1. 三个 if-else 分支大量重复代码（判空→取top→判匹配→pop/return），可以用 `unordered_map<char, char>` 将右括号映射到左括号，将三个分支合并为一个通用分支，减少代码量。
  2. `if (st.empty()) return true; else return false;` 可以简化为 `return st.empty();`。
  3. 可以使用 `for (char c : s)` 代替索引遍历，更简洁。
- 代码风格: 清晰直白，但存在明显的代码重复，缺少 C++ 语法的精简写法。

## 总结
> 栈匹配法是括号问题的标准答案，代码逻辑正确，但可以通过 map 和范围 for 循环大幅精简。

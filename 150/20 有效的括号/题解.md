# 20. 有效的括号

## 题目描述
> 给定一个只包含 '(', ')', '{', '}', '[', ']' 的字符串 s，判断字符串中的括号是否有效配对。有效需满足：左括号必须用相同类型的右括号闭合；左括号必须以正确的顺序闭合；每个右括号都有一个对应的相同类型的左括号。

## 解法一: 栈匹配法
### 思路
使用栈来辅助匹配。遍历字符串，遇到左括号就压入栈中；遇到右括号时，检查栈顶是否为对应的左括号——如果是则弹出，否则直接返回 false。最后判断栈是否为空（空说明全部匹配）。

这也是该问题的标准最优解法。

### 复杂度
- 时间复杂度: O(n)，遍历一次字符串。
- 空间复杂度: O(n)，最坏情况下全部是左括号。

### 代码
```cpp
#include <iostream>
#include <string>
#include <stack>
#include <unordered_map>
using namespace std;

bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> pairs = {
        {')', '('},
        {']', '['},
        {'}', '{'}
    };
    
    for (char c : s) {
        if (pairs.count(c)) {
            // 右括号
            if (st.empty() || st.top() != pairs[c]) {
                return false;
            }
            st.pop();
        } else {
            // 左括号
            st.push(c);
        }
    }
    return st.empty();
}
```

## 解法二: 直接替换法（模拟消除）
### 思路
反复将字符串中的 "()", "[]", "{}" 子串替换为空串，如果最终字符串为空则说明全部有效配对。相当于不断地消除紧邻的配对括号，如果最终全部消除就是合法的。

### 复杂度
- 时间复杂度: O(n^2)，每次替换需要扫描整个字符串。
- 空间复杂度: O(n)，字符串存储。

### 代码
```cpp
bool isValid(string s) {
    int len;
    do {
        len = s.size();
        // 也可以手动查找替换
        size_t pos;
        if ((pos = s.find("()")) != string::npos) s.erase(pos, 2);
        else if ((pos = s.find("[]")) != string::npos) s.erase(pos, 2);
        else if ((pos = s.find("{}")) != string::npos) s.erase(pos, 2);
    } while (s.size() < len && !s.empty());
    return s.empty();
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 栈匹配法 | O(n) | O(n) | 标准最优解，一次遍历 |
| 直接替换法 | O(n^2) | O(n) | 思路简单但效率低 |

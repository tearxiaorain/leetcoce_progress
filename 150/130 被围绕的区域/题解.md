# 130. 被围绕的区域

## 题目描述

> 给定 `m × n` 的矩阵 `board`，元素为 `'X'` 或 `'O'`。请把所有**被 `'X'` 完全围绕**的区域内的 `'O'` 改成 `'X'`。
> 关键规则：任何**在边界上**的 `'O'`，以及与之（上下左右）相连的 `'O'` 都不会被围绕，必须保留。转换要求**原地**进行。
> 例：`[["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]` → `[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]`。

## 解法一：逐块 BFS，整块收集后再决定

### 思路
直接把题意翻译成代码：扫描每一格，遇到还没访问过的 `'O'` 就用 BFS 取出一整个连通块，同时记录这块是否碰到过矩阵边界。

- 碰到了边界 → 这块安全，什么都不做（里面的格子已标记为访问过，不再重复处理）；
- 没碰到边界 → 这块被完全围绕，把整块改成 `'X'`。

每个格子只会被访问一次（`seen` 标记），所以总体是 O(mn)。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(m·n)（`seen` 矩阵 + 队列 + 块内格子列表）

### 代码
```cpp
void solve(vector<vector<char>>& board) {
    if (board.empty() || board[0].empty()) return;
    int m = board.size(), n = board[0].size();
    vector<vector<bool>> seen(m, vector<bool>(n, false));
    const int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] != 'O' || seen[i][j]) continue;

            vector<pair<int,int>> cells;           // 本块的全部格子
            queue<pair<int,int>> q;
            bool touchEdge = false;                // 是否与边界连通
            q.push({i, j}); seen[i][j] = true;

            while (!q.empty()) {
                auto [x, y] = q.front(); q.pop();
                cells.push_back({x, y});
                if (x == 0 || x == m - 1 || y == 0 || y == n - 1) touchEdge = true;
                for (auto& d : dir) {
                    int nx = x + d[0], ny = y + d[1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (seen[nx][ny] || board[nx][ny] != 'O') continue;
                    seen[nx][ny] = true;
                    q.push({nx, ny});
                }
            }
            if (!touchEdge)                        // 被完全围绕 → 翻成 X
                for (auto& c : cells) board[c.first][c.second] = 'X';
        }
    }
}
```

## 解法二：从边界反推"安全格"（推荐）

### 思路
换个角度：与其判断每个块是否被围，不如**只做一次边界洪水填充**。所有与边界连通的 `'O'` 都是安全的，剩下的 `'O'` 必然被围。

1. 从四条边上的每一个 `'O'` 出发做 DFS/BFS，把沿途所有 `'O'` 临时标成 `'#'`（表示"安全"）；
2. 遍历整张棋盘：还是 `'O'` 的说明被围，改成 `'X'`；是 `'#'` 的还原成 `'O'`。

不需要 `seen` 数组，也不需要收集连通块，代码更短、常数更小。

### 复杂度
- 时间复杂度: O(m·n)（每格最多被访问一次）
- 空间复杂度: O(m·n)（最坏情况整张棋盘是一块，递归/栈深度或队列长度达到 m·n）

### 代码
```cpp
int m, n;
const int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};

void mark(vector<vector<char>>& board, int x, int y) {   // 淹没与边界连通的 O
    if (x < 0 || x >= m || y < 0 || y >= n || board[x][y] != 'O') return;
    board[x][y] = '#';                                   // 临时标记为安全
    for (auto& d : dir) mark(board, x + d[0], y + d[1]);
}

void solve(vector<vector<char>>& board) {
    if (board.empty() || board[0].empty()) return;
    m = board.size(); n = board[0].size();
    for (int i = 0; i < m; i++) {
        mark(board, i, 0);                               // 左边界
        mark(board, i, n - 1);                           // 右边界
    }
    for (int j = 0; j < n; j++) {
        mark(board, 0, j);                               // 上边界
        mark(board, m - 1, j);                           // 下边界
    }
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O') board[i][j] = 'X';   // 剩下的都被围住了
            else if (board[i][j] == '#') board[i][j] = 'O';   // 安全格还原
        }
    }
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 逐块 BFS + 触边判断 | O(m·n) | O(m·n) | 顺着题意写，需要 seen / 队列 / 块列表 |
| 边界洪水填充 | O(m·n) | O(m·n) | 标准解：只淹没边界的 O，最后统一翻转 |

> 变体：也可以用并查集，把四条边上的 `'O'` 与一个虚拟节点合并，最后凡是与虚拟节点同集合的格子保持 `'O'`；格点量大或担心递归深度时，把 DFS 换成显式栈的迭代写法即可。

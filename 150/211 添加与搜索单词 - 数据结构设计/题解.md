# 211. 添加与搜索单词 - 数据结构设计

## 题目描述

> 设计一个数据结构,支持 `addWord(word)` 添加单词、`search(word)` 查询单词是否存在。`search` 中的 `'.'` 可以匹配**任意一个**字母。例如添加 "bad"/"dad"/"mad" 后,`search(".ad")=true`、`search("b..")=true`、`search("pad")=false`。添加的单词与搜索词均只含小写字母或 `'.'`。

## 解法一: 前缀树 + 递归（标准解）

### 思路
用 **Trie(前缀树)** 存字典:`addWord` 逐字符建链、末节点标记单词;`search` 需要处理 `'.'`——遇到 `.` 时无法确定走哪个子节点,就**递归回溯**尝试所有存在的子节点,其余字符照常走链。递归基:处理完整个词时,判断当前节点是否是一个单词的结尾。

关键点:
- 递归时把**待匹配串的剩余部分**向下传,或传一个 `index` 指针;
- `'.'` 分支枚举 26 个子节点中非空者,有一个能走到底即返回 true;
- 节点应尽量紧凑,否则大量单词时内存吃紧(见 211 曾超内存的教训)。

### 复杂度
- 时间复杂度: addWord O(L);search 无 `.` 时 O(L),含 `.` 时最坏 O(26^d)(d 为 `.` 个数),受限于字典实际规模
- 空间复杂度: O(总字符数 × 节点开销)

### 代码
```cpp
class WordDictionary {
    struct Node {
        Node* next[26] = {};   // 内嵌定长数组,随节点一次分配,省内存
        bool isWord = false;
    };
    Node* root;
    bool dfs(const string& w, int i, Node* p) {
        if (i == (int)w.size()) return p->isWord;
        if (w[i] != '.') {
            Node* n = p->next[w[i] - 'a'];
            return n && dfs(w, i + 1, n);
        }
        for (int k = 0; k < 26; k++)        // '.' 尝试所有分支
            if (p->next[k] && dfs(w, i + 1, p->next[k])) return true;
        return false;
    }
public:
    WordDictionary() { root = new Node(); }
    void addWord(string word) {
        Node* p = root;
        for (char c : word) {
            int k = c - 'a';
            if (!p->next[k]) p->next[k] = new Node();
            p = p->next[k];
        }
        p->isWord = true;
    }
    bool search(string word) { return dfs(word, 0, root); }
};
```

## 解法二: 懒建子节点 / 按长度分桶（进一步优化）

### 思路
- **子节点稀疏时**可把 `Node* next[26]` 换成 `unordered_map<char, Node*>` 或按需建数组的写法,只为真实存在的分支分配,进一步压缩内存(字符集小、前缀稀疏时收益明显)。
- 另类思路:按**单词长度**分桶(`vector<vector<string>> byLen`),search 时只在该长度的桶里逐词匹配;若字典偏短、`. ` 较少也可过,但最坏仍是 O(词数×词长)。

### 复杂度
- 时间复杂度: 与解法一同,addWord O(L)、search O(最长匹配代价)
- 空间复杂度: O(总字符数)(只存真实分支)

### 代码（哈希子节点版核心）
```cpp
struct Node {
    unordered_map<char, Node*> next;
    bool isWord = false;
};
// addWord 里改为: if (!p->next.count(c)) p->next[c] = new Node();
// dfs 里 '.' 分支: for (auto& [c, n] : p->next) if (dfs(w, i+1, n)) return true;
```

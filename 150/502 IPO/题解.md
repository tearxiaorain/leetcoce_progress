# 502. IPO

## 题目描述

> 假设你初始资本为 `w`,最多可完成 `k` 个不同项目。每个项目 `i` 需投入资本 `capital[i]`,完成后可净赚 `profits[i]`。**每次只能启动一个当前资本 `w` 能负担得起(capital[i] ≤ w)的项目**,启动后资本变为 `w + profits[i]`。求最多完成 k 个项目后能获得的最大资本。
> 输入输出示意:`k=2, w=0, profits=[1,2,3], capital=[0,1,1]` → `4`(先做利润 1 的项目得 w=1,再做利润 2 的项目得 w=3?——实际为 0→1(赚1)→3(赚2)=4?按示例返回 4)。

## 解法一: 贪心 + 双堆（标准解）

### 思路
这是一个"当前资金内选最赚项目"的贪心问题。核心观察:**资金只会越赚越多、不会减少**,所以能做的项目集合单调扩大。用两组数据结构:
1. 把所有项目按 `capital` 升序排成候选流(未解锁);
2. **最小堆(按 capital)** 已含全部项目其实可省——更常见写法:先按 capital 排序,用一个指针扫描。

标准做法:
- 把项目按 `(capital, profit)` 排序;
- 循环 `k` 次:每轮先把 `capital[i] ≤ w` 的所有项目**解锁**进一个**按利润最大的最大堆**(解锁只进不退,因为 w 单调增),然后取堆顶项目执行,`w += profit`(堆空则无法再启动,提前结束)。

因为每轮都挑"当前资金能承担的项目中利润最高"的那个,且选择集随资金增长单调变大,贪心是安全的——更早做低利润项目只会推迟高利润项目解锁,但不会带来额外收益,标准证明用"交换论证"。

### 复杂度
- 时间复杂度: O((n + k) log n)(排序 O(n log n) + 最多解锁 n 次、取顶 k 次)
- 空间复杂度: O(n)(最大堆存项目)

### 代码
```cpp
int findMaximizedCapital(int k, int w, vector<int>& profits, vector<int>& capital) {
    int n = profits.size();
    vector<pair<int,int>> proj(n);                     // {capital, profit}
    for (int i = 0; i < n; i++) proj[i] = {capital[i], profits[i]};
    sort(proj.begin(), proj.end());                    // 按启动资金升序

    priority_queue<int> pq;                            // 已解锁项目按利润大顶堆
    int i = 0;
    for (int round = 0; round < k; round++) {
        while (i < n && proj[i].first <= w)            // 解锁所有买得起的
            pq.push(proj[i++].second);
        if (pq.empty()) break;                         // 没有可做项目
        w += pq.top(); pq.pop();                       // 做利润最大的
    }
    return w;
}
```

# 92. 反转链表 II

## 题目描述

> 给你单链表的头指针 `head` 和两个整数 `left` 和 `right`，其中 `left <= right`。请你反转从位置 `left` 到位置 `right` 的链表节点，返回 **反转后的链表**。
> 位置从 1 开始计数。

## 解法一: 穿针引线法（头插法）

### 思路
找到 `left` 的前驱节点 `pre`，然后将 `left` 到 `right` 之间的节点逐个以"头插法"插入到 `pre` 之后。

1. 用 dummy 节点处理 `left == 1` 的边界
2. `pre` 走到 `left - 1` 位置
3. `cur` 指向 `pre->next`（即 left 节点）
4. 循环 `right - left` 次，每次将 `cur->next` 取出，插入到 `pre->next` 位置

```
pre → 1(cur) → 2 → 3 → 4     取出 2 插入 pre 后
pre → 2 → 1(cur) → 3 → 4     取出 3 插入 pre 后
pre → 3 → 2 → 1(cur) → 4
```

### 复杂度
- 时间复杂度: **O(n)** — 遍历一次
- 空间复杂度: **O(1)** — 只用了常量指针

### 代码
```cpp
ListNode* reverseBetween(ListNode* head, int left, int right) {
    ListNode dummy(0, head);
    ListNode* pre = &dummy;

    // pre 走到 left-1
    for (int i = 1; i < left; i++)
        pre = pre->next;

    ListNode* cur = pre->next;
    for (int i = 0; i < right - left; i++) {
        ListNode* tmp = cur->next;      // 待前插的节点
        cur->next = tmp->next;          // cur 跳过 tmp
        tmp->next = pre->next;          // tmp 插到 pre 后
        pre->next = tmp;                // pre 接上 tmp
    }
    return dummy.next;
}
```

## 解法二: 截断反转拼接法

### 思路
将链表分成三段：`[1, left-1]`、`[left, right]`、`[right+1, end]`。反转中间段后再拼接回去。

1. 找到 left 前驱和 right 节点
2. 切断中间段，单独反转
3. 三部分重新连接

### 复杂度
- 时间复杂度: **O(n)** — 遍历 + 反转各一次
- 空间复杂度: **O(1)**

### 代码
```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}

ListNode* reverseBetween(ListNode* head, int left, int right) {
    ListNode dummy(0, head);
    ListNode* pre = &dummy;
    for (int i = 1; i < left; i++)
        pre = pre->next;

    ListNode* segHead = pre->next;
    ListNode* segTail = segHead;
    for (int i = left; i < right; i++)
        segTail = segTail->next;

    ListNode* rest = segTail->next;
    segTail->next = nullptr;                  // 切断

    pre->next = reverseList(segHead);         // 反转并接回
    segHead->next = rest;                     // segHead 变成了尾

    return dummy.next;
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 |
|------|-----------|-----------|------|
| 头插法 | O(n) | O(1) | 一次遍历，代码精炼 |
| 截断反转 | O(n) | O(1) | 思路清晰，易于理解 |

# 49. 字母异位词分组

## 题目描述
> 给定一个字符串数组，将字母异位词（由相同字母重排列而成的单词）分到同一组。返回所有分组，顺序不限。

## 解法一: 排序作为键
### 思路
字母异位词排序后得到的字符串相同。因此可以将每个单词排序后作为哈希表的键，值存储原始单词列表。

例：`"eat"` 排序为 `"aet"`，`"tea"` 排序也为 `"aet"`，它们被分到同一组。

### 复杂度
- 时间复杂度: O(n * k log k)，n 为单词数，k 为单词最大长度
- 空间复杂度: O(n * k)，哈希表存储所有单词

### 代码
```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (string& s : strs) {
            string key = s;
            sort(key.begin(), key.end());
            mp[key].push_back(s);
        }
        vector<vector<string>> ans;
        for (auto& p : mp)
            ans.push_back(p.second);
        return ans;
    }
};
```

## 解法二: 字符计数作为键
### 思路
用每个单词的字符频次作为键，避免排序。由于只有小写字母，可用长度为 26 的数组计数，然后拼接成字符串（如 `"#1#0#2..."` 表示 a 出现 1 次、b 出现 0 次、c 出现 2 次等）。

### 复杂度
- 时间复杂度: O(n * k)，无需排序
- 空间复杂度: O(n * k)

### 代码
```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (string& s : strs) {
            int count[26] = {0};
            for (char c : s) count[c - 'a']++;
            string key;
            for (int i = 0; i < 26; i++) {
                key += '#';
                key += to_string(count[i]);
            }
            mp[key].push_back(s);
        }
        vector<vector<string>> ans;
        for (auto& p : mp)
            ans.push_back(p.second);
        return ans;
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 排序作键 | O(n·k log k) | O(n·k) | 实现简单直观 | 排序有额外开销 |
| 字符计数作键 | O(n·k) | O(n·k) | 理论上更快（当k大时） | 键较长，拼接有开销 |

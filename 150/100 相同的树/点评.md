# 100. 相同的树 — 代码点评
## 使用的方法
递归 DFS（深度优先搜索）。同步遍历两棵树，逐节点比较结构和值是否一致。

## 复杂度分析
- 时间复杂度：O(min(m, n))，每个对应节点比较一次，遇到第一个不同处即可返回。
- 空间复杂度：O(min(h1, h2))，递归栈深度取决于较矮树的高度，最坏链状树为 O(min(m, n))。

## 代码评价

**优点**：
- 逻辑结构清晰，三句 if 分别处理"都空"、"一空"、"值不同"三种终止条件，符合递归解题的经典范式。
- 使用 `!p || !q` 简洁地表达"其中一个为空"的判断。

**可改进**：
- 在第 38-44 行，`if (p->val == q->val)` 内部又嵌套了 if-else，实际上当 `p->val != q->val` 时已经在外层 `else` 返回 false，内部可以直接写 `return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);` 简化为一行。
- 引入 r1、r2 中间变量略显冗余，不如直接短路求值返回。
- 头文件包含了一些未使用的 `<vector>`、`<stack>`、`<map>`、`<set>`、`<string>`。

**风格**：
- 符合一般 ACM 风格的写法，使用了 `using namespace std;`。
- 变量命名直接明了。

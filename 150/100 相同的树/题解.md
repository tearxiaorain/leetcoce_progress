# 100. 相同的树
## 题目描述
> 给定两棵二叉树的根节点 p 和 q，编写一个函数来检验这两棵树是否相同。如果两棵树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

## 解法一: 递归（DFS）
**思路**：递归地比较两棵树的每个节点。如果两个节点都为空，则相同；如果只有一个为空，则不同；如果两个节点值不同，则不同；否则递归比较它们的左子树和右子树。

**复杂度**：
- 时间复杂度：O(min(m, n))，其中 m 和 n 分别是两棵树的节点数。最坏情况下需要遍历所有节点。
- 空间复杂度：O(min(h1, h2))，递归栈深度取决于较矮树的高度，最坏情况（链状树）为 O(min(m, n))。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        // 都为空，相同
        if (p == nullptr && q == nullptr) return true;
        // 一个为空，不同
        if (p == nullptr || q == nullptr) return false;
        // 值不同，不同
        if (p->val != q->val) return false;
        // 递归比较左右子树
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

## 解法二: 迭代（BFS 队列）
**思路**：使用队列进行广度优先搜索，同时将两棵树的对应节点入队，逐对取出比较。如果对应节点结构或值不同则返回 false。

**复杂度**：
- 时间复杂度：O(min(m, n))，需要遍历所有对应节点。
- 空间复杂度：O(min(m, n))，队列中最多存储较宽层的节点数。

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        queue<TreeNode*> que;
        que.push(p);
        que.push(q);
        while (!que.empty()) {
            TreeNode* node1 = que.front(); que.pop();
            TreeNode* node2 = que.front(); que.pop();
            if (node1 == nullptr && node2 == nullptr) continue;
            if (node1 == nullptr || node2 == nullptr) return false;
            if (node1->val != node2->val) return false;
            que.push(node1->left);
            que.push(node2->left);
            que.push(node1->right);
            que.push(node2->right);
        }
        return true;
    }
};
```

## 解法三: 迭代（DFS 栈）
**思路**：使用栈进行深度优先搜索，模拟递归过程。将两棵树的对应节点同步压栈，逐对弹出比较。

**复杂度**：
- 时间复杂度：O(min(m, n))
- 空间复杂度：O(min(h1, h2))

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        stack<TreeNode*> stk;
        stk.push(p);
        stk.push(q);
        while (!stk.empty()) {
            TreeNode* node1 = stk.top(); stk.pop();
            TreeNode* node2 = stk.top(); stk.pop();
            if (node1 == nullptr && node2 == nullptr) continue;
            if (node1 == nullptr || node2 == nullptr) return false;
            if (node1->val != node2->val) return false;
            stk.push(node1->left);
            stk.push(node2->left);
            stk.push(node1->right);
            stk.push(node2->right);
        }
        return true;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 DFS | O(min(m,n)) | O(min(h1,h2)) | 简洁直观，函数调用栈 |
| 迭代 BFS | O(min(m,n)) | O(min(m,n)) | 队列层序遍历，空间可能更大 |
| 迭代 DFS | O(min(m,n)) | O(min(h1,h2)) | 栈模拟递归，避免递归爆栈 |

> 推荐解法一（递归），代码最简洁，也是二叉树问题的经典递归模板。如果树极深可能爆栈，则用解法三的迭代 DFS。

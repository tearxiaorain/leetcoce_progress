# 71. 简化路径

## 题目描述
> 给定一个 Unix 风格的绝对路径，将其简化为规范路径。规范路径规则：
> - 以 `/` 开头
> - 任意两个目录间只有一个 `/`
> - 不以 `/` 结尾
> - 不含 `.`（当前目录）和 `..`（上级目录）

## 解法一: 栈（分割 + 模拟）
### 思路
按 `/` 分割路径，用栈（或 vector 模拟栈）处理每个部分：
- 遇到空字符串或 `.`：跳过
- 遇到 `..`：弹出栈顶（返回上级目录），若栈空则忽略
- 其他：压入栈

最后将栈中元素用 `/` 拼接。

**图解：**
```
path = "/a/./b/../../c/"

按 '/' 分割: ["", "a", ".", "b", "..", "..", "c", ""]

处理:
""     → 跳过
"a"    → 入栈: ["a"]
"."    → 跳过
"b"    → 入栈: ["a", "b"]
".."   → 弹出: ["a"]
".."   → 弹出: []
"c"    → 入栈: ["c"]
""     → 跳过

结果: "/c"
```

### 复杂度
- 时间复杂度: O(n)，遍历一次 + 分割
- 空间复杂度: O(n)，栈空间

### 代码
```cpp
class Solution {
public:
    string simplifyPath(string path) {
        vector<string> st;
        stringstream ss(path);
        string token;
        while (getline(ss, token, '/')) {
            if (token.empty() || token == ".") continue;
            if (token == "..") {
                if (!st.empty()) st.pop_back();
            } else {
                st.push_back(token);
            }
        }
        string ans;
        for (string& s : st)
            ans += "/" + s;
        return ans.empty() ? "/" : ans;
    }
};
```

## 解法二: 手动分割（不使用 stringstream）
### 思路
不使用 `getline`，手动遍历字符串，积累字符，遇到 `/` 时处理当前积累的目录名。逻辑与解法一相同，但更底层。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)

### 代码
```cpp
class Solution {
public:
    string simplifyPath(string path) {
        vector<string> st;
        int n = path.size();
        for (int i = 0; i < n; i++) {
            if (path[i] == '/') continue;
            string token;
            while (i < n && path[i] != '/')
                token += path[i++];
            if (token == ".") continue;
            if (token == "..") {
                if (!st.empty()) st.pop_back();
            } else {
                st.push_back(token);
            }
        }
        string ans;
        for (string& s : st)
            ans += "/" + s;
        return ans.empty() ? "/" : ans;
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| stringstream 分割 | O(n) | O(n) | 代码简洁，利用标准库 | stringstream 有些开销 |
| 手动分割 | O(n) | O(n) | 更底层控制，无 stringstream 开销 | 代码稍长 |

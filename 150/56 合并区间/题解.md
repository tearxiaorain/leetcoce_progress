# 56. 合并区间

## 题目描述
> 给定一个区间数组 `intervals`，其中 `intervals[i] = [start_i, end_i]`，合并所有重叠的区间，返回一个不重叠的区间数组。

## 解法一: 排序 + 线性扫描
### 思路
1. 按区间左端点升序排序
2. 遍历排序后的区间，维护当前合并区间 `[L, R]`：
   - 若新区间左端点 `<= R`，说明有重叠，扩展右边界 `R = max(R, new_end)`
   - 否则无重叠，将 `[L, R]` 加入结果，更新为新区间

**图解：**
```
原始: [1,3], [2,6], [8,10], [15,18]
排序后不变（已按左端点排序）

[1,3] → L=1, R=3
[2,6]: 2<=3 重叠 → R=max(3,6)=6
[8,10]: 8>6 无重叠 → 输出[1,6], L=8,R=10
[15,18]: 15>10 无重叠 → 输出[8,10], L=15,R=18
最后输出[15,18]

结果: [1,6], [8,10], [15,18]
```

### 复杂度
- 时间复杂度: O(n log n)，排序开销
- 空间复杂度: O(log n) 排序栈空间，或 O(n) 存储结果

### 代码
```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> ans;
        int L = intervals[0][0], R = intervals[0][1];
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] <= R) {
                R = max(R, intervals[i][1]);
            } else {
                ans.push_back({L, R});
                L = intervals[i][0];
                R = intervals[i][1];
            }
        }
        ans.push_back({L, R});
        return ans;
    }
};
```

## 解法二: 差分数组（不推荐，仅思路呈现）
### 思路
将所有区间端点映射到数轴上的事件点，用差分数组记录区间覆盖次数。然后扫描数轴，连续覆盖次数 > 0 的段即为合并后的区间。但需要处理端点坐标范围过大（题目为 -10^4 ~ 10^4 尚可）的问题，不具普适性。

### 复杂度
- 时间复杂度: O(n + W)，W 为坐标范围
- 空间复杂度: O(W)

## 总结
| 解法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 排序+扫描 | O(n log n) | O(1) | 通用，最优 |
| 差分数组 | O(n+W) | O(W) | 仅坐标范围小时可用 |

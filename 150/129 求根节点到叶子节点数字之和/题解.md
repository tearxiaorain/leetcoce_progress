# 129. 求根节点到叶节点数字之和
## 题目描述
> 给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 0 到 9 之间的数字。每条从根节点到叶节点的路径都代表一个数字：例如从根节点到叶节点的路径 1→2→3 表示数字 123。计算从根节点到叶节点生成的所有数字之和。叶子节点是指没有子节点的节点。

## 解法一: 递归（DFS 前序，携带当前数值）
**思路**：自根向下递归，沿途维护"当前路径构成的数值" `cur`。进入每个节点时先更新 `cur = cur * 10 + node->val`；若到达叶子节点，把 `cur` 累加到总和 `sum`（用引用传递）；否则递归处理左右子树。这是前序遍历的自然应用。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        int sum = 0;
        dfs(root, 0, sum);
        return sum;
    }

    void dfs(TreeNode* node, int cur, int& sum) {
        if (node == nullptr) return;
        cur = cur * 10 + node->val;
        if (node->left == nullptr && node->right == nullptr) {
            sum += cur;          // 叶子节点，累加路径数值
            return;
        }
        dfs(node->left, cur, sum);
        dfs(node->right, cur, sum);
    }
};
```

## 解法二: 递归（DFS 返回值累加，不依赖引用）
**思路**：让递归函数返回"以当前节点为根的子树的路径数字之和"。传入父节点传递下来的数值 `pre`，更新为 `pre = pre * 10 + node->val`；叶子节点直接返回 `pre`；内部节点返回左右子树返回值之和。写法更函数式，无需引用变量。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)，递归栈深度为树高。

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }

    int dfs(TreeNode* node, int pre) {
        if (node == nullptr) return 0;
        int cur = pre * 10 + node->val;
        if (node->left == nullptr && node->right == nullptr) {
            return cur;          // 叶子节点返回路径数值
        }
        return dfs(node->left, cur) + dfs(node->right, cur);
    }
};
```

## 解法三: 迭代（栈 DFS，携带当前数值）
**思路**：用栈模拟前序遍历，栈元素为「节点 + 到达该节点的路径数值」。弹出节点后更新数值；叶子节点累加结果，否则压入子节点（携带更新后的数值）。避免深树递归爆栈。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，最坏情况栈中保存较多节点（按深度分析为 O(h)）。

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        if (root == nullptr) return 0;
        int sum = 0;
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, 0});
        while (!stk.empty()) {
            auto [node, pre] = stk.top(); stk.pop();
            int cur = pre * 10 + node->val;
            if (node->left == nullptr && node->right == nullptr) {
                sum += cur;
                continue;
            }
            if (node->right != nullptr) stk.push({node->right, cur});
            if (node->left  != nullptr) stk.push({node->left,  cur});
        }
        return sum;
    }
};
```

## 解法四: 迭代（队列 BFS，携带当前数值）
**思路**：改用队列广度优先遍历，队列元素同样为「节点 + 路径数值」，逐层传递数值，叶子节点累加。BFS 同样能正确求出所有根到叶路径数字之和。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列中最多保存一层的节点数。

```cpp
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        if (root == nullptr) return 0;
        int sum = 0;
        queue<pair<TreeNode*, int>> q;
        q.push({root, 0});
        while (!q.empty()) {
            auto [node, pre] = q.front(); q.pop();
            int cur = pre * 10 + node->val;
            if (node->left == nullptr && node->right == nullptr) {
                sum += cur;
                continue;
            }
            if (node->left  != nullptr) q.push({node->left,  cur});
            if (node->right != nullptr) q.push({node->right, cur});
        }
        return sum;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归(引用累加) | O(n) | O(h) | 前序遍历，叶子累加 |
| 递归(返回值) | O(n) | O(h) | 函数式写法，无副作用 |
| 迭代 DFS | O(n) | O(n) | 栈携带路径数值 |
| 迭代 BFS | O(n) | O(n) | 队列携带路径数值 |

> 推荐解法一或解法二（递归），代码简洁直观，是根到叶路径数值问题的经典模板。解法三/四是同一思路的迭代版本。

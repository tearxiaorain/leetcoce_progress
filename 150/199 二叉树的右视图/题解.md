# 199. 二叉树的右视图
## 题目描述
> 给定一个二叉树的根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

## 解法一: BFS 层序遍历（取每层最后一个节点）
**思路**：站在右侧能看到的是"每一层最右边的节点"。用队列做层序遍历，逐层取出节点；每层处理完 `sz` 个节点后，把该层最后一个节点的值加入结果（也可先右后左入队，取每层第一个节点）。

**复杂度**：
- 时间复杂度：O(n)，每个节点入队、出队各一次。
- 空间复杂度：O(w)，队列最多保存最宽一层的节点数，最坏（满二叉树底层）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        if (root == nullptr) return res;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            for (int i = 0; i < sz; i++) {
                TreeNode* node = q.front(); q.pop();
                if (i == sz - 1) res.push_back(node->val);  // 每层最后一个节点
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return res;
    }
};
```

## 解法二: DFS（根→右→左 前序，记录每层首次访问）
**思路**：按「根 → 右子树 → 左子树」的顺序遍历，这样每一层**第一次**被访问到的节点一定是最靠右的节点。维护当前深度 `depth`，当 `depth == res.size()` 时说明首次进入该层，记录当前节点值即可。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        dfs(root, 0, res);
        return res;
    }

    void dfs(TreeNode* node, int depth, vector<int>& res) {
        if (node == nullptr) return;
        if (depth == res.size()) res.push_back(node->val); // 该层首次访问，即最右节点
        dfs(node->right, depth + 1, res);
        dfs(node->left,  depth + 1, res);
    }
};
```

## 解法三: DFS（根→左→右 前序，深度覆盖）
**思路**：按「根 → 左子树 → 右子树」的顺序遍历，用 `depth` 作为结果数组下标，每次访问都覆盖 `res[depth]`。因为右子树最后访问，同一层右子树的节点会覆盖左子树的节点，最终 `res[depth]` 就是该层最右节点。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)，递归栈深度为树高。

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        dfs(root, 0, res);
        return res;
    }

    void dfs(TreeNode* node, int depth, vector<int>& res) {
        if (node == nullptr) return;
        if (depth == res.size()) res.push_back(node->val);
        else res[depth] = node->val;  // 右子树后访问，覆盖为最右节点
        dfs(node->left,  depth + 1, res);
        dfs(node->right, depth + 1, res);
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| BFS 层序遍历 | O(n) | O(n) | 取每层最后一个节点 |
| DFS 根右左 | O(n) | O(h) | 每层首次访问即最右 |
| DFS 根左右覆盖 | O(n) | O(h) | 深度下标覆盖，最右胜出 |

> 推荐解法二（DFS 根→右→左），代码简洁且空间只与树高相关。解法一（BFS）最直观，是层序类问题的通用模板；解法三依赖覆盖顺序，理解即可。

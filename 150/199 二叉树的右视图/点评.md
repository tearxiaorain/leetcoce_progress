# 199. 二叉树的右视图 — 代码点评
## 使用的方法
BFS 层序遍历 + 空指针占位。队列按层处理，把空指针也压入队列占位；每层遍历中，用 `see` 记录最后一个非空节点的值，用 `flag` 标记本层是否出现过非空节点；出现则把 `see` 加入结果。

## 复杂度分析
- 时间复杂度：O(n)。每个真实节点压入两个子节点（可能为空），空节点不再扩张子节点，队列总共处理 O(n) 个真实节点 + O(n) 个空节点，合计 O(n)。
- 空间复杂度：O(n)。队列因空指针占位，最坏情况约保留 2×最宽层节点数，O(n)。

## 代码评价

**优点**：
- 层序思路正确：把空指针也入队后，每层从左到右最后一个非空节点就是右视图节点，`see` 能正确捕获该值。
- 用 `flag` 区分"本层全空"与"本层有节点"，避免把空层计入结果，逻辑自洽，能处理 `[1,2]` 这类一侧缺子树的情况。

**可改进**：
- 空指针入队带来约一倍的额外空间与处理量，且 `see`/`flag` 双变量记账较绕。更简洁的做法是每层用 `int sz = q.size();` 只入队非空子节点，直接取该层第 `sz-1` 个节点（见题解解法一）。
- `see` 在每层非空节点间被反复覆盖，语义依赖"最后一个非空节点"，建议直接写 `if (i == sz - 1) res.push_back(node->val);` 更直白。
- 第 48-53 行对 null 子节点无条件 `q.push(t->left/t->right)`，是空指针占位的根源，改为 `if (node->left) q.push(...)` 即可消除。
- 头文件包含了一些未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`（实际用到 `<iostream>`、`<vector>`、`<queue>`）。

**风格**：
- 符合一般 ACM 风格，使用 `using namespace std;`。
- 变量名 `see`/`flag` 简洁但语义不够明确，建议 `rightmost`/`hasNode`。

## 总结
> AC ✓

代码结果正确，采用"层序 + 空指针占位"思路无误，复杂度 O(n)/O(n)。主要不足是空指针占位导致的空间与处理冗余，以及 `see`/`flag` 双变量记账可读性一般。最优为 DFS（根→右→左前序）O(n)/O(h)，或只入队非空节点的层序 O(n)/O(n)。

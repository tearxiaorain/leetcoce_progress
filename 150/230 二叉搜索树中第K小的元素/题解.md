# 230. 二叉搜索树中第K小的元素
## 题目描述
> 给定一个二叉搜索树的根节点 `root` 和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

## 解法一: 递归中序遍历
**思路**：二叉搜索树的中序遍历序列是严格递增的，因此中序遍历访问到的第 `k` 个节点就是第 `k` 小元素。维护计数器 `cnt`，中序遍历每访问一个节点 `cnt++`，当 `cnt == k` 时记录答案并提前返回。

**复杂度**：
- 时间复杂度：O(n)，最坏需要遍历到第 k 个节点（k=n 时 O(n)）。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        int ans = 0, cnt = 0;
        inorder(root, k, cnt, ans);
        return ans;
    }

    void inorder(TreeNode* node, int k, int& cnt, int& ans) {
        if (node == nullptr || cnt >= k) return;   // 已找到，提前剪枝
        inorder(node->left, k, cnt, ans);
        cnt++;
        if (cnt == k) { ans = node->val; return; }  // 第 k 个访问的节点
        inorder(node->right, k, cnt, ans);
    }
};
```

## 解法二: 迭代中序遍历（栈）
**思路**：用栈显式模拟中序遍历，避免递归。每弹出一个节点计数器减一，当计数器减到 0 时即为第 `k` 小元素，可提前终止。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)，栈中最多保存树高个节点，最坏 O(n)。

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        stack<TreeNode*> stk;
        TreeNode* cur = root;
        while (cur || !stk.empty()) {
            while (cur) {                 // 一路向左压栈
                stk.push(cur);
                cur = cur->left;
            }
            cur = stk.top(); stk.pop();
            if (--k == 0) return cur->val; // 第 k 个弹出的节点
            cur = cur->right;
        }
        return -1;
    }
};
```

## 解法三: Morris 中序遍历（O(1) 空间）
**思路**：利用线索二叉树（threaded binary tree）实现无栈、无递归的中序遍历。通过把当前节点左子树的最右节点的右指针临时指向当前节点（后继线索）来回到当前节点，访问后拆除线索。访问到第 `k` 个节点即返回。

**复杂度**：
- 时间复杂度：O(n)，每个节点最多访问常数次（找前驱虽需遍历，但均摊 O(1)）。
- 空间复杂度：O(1)，仅用少量指针变量。

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        TreeNode* cur = root;
        while (cur) {
            if (cur->left == nullptr) {
                if (--k == 0) return cur->val;      // 无左子树，访问当前节点
                cur = cur->right;
            } else {
                TreeNode* pre = cur->left;           // 左子树的最右节点 = 中序前驱
                while (pre->right && pre->right != cur) pre = pre->right;
                if (pre->right == nullptr) {         // 建立线索
                    pre->right = cur;
                    cur = cur->left;
                } else {                             // 拆除线索，访问当前节点
                    pre->right = nullptr;
                    if (--k == 0) return cur->val;
                    cur = cur->right;
                }
            }
        }
        return -1;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归中序遍历 | O(n) | O(h) | 中序第 k 个节点，计数剪枝 |
| 迭代中序遍历 | O(n) | O(h) | 栈模拟中序，提前终止 |
| Morris 遍历 | O(n) | O(1) | 线索二叉树，无额外空间 |

> 推荐解法二（迭代中序遍历），直观且能提前终止。若要求 O(1) 空间，则用解法三（Morris）；进阶可维护子树节点数，将查询降到 O(h)（需在建树/插入时维护 `cnt` 字段）。

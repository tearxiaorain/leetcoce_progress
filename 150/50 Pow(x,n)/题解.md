# 50. Pow(x, n)

## 题目描述
> 实现 `pow(x, n)`，即计算 `x` 的 `n` 次幂。`n` 可以是负数。
> - `-100.0 < x < 100.0`
> - `-2³¹ <= n <= 2³¹ - 1`

## 解法一: 递归快速幂（分治法）

### 思路
利用指数的二分性质：
- n 为偶数：`xⁿ = x^{n/2} × x^{n/2}`
- n 为奇数：`xⁿ = x^{n/2} × x^{n/2} × x`
- n 为负数：`xⁿ = 1 / x^{-n}`

递归计算 `half = myPow(x, n/2)`，然后合并结果。

### 复杂度
- 时间复杂度: O(log n)，每次递归将指数减半
- 空间复杂度: O(log n)，递归栈深度

### 代码
```cpp
double myPow(double x, int n) {
    if (n == 0) return 1.0;
    if (n < 0) {
        // 处理 n = INT_MIN 时 -n 溢出的边界情况
        return 1.0 / (x * myPow(x, -(n + 1)));
    }
    double half = myPow(x, n / 2);
    if (n % 2 == 0) return half * half;
    else return half * half * x;
}
```

## 解法二: 迭代快速幂（二进制分解）

### 思路
将指数 n 按二进制分解，从低位到高位处理每一位。例如 `x¹³ = x⁸ · x⁴ · x¹`（13 的二进制为 1101）。
- 用 `long long` 存 n 避免 INT_MIN 取反溢出
- 每次循环：若当前二进制位为 1，结果乘上当前幂；然后将 x 平方，n 右移一位

### 复杂度
- 时间复杂度: O(log n)
- 空间复杂度: O(1)

### 代码
```cpp
double myPow(double x, int n) {
    long long N = n;
    if (N < 0) { x = 1.0 / x; N = -N; }
    double res = 1.0;
    while (N) {
        if (N & 1) res *= x;
        x *= x;
        N >>= 1;
    }
    return res;
}
```

## 总结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 递归快速幂 | O(log n) | O(log n) | 代码简洁，注意INT_MIN边界 |
| 迭代快速幂 | O(log n) | O(1) | 无递归开销，更优 |

> **注意**: 当 n = -2³¹ 时，`-n` 会溢出 int。递归解法用 `-(n+1)` 技巧绕过，迭代解法用 `long long` 存储。

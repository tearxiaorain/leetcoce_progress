# 124. 二叉树中的最大路径和

## 题目描述

> 二叉树中的**路径**被定义为一条节点序列，序列中每对相邻节点之间都存在边，且同一个节点在序列中**最多出现一次**。路径至少包含一个节点，不一定要经过根节点。
> 给定二叉树的根节点 `root`，返回其最大路径和（路径上所有节点值之和的最大值）。
> 例：`root = [-10,9,20,null,null,15,7]` → `42`（路径 `15 → 20 → 7`）；`root = [-3]` → `-3`。
> 数据范围：节点数 1 ~ 3×10⁴，节点值 -1000 ~ 1000（**可能全为负数**）。

## 解法一：枚举"最高点" + 每次重新递归（直观解法）

### 思路
任意一条路径都有唯一一个"最高点"（离根最近的那个节点）。设最高点为 `v`，则路径由三段拼成：`v` 左侧向下的一段、`v` 本身、`v` 右侧向下的一段。所以：

- 先写一个朴素递归 `down(v)`：从 `v` 向下走能得到的最大和（可以随时停下，因此和负数时取 0 表示"不走这一段"）；
- 再枚举每个节点作为最高点，答案候选就是 `down(v->left) + v->val + down(v->right)`，取其中最大值。

因为每个 `down` 调用都要重新走完整棵子树，最坏（退化成链）是 O(n²)。

### 复杂度
- 时间复杂度: O(n²)（每个节点都重新递归整棵子树）
- 空间复杂度: O(h)（递归栈，h 为树高）

### 代码
```cpp
// 从 v 向下延伸（可以中途停下）能得到的最大和
long long down(TreeNode* v) {
    if (!v) return 0;
    return v->val + max(0LL, max(down(v->left), down(v->right)));
}

void enumerate(TreeNode* v, long long& best) {     // 枚举路径最高点
    if (!v) return;
    long long l = down(v->left), r = down(v->right);
    best = max(best, l + v->val + r);              // l、r 都 ≥ 0，等于"能拿就拿"
    enumerate(v->left, best);
    enumerate(v->right, best);
}

int maxPathSum(TreeNode* root) {
    long long best = LLONG_MIN;                    // 全负数时也要能取到单节点路径
    enumerate(root, best);
    return (int)best;
}
```

## 解法二：一次后序 DFS + 全局答案（推荐）

### 思路
解法一的问题是同一棵子树被反复递归。其实 `down` 只需要算一次：后序遍历时，每一层返回"以该节点为起点、向下延伸的最大和"给父节点，同时顺便用"以它为最高点的路径和"更新全局答案。

关键是区分两种语义：

- **向上返回**：只能选左右中的一条边（路径不能分叉着往上走），所以 `return v->val + max(0, left, right)`；取 0 表示"上面不要这一段"。
- **更新答案**：可以用上左右两条边，`candidate = left + val + right`（左右都已裁剪到非负）。

每个节点只被访问一次，O(n)。注意节点值可能全为负数：左右贡献取 `max(0, ...)` 保证答案候选至少包含 `v->val` 本身，全局答案初值设为 `LLONG_MIN`（或 `INT_MIN`）即可。

### 复杂度
- 时间复杂度: O(n)（每个节点一次后序访问）
- 空间复杂度: O(h)（递归栈，h 为树高；最好 O(log n)、最坏 O(n)）

### 代码
```cpp
long long best;                                        // 全局最大路径和

long long dfs(TreeNode* v) {                           // 返回：从 v 向下延伸的最大和(可含 v)
    if (!v) return 0;
    long long l = max(0LL, dfs(v->left));              // 负贡献直接舍弃
    long long r = max(0LL, dfs(v->right));
    best = max(best, l + r + v->val);                  // v 作为路径最高点
    return v->val + max(l, r);                         // 向父节点只能走一条边
}

int maxPathSum(TreeNode* root) {
    best = LLONG_MIN;
    dfs(root);
    return (int)best;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 枚举最高点 + 重复递归 | O(n²) | O(h) | 思路直白：路径 = 左臂 + 最高点 + 右臂 |
| 一次后序 DFS | O(n) | O(h) | 标准解：返回值与"答案候选"分开，一次遍历搞定 |

> 细节：`best` 用 `LLONG_MIN` / `INT_MIN` 起头，否则全负数用例（如 `[-3]`、`[-2,-1]`）会错；链状树较深时如果想避免递归栈，可把后序改成显式栈 + 哈希表存每个节点的单边贡献。

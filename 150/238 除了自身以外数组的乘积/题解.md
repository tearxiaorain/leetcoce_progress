# 238. 除自身以外数组的乘积 (Product of Array Except Self)

## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据**保证**数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 32 位整数范围内。

**要求**：不要使用除法，且在 O(n) 时间复杂度内完成此题。

**进阶**：你可以在 O(1) 的额外空间复杂度内完成这个题目吗？（出于对空间复杂度分析的目的，输出数组**不被视为**额外空间。）

---

## 解法一：左右乘积列表

### 思路

对于位置 `i`，答案 = (左侧所有元素的乘积) x (右侧所有元素的乘积)。

构造两个数组：
- `left[i]`：`nums[0] * nums[1] * ... * nums[i-1]`
- `right[i]`：`nums[i+1] * nums[i+2] * ... * nums[n-1]`

则 `answer[i] = left[i] * right[i]`。

### C++ 代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> left(n, 1);
        vector<int> right(n, 1);
        vector<int> answer(n);

        // 计算左侧乘积
        for (int i = 1; i < n; ++i) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        // 计算右侧乘积
        for (int i = n - 2; i >= 0; --i) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        // 合并结果
        for (int i = 0; i < n; ++i) {
            answer[i] = left[i] * right[i];
        }

        return answer;
    }
};
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 解法二：输出数组 + 动态前缀乘积（O(1) 额外空间）

### 思路

将输出数组 `answer` 本身当作 `left` 数组使用，然后用一个变量 `R` 从右向左滚动维护右侧乘积，直接在 `answer` 上乘入右侧乘积。

- 第一遍（左到右）：`answer[i]` 存的是 `i` 左侧所有元素的乘积
- 第二遍（右到左）：维护变量 `R` = 右侧乘积，`answer[i] *= R`，然后 `R *= nums[i]`

这样额外空间仅为 `R` 这一个变量，符合 O(1) 要求。

### C++ 代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(n, 1);

        // 第一遍：answer[i] = 左侧乘积
        for (int i = 1; i < n; ++i) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // 第二遍：从右向左，乘入右侧乘积
        int R = 1;
        for (int i = n - 1; i >= 0; --i) {
            answer[i] *= R;
            R *= nums[i];
        }

        return answer;
    }
};
```

### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（不计输出数组） |

---

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 左右乘积列表 | O(n) | O(n) | 前缀积 + 后缀积，分别存于两个数组 |
| 输出数组滚动 | O(n) | O(1) | 复用输出数组存前缀积，变量滚动维护后缀积 |

解法二是面试中最期望的答案——O(n) 时间 + O(1) 额外空间，思路巧妙且代码简洁。

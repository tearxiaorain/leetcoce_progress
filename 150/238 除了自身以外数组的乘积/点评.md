# 238. 除自身以外数组的乘积 — 代码点评

## 解法识别

代码实现了**左右乘积列表**算法，对应题解中的解法一。额外使用了两个辅助数组 `m1`（前缀积）和 `m2`（后缀积）。

---

## 代码亮点

1. **一次循环同时构建两个数组**：通过 `m1[i]` 和 `m2[n-i-1]` 在一次遍历中同时填充前缀积和后缀积，减少了循环次数。

```cpp
for (int i = 1; i < n; i++) {
    m1[i] = m1[i - 1] * nums[i];
    m2[n - i - 1] = m2[n - i] * nums[n - i - 1];
}
```

2. **首尾边界处理正确**：`res[0] = m2[1]`，`res[n-1] = m1[n-2]`，正确地处理了边界。

---

## 存在的问题

### 1. 空间复杂度可优化至 O(1)（建议改进）

当前使用两个辅助数组 `m1`、`m2`（O(n) 空间），而进阶要求是 O(1) 额外空间。可以复用 `res` 数组：
- 第一遍 `res[i] = res[i-1] * nums[i-1]`
- 第二遍用变量 `R` 从右向左滚动

### 2. 遗留注释代码

被注释的 O(n^2) 暴力解法遗留在函数中，属于调试残留，应删除：

```cpp
// for(int i=0;i<n;i++)
// {
//     for(int j=0;j<n;j++)
//     {
//         if(i!=j)
//             res[j]*=nums[i];
//     }
// }
```

### 3. 变量命名不够直观

`m1`/`m2` 无法让人一眼看出是前缀积/后缀积，建议用 `prefix`/`suffix` 或 `left`/`right`。

### 4. 未输出结果

main 函数计算了 `r` 但没有 `cout` 输出或 assert 验证，测试用例缺少验证手段。

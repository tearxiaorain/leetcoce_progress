# 191. 位 1 的个数

## 题目描述

> 编写一个函数,输入一个**无符号整数**(二进制表示),返回其二进制表达式中数字位数为 `1` 的个数(即汉明重量)。例如 `n = 00000000000000000000000000001011` → `3`。

## 解法一: 逐位检查（32 次循环）

### 思路
循环 32 次(整型固定 32 位),每次用 `n & 1` 取最低位,是 1 就计数,然后 `n >>= 1` 右移。思路直接,固定 32 轮。
对 `n` 为负数(当作无符号处理)也能正确工作,因为右移无符号逻辑右移。

### 复杂度
- 时间复杂度: O(1)(固定 32 次,与 n 无关)
- 空间复杂度: O(1)

### 代码
```cpp
int hammingWeight(uint32_t n) {
    int cnt = 0;
    for (int i = 0; i < 32; i++) {
        if (n & 1) cnt++;
        n >>= 1;
    }
    return cnt;
}
```

## 解法二: `n & (n-1)` 清零最低位（按需循环）

### 思路
关键技巧:`n & (n-1)` 会把 `n` 的**最低位的 1 变成 0**(借位相减)。每次执行一次就消掉一个 1,循环到 `n == 0`,循环次数 = 1 的个数,而非固定 32 次。1 很少时更快。

### 复杂度
- 时间复杂度: O(k)(k 为 1 的个数,≤ 32)
- 空间复杂度: O(1)

### 代码
```cpp
int hammingWeight(uint32_t n) {
    int cnt = 0;
    while (n) {
        n &= (n - 1);   // 消掉最低位的 1
        cnt++;
    }
    return cnt;
}
```

# 19. 删除链表的倒数第 N 个节点

## 题目描述

> 给定一个链表头 `head` 和一个整数 `n`，删除链表的**倒数第 n 个节点**，返回链表头。保证 `n` 有效（1 ≤ n ≤ 链表长度）。
> 输入输出示意：`head = [1,2,3,4,5], n = 2` → `[1,2,3,5]`。

## 解法一: 两次遍历（先数长度）

### 思路
第一遍统计链表总长 `L`。倒数第 n 个 = 正数第 `L-n+1` 个。要删它，找到它的前驱（正数第 `L-n` 个），令 `pre->next = pre->next->next`。
用哑节点 `dummy` 指向头，避免删头节点时无前驱的特判：从 `dummy` 出发走 `L-n` 步即停在待删节点前驱。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);
    int len = 0;
    for (ListNode* p = head; p; p = p->next) len++;
    ListNode* pre = &dummy;
    for (int i = 0; i < len - n; i++) pre = pre->next;
    pre->next = pre->next->next;      // 跳过待删节点（本例不释放内存）
    return dummy.next;
}
```

## 解法二: 双指针（一次遍历）

### 思路
让快指针 `fast` 先走 `n` 步，慢指针 `slow` 停在哑节点（待删节点的前驱）。此后 `fast` 与 `slow` 同步前移，当 `fast` 走到链表尾（`nullptr`）时，`slow` 正好停在倒数第 n 个节点的前驱，删掉其后继即可。
关键点：`slow` 初始在哑节点而非头节点，这样倒数第 n 个节点即使正好是头节点也能删。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);
    ListNode *fast = head, *slow = &dummy;
    for (int i = 0; i < n; i++) fast = fast->next;   // fast 先走 n 步
    while (fast) {                                    // 同步走到 fast 到尾
        fast = fast->next;
        slow = slow->next;
    }
    slow->next = slow->next->next;                    // slow 停在待删前驱
    return dummy.next;
}
```

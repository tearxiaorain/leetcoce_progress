# 138. 随机链表的复制

## 题目描述

> 给定一个链表，每个节点除 `next` 外还有一个指向链内任意节点的 `random` 指针。要求**深拷贝**：构造一个全新的链表，其结构、next 与 random 指向都与原链表**一一对应**，新链表每个节点都是新建的（不能复用原节点）。
> 输入输出示意：`head = [[7,null],[13,0],[11,4],[10,2],[1,0]]` → 复制后结构与原链表完全一致。

## 解法一: 哈希表映射（直观，两遍遍历）

### 思路
第一遍：遍历原链表，每遇到一个原节点 `cur`，新建 `new Node(cur->val)`，并用 `unordered_map<Node*, Node*> m` 记下 **原节点 → 新节点** 的映射。
第二遍：再次遍历原链表，用映射把新链的 `next` 和 `random` 接上：`m[cur]->next = m[cur->next]`，`m[cur]->random = m[cur->random]`（`cur->next` 或 `cur->random` 为 `nullptr` 时映射不命中，需特判）。
核心：用哈希表把「原节点地址」翻译成「新节点地址」，random 指向的是谁就有了着落。

### 复杂度
- 时间复杂度: O(n)（两遍遍历 + 哈希表 O(1) 平均查询）
- 空间复杂度: O(n)（哈希表存 n 个映射）

### 代码
```cpp
Node* copyRandomList(Node* head) {
    if (!head) return nullptr;
    unordered_map<Node*, Node*> m;
    for (Node* p = head; p; p = p->next)
        m[p] = new Node(p->val);
    for (Node* p = head; p; p = p->next) {
        m[p]->next   = p->next   ? m[p->next]   : nullptr;
        m[p]->random = p->random ? m[p->random] : nullptr;
    }
    return m[head];
}
```

## 解法二: 原地拼接 + 拆链（O(n) O(1)）

### 思路
1. **复制并拼接**：遍历原链，每个节点 `cur` 之后紧插一个新副本 `new Node(cur->val)`，即 `cur->next = copy; copy->next = cur->next 的原后继`，形成 `原→新→原→新…` 的长链。
2. **连 random**：再次遍历，新副本的 random 就是其前驱原节点的 random 的后继：`cur->next->random = cur->random ? cur->random->next : nullptr`。
3. **拆链**：第三次遍历，把新链从长链中分离出来，同时恢复原链的 next。

不需要哈希表，副本紧挨原节点，random 一步就能定位。

### 复杂度
- 时间复杂度: O(n)（三遍线性遍历）
- 空间复杂度: O(1)（不含返回值，无额外容器）

### 代码
```cpp
Node* copyRandomList(Node* head) {
    if (!head) return nullptr;
    for (Node* p = head; p; p = p->next->next) {     // 1. 插副本
        Node* c = new Node(p->val);
        c->next = p->next;
        p->next = c;
    }
    for (Node* p = head; p; p = p->next->next)       // 2. 连 random
        p->next->random = p->random ? p->random->next : nullptr;
    Node* nh = head->next;
    for (Node* p = head; p; p = p->next) {           // 3. 拆链
        Node* c = p->next;
        p->next = c->next;
        c->next = p->next ? p->next->next : nullptr;
    }
    return nh;
}
```

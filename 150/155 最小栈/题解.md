# 155. 最小栈

## 题目描述
> 设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。实现 MinStack 类：
> - `push(val)`：将元素 val 压入栈
> - `pop()`：移除栈顶元素
> - `top()`：获取栈顶元素
> - `getMin()`：获取栈中的最小元素

## 解法一: 辅助栈法（双栈）
### 思路
使用两个栈：
1. `dataStack`：存储所有元素，正常的栈。
2. `minStack`：存储当前栈中的最小值。每次 push 时，如果新元素 <= minStack.top()，则也压入 minStack。每次 pop 时，如果弹出的元素等于 minStack.top()，则 minStack 也弹出一个。

注意：push 时使用 `<=` 而非 `<`，这样处理重复最小值的情况。

### 复杂度
- 时间复杂度: O(1)，所有操作均为常数时间
- 空间复杂度: O(n)，最坏情况两个栈共存储 2n 个元素

### 代码
```cpp
class MinStack {
private:
    stack<int> dataStack;
    stack<int> minStack;

public:
    MinStack() {}
    
    void push(int val) {
        dataStack.push(val);
        if (minStack.empty() || val <= minStack.top()) {
            minStack.push(val);
        }
    }
    
    void pop() {
        if (dataStack.top() == minStack.top()) {
            minStack.pop();
        }
        dataStack.pop();
    }
    
    int top() {
        return dataStack.top();
    }
    
    int getMin() {
        return minStack.top();
    }
};
```

## 解法二: 差值法（单栈 + 变量）
### 思路
使用一个栈和一个变量 `minVal` 记录当前最小值。栈中存储的是 `val - minVal` 的差值：
- push 时：栈为空则 minVal = val，压入 0；否则压入 `val - minVal`，如果 val < minVal 则更新 minVal。
- pop 时：如果栈顶差值 < 0，说明弹出的元素曾更新了最小值，需要恢复上一个最小值：`minVal = minVal - topDiff`。
- top 时：如果栈顶差值 < 0，说明当前栈顶就是最小值，直接返回 minVal；否则返回 `minVal + topDiff`。

### 复杂度
- 时间复杂度: O(1)
- 空间复杂度: O(n)，单个栈（但有时会溢出 int 范围，需用 long long）

### 代码
```cpp
class MinStack {
private:
    stack<long long> diffStack;
    long long minVal;

public:
    MinStack() {}
    
    void push(int val) {
        if (diffStack.empty()) {
            diffStack.push(0);
            minVal = val;
        } else {
            long long diff = (long long)val - minVal;
            diffStack.push(diff);
            if (val < minVal) {
                minVal = val;
            }
        }
    }
    
    void pop() {
        long long diff = diffStack.top();
        diffStack.pop();
        if (diff < 0) {
            // 恢复上一个最小值
            minVal = minVal - diff;
        }
    }
    
    int top() {
        long long diff = diffStack.top();
        if (diff < 0) {
            return (int)minVal;
        } else {
            return (int)(minVal + diff);
        }
    }
    
    int getMin() {
        return (int)minVal;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(1) | O(n) | 辅助栈同步维护最小值 |
| 解法二 | O(1) | O(n) | 单栈存储与当前最小值的差值 |

解法一（辅助栈）最为直观，也最常用。解法二节省了一个栈的空间，但实现复杂且需处理 long long 溢出，一般面试推荐解法一。

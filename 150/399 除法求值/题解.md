# 399. 除法求值

## 题目描述

> 给定变量之间的除法方程：`equations[i] = [Ai, Bi]` 与 `values[i]`，表示 `Ai / Bi = values[i]`（变量都是字符串）。
> 再给定若干查询 `queries[j] = [Cj, Dj]`，求 `Cj / Dj` 的值；若无法根据已知方程推出结果，返回 `-1.0`。
> 例：`equations = [["a","b"],["b","c"]], values = [2.0,3.0]`，查询 `[["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]` → `[6.0, 0.5, -1.0, 1.0, -1.0]`。
> 数据范围：1 ≤ equations.length ≤ 20，查询最多 20 个；只要查询涉及的变量之一没出现过，答案就是 `-1.0`。

## 解法一：建无向带权图 + 每次查询 DFS 找路径

### 思路
把每个变量看成图上的点：已知 `A / B = v`，就加两条有向边 `A --v--> B` 和 `B --1/v--> A`（权表示"从当前点走一步得到的比值"）。

那么一次查询 `C / D` 就是"从 `C` 走到 `D` 的路径上所有边权相乘"：因为 `C/X1 × X1/X2 × … × D` 途中约掉，正好等于 `C/D`。若两点不连通（或有一个变量从未出现），返回 `-1.0`。深搜时要记录访问过的点，避免在环上打转。

每次查询都重新搜一遍，适合查询数不多的场景（本题 Q ≤ 20）。

### 复杂度
- 时间复杂度: O(Q · (V + E))（每次查询一次图搜索）
- 空间复杂度: O(V + E)（邻接表）+ O(V) 访问标记与递归栈

### 代码
```cpp
unordered_map<string, vector<pair<string, double>>> g;   // 变量 -> {邻居, 边权}
unordered_set<string> visited;

double dfs(const string& cur, const string& dst, double acc) {
    if (cur == dst) return acc;                          // 到达终点
    visited.insert(cur);
    for (auto& [nxt, w] : g[cur]) {
        if (visited.count(nxt)) continue;                // 防环
        double res = dfs(nxt, dst, acc * w);             // 沿途乘权
        if (res != -1.0) return res;
    }
    return -1.0;
}

vector<double> calcEquation(vector<vector<string>>& equations, vector<double>& values,
                            vector<vector<string>>& queries) {
    g.clear();
    for (size_t i = 0; i < equations.size(); i++) {
        const string& a = equations[i][0];
        const string& b = equations[i][1];
        g[a].push_back({b, values[i]});                  // a / b = v
        g[b].push_back({a, 1.0 / values[i]});            // b / a = 1/v
    }
    vector<double> res;
    for (auto& q : queries) {
        if (!g.count(q[0]) || !g.count(q[1])) {          // 变量没出现过
            res.push_back(-1.0);
            continue;
        }
        visited.clear();
        res.push_back(dfs(q[0], q[1], 1.0));
    }
    return res;
}
```

## 解法二：带权并查集（推荐）

### 思路
把"同一个连通分量里的变量"合并成一棵树，并让每个节点记住**自己与父节点的比值**：`weight[x] = x / parent[x]`。路径压缩时把这个比值一路乘到根上，于是 `x / root = weight[x]`。

有了它，查询就变成常数级判断：

- 两个变量的根不同 → 不在同一连通分量，返回 `-1.0`；
- 根相同 → `x / y = (x / root) ÷ (y / root) = weight[x] / weight[y]`。

合并方程 `a / b = v` 时，设 `ra`、`rb` 分别是 `a`、`b` 的根，令 `parent[ra] = rb`，则由

```
a / b = (weight[a] · ra) / (weight[b] · rb) = v
```

解得 `weight[ra] = ra / rb = v · weight[b] / weight[a]`，这正是合并时要写的公式。

### 复杂度
- 时间复杂度: O((E + Q) · α(V))（α 为反阿克曼函数，近似常数）
- 空间复杂度: O(V)（父指针与权重哈希表）

### 代码
```cpp
unordered_map<string, string> parent;    // 并查集父节点
unordered_map<string, double> weight;    // weight[x] = x / parent[x]

string find(const string& x) {
    if (parent[x] == x) return x;
    string root = find(parent[x]);
    weight[x] *= weight[parent[x]];      // 路径压缩：把到根的倍数一并累乘
    return parent[x] = root;
}

void unite(const string& a, const string& b, double v) {   // 记录 a / b = v
    string ra = find(a), rb = find(b);
    if (ra == rb) return;                // 已在同一分量，题目保证不冲突
    parent[ra] = rb;                     // 让 ra 挂到 rb 下
    weight[ra] = weight[b] * v / weight[a];                // 由 a/b = v 推导得到
}

vector<double> calcEquation(vector<vector<string>>& equations, vector<double>& values,
                            vector<vector<string>>& queries) {
    parent.clear(); weight.clear();
    for (auto& e : equations) {          // 先把出现的变量都建成独立集合
        if (!parent.count(e[0])) { parent[e[0]] = e[0]; weight[e[0]] = 1.0; }
        if (!parent.count(e[1])) { parent[e[1]] = e[1]; weight[e[1]] = 1.0; }
    }
    for (size_t i = 0; i < equations.size(); i++)
        unite(equations[i][0], equations[i][1], values[i]);

    vector<double> res;
    for (auto& q : queries) {
        if (!parent.count(q[0]) || !parent.count(q[1])) {
            res.push_back(-1.0);         // 变量不存在
            continue;
        }
        string ra = find(q[0]), rb = find(q[1]);
        res.push_back(ra == rb ? weight[q[0]] / weight[q[1]] : -1.0);
    }
    return res;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 带权图 + 每次 DFS | O(Q·(V+E)) | O(V+E) | 思路直观：路径边权相乘即比值 |
| 带权并查集 | O((E+Q)·α(V)) | O(V) | 标准解：一次合并、查询近似 O(1) |

> 还有一条更"暴力"的路：把所有变量编号，用二维表存已知比值，跑一遍 Floyd 把能推出来的比值全部补全（O(V³)）。变量数 ≤ 40 时够用，但代码更长、精度误差也会累积，一般用并查集或图搜索即可。

# 226. 翻转二叉树 — 代码点评
## 使用的方法
递归后序遍历。先递归翻转左右子树，再交换当前节点的左右指针。属于自底向上的翻转策略。

## 复杂度分析
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏情况（链状树）为 O(n)。

## 代码评价

**优点**：
- 递归逻辑正确，先深入子树完成翻转（自底向上），再交换指针，顺序合理。
- 空节点判断 `if (p == nullptr) return p;` 简洁且能正确处理边界。
- 函数签名返回 TreeNode*，方便链式调用和递归返回值赋值。

**可改进**：
- 第 36-37 行的变量名 `t1`、`t2` 语义不够明确，建议用 `left`、`right` 或 `invertedLeft`、`invertedRight`。
- 可以使用 `std::swap(p->left, p->right)` 替代手动三行交换代码（t1/t2 保存 + 赋值），更简洁且不容易写错。
- 参数名用 `p` 而非 `root` 不够直观，建议改为 `root` 与题目描述保持一致。
- 头文件包含了一些未使用的 `<vector>`、`<stack>`、`<map>`、`<set>`、`<string>`、`<algorithm>`。

**风格**：
- 代码紧凑，但变量命名和手动交换可优化。
- 后序遍历思路清晰，是 226 题的经典递归解法之一。

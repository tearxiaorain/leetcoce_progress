# 226. 翻转二叉树
## 题目描述
> 给你一棵二叉树的根节点 root，翻转这棵二叉树，并返回其根节点。翻转是指将每个节点的左右子树进行交换。

## 解法一: 递归（前序遍历）
**思路**：从根节点开始，交换其左右子树，然后递归地对左右子树进行同样的翻转操作。采用前序遍历顺序：先交换当前节点的左右孩子，再递归翻转左右子树。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度取决于树高，最坏情况（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        // 交换左右子树
        swap(root->left, root->right);
        // 递归翻转左右子树
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

## 解法二: 递归（后序遍历）
**思路**：先递归翻转左右子树，再交换当前节点的左右指针。后序遍历同样可以完成翻转，只是交换时机不同。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        // 先翻转子树
        TreeNode* left = invertTree(root->left);
        TreeNode* right = invertTree(root->right);
        // 再交换
        root->left = right;
        root->right = left;
        return root;
    }
};
```

## 解法三: 迭代 BFS（层序遍历）
**思路**：使用队列层序遍历，对每个出队节点交换其左右孩子，然后将非空孩子入队。自上而下逐层翻转。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列最坏存储一层节点

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        queue<TreeNode*> que;
        que.push(root);
        while (!que.empty()) {
            TreeNode* node = que.front();
            que.pop();
            swap(node->left, node->right);
            if (node->left) que.push(node->left);
            if (node->right) que.push(node->right);
        }
        return root;
    }
};
```

## 解法四: 迭代 DFS（栈）
**思路**：使用栈进行深度优先遍历，对每个弹出的节点交换左右孩子，再压入非空孩子。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        stack<TreeNode*> stk;
        stk.push(root);
        while (!stk.empty()) {
            TreeNode* node = stk.top();
            stk.pop();
            swap(node->left, node->right);
            if (node->left) stk.push(node->left);
            if (node->right) stk.push(node->right);
        }
        return root;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归前序 | O(n) | O(h) | 先交换再递归子节点 |
| 递归后序 | O(n) | O(h) | 先递归子节点再交换 |
| 迭代 BFS | O(n) | O(n) | 队列层序遍历，逐层交换 |
| 迭代 DFS | O(n) | O(h) | 栈深度遍历，逐个交换 |

> 推荐解法一（递归前序），代码最简洁。此题无论哪种遍历顺序都能正确完成翻转，是经典的"每个节点都做同一操作"型题目。

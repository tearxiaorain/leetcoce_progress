# 54. 螺旋矩阵

## 题目描述
> 给定一个 m x n 的矩阵，按顺时针螺旋顺序返回矩阵中的所有元素。

## 解法一: 边界收缩法（按层模拟）
### 思路
定义上下左右四个边界：`top`, `bottom`, `left`, `right`。按顺时针方向遍历：
1. 从左到右遍历上边界 `top` 行，然后 `top++`
2. 从上到下遍历右边界 `right` 列，然后 `right--`
3. 如果 `top <= bottom`，从右到左遍历下边界 `bottom` 行，然后 `bottom--`
4. 如果 `left <= right`，从下到上遍历左边界 `left` 列，然后 `left++`

每步遍历后收缩对应边界，直到边界交错。

**图解（3x4 矩阵）：**
```
top=0:  [ 1  2  3  4]  → 右移, top++
         [ 5  6  7  8]
bottom=2:[ 9 10 11 12]

right=3: [ .  .  .  .]
         [ 5  6  7  8]  ↓ 下移, right--
         [ 9 10 11 12]

bottom=2: [ .  .  .  .]
          [ .  .  .  .]
          [12 11 10  9]  ← 左移, bottom--

left=0:  [ .  .  .  .]
         [ 5  6  .  .]  ↑ 上移, left++
         [ .  .  .  .]
```

### 复杂度
- 时间复杂度: O(m * n)，每个元素访问一次
- 空间复杂度: O(1)，不计输出数组

### 代码
```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> ans;
        int m = matrix.size(), n = matrix[0].size();
        int top = 0, bottom = m - 1, left = 0, right = n - 1;
        while (top <= bottom && left <= right) {
            // 左 → 右
            for (int j = left; j <= right; j++)
                ans.push_back(matrix[top][j]);
            top++;
            // 上 → 下
            for (int i = top; i <= bottom; i++)
                ans.push_back(matrix[i][right]);
            right--;
            // 右 → 左（需判断是否还有行）
            if (top <= bottom) {
                for (int j = right; j >= left; j--)
                    ans.push_back(matrix[bottom][j]);
                bottom--;
            }
            // 下 → 上（需判断是否还有列）
            if (left <= right) {
                for (int i = bottom; i >= top; i--)
                    ans.push_back(matrix[i][left]);
                left++;
            }
        }
        return ans;
    }
};
```

## 解法二: 方向数组法
### 思路
定义方向数组 `dir = [(0,1), (1,0), (0,-1), (-1,0)]` 表示右、下、左、上。维护当前位置和方向索引，用 `visited` 数组或边界判断何时转向。

### 复杂度
- 时间复杂度: O(m * n)
- 空间复杂度: O(m * n)（visited 数组）或 O(1)（边界模拟法）

### 代码
```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        int dx[] = {0, 1, 0, -1};
        int dy[] = {1, 0, -1, 0};
        vector<int> ans;
        int x = 0, y = 0, dir = 0;
        for (int i = 0; i < m * n; i++) {
            ans.push_back(matrix[x][y]);
            visited[x][y] = true;
            int nx = x + dx[dir], ny = y + dy[dir];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n || visited[nx][ny]) {
                dir = (dir + 1) % 4;
                nx = x + dx[dir];
                ny = y + dy[dir];
            }
            x = nx; y = ny;
        }
        return ans;
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 边界收缩法 | O(mn) | O(1) | 无需额外空间，直观 | 需要处理边界条件 |
| 方向数组法 | O(mn) | O(mn) | 方向切换统一 | visited 数组占用空间 |

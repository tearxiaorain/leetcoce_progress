# 27. 移除元素

## 题目描述
> 给定一个数组 nums 和一个值 val，原地移除所有数值等于 val 的元素，并返回移除后数组的新长度。不需要考虑数组中超出新长度后面的元素。要求 O(1) 额外空间。

## 解法一: 双指针法（快慢指针）
### 思路
使用快慢双指针。慢指针 i 指向下一个应该放置保留元素的位置，快指针 j 遍历整个数组。当 nums[j] != val 时，说明该元素需要保留，将其复制到 nums[i] 并移动慢指针；当 nums[j] == val 时跳过。

### 复杂度
- 时间复杂度: O(n)，遍历一次数组。
- 空间复杂度: O(1)，只使用两个指针。

### 代码
```cpp
#include <iostream>
#include <vector>
using namespace std;

int removeElement(vector<int>& nums, int val) {
    int i = 0;  // 慢指针
    for (int j = 0; j < nums.size(); j++) {
        if (nums[j] != val) {
            nums[i] = nums[j];
            i++;
        }
    }
    return i;
}
```

## 解法二: 双指针法（首尾指针，优化版）
### 思路
当要删除的元素较少时，将等于 val 的元素与数组末尾元素交换。首指针 left 指向开头，尾指针 right 指向末尾。当 nums[left] == val 时，用 nums[right] 替换它并收缩右指针；否则移动左指针。这样可以减少不必要的复制。

### 复杂度
- 时间复杂度: O(n)，但实际赋值次数更少。
- 空间复杂度: O(1)。

### 代码
```cpp
int removeElement(vector<int>& nums, int val) {
    int left = 0;
    int right = nums.size() - 1;
    while (left <= right) {
        if (nums[left] == val) {
            nums[left] = nums[right];
            right--;
        } else {
            left++;
        }
    }
    return left;
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 快慢指针 | O(n) | O(1) | 保证剩余元素相对顺序不变 |
| 首尾指针 | O(n) | O(1) | 赋值次数少，但不保证顺序 |

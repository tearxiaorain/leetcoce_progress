# 151. 反转字符串中的单词

## 题目描述
> 给定一个字符串 s，反转字符串中单词的顺序。单词是由非空格字符组成的子串，单词之间用至少一个空格分隔。返回的字符串中单词间应以单个空格分隔，且首尾不应有空格。

## 解法一: 分割 + 反转拼接
### 思路
使用字符串流 `istringstream` 按空格分割单词，将单词存入 vector，然后从后向前拼接，单词之间用一个空格分隔。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)，需要额外空间存储单词列表

### 代码
```cpp
class Solution {
public:
    string reverseWords(string s) {
        istringstream iss(s);
        vector<string> words;
        string word;
        
        while (iss >> word) {
            words.push_back(word);
        }
        
        string result;
        for (int i = words.size() - 1; i >= 0; i--) {
            result += words[i];
            if (i > 0) result += " ";
        }
        
        return result;
    }
};
```

## 解法二: 原地反转法（O(1) 额外空间）
### 思路
1. 反转整个字符串。
2. 逐个反转每个单词。
3. 去除多余的空格（使用双指针重写整个字符串，跳过首尾空格并将单词间多个空格压缩为一个）。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)，原地操作（不计输出字符串）

### 代码
```cpp
class Solution {
public:
    string reverseWords(string s) {
        // 步骤1: 反转整个字符串
        reverse(s.begin(), s.end());
        
        // 步骤2+3: 反转每个单词并去除多余空格
        int idx = 0;  // 写入指针
        int n = s.size();
        
        for (int i = 0; i < n; i++) {
            if (s[i] != ' ') {
                // 如果不是第一个单词，前面加一个空格
                if (idx != 0) s[idx++] = ' ';
                
                // 将这个单词完整复制，同时反转
                int start = idx;
                while (i < n && s[i] != ' ') {
                    s[idx++] = s[i++];
                }
                reverse(s.begin() + start, s.begin() + idx);
            }
        }
        
        s.resize(idx);
        return s;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n) | O(n) | 分割单词存入 vector 后反转拼接 |
| 解法二 | O(n) | O(1) | 两次反转（整体 + 单词） + 去空格 |

解法一最简单直观，适合快速实现。解法二展示了对字符串原地操作的理解，C++ 中其实 `string` 不是原地修改（因为需要 return），但方法本身的额外空间开销是 O(1)。

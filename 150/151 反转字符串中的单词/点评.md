# 151. 反转字符串中的单词 — 代码点评

## 使用的方法
栈反转法——遍历字符串提取单词，遇到空格时将非空单词压入栈，最后依次弹出栈中单词并用空格拼接。

## 复杂度分析
- 时间复杂度: O(n)，遍历一次字符串 + 弹栈拼接
- 空间复杂度: O(n)，栈存储所有单词

## 代码评价
- 优点: 利用栈 LIFO 特性巧妙实现了单词顺序的反转，无需手动从后向前遍历；正确处理了多个连续空格的情况（`word != ""` 判断避免压入空字符串）；循环结束后再次检查剩余单词，处理了末尾无空格的情况。
- 可改进之处:
  1. 空间上可以优化为 O(1) 的原地反转法（先整体反转字符串，再分别反转每个单词并压缩空格）。
  2. 第二个循环中 `n` 变量被复用为 `words.size()`，虽然正确但可读性稍差，建议使用不同变量名如 `sz`。
  3. `if(n)` 和后面的 for 循环逻辑可以统一：使用 `while (!words.empty())` 循环弹栈拼接，并在单词间插入空格，代码更简洁。
  4. 代码中部分缩进不统一（如 `if(word != "")` 处）。
  5. main 函数中的测试数组与本题无关。
- 代码风格: 整体结构清晰，栈的使用恰当，但有缩进不一致的问题。

## 总结
> 用栈反转单词顺序的思路直观且正确，实现了 O(n) 时间复杂度的解法。可优化为 O(1) 空间的三步反转法。

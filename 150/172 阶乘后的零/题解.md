# 172. 阶乘后的零 (Factorial Trailing Zeroes)

## 题目描述

给定一个整数 `n`，返回 `n!` 结果中尾随零的数量。

**示例 1:**
```
输入: n = 3
输出: 0
解释: 3! = 6，不含尾随零。
```

**示例 2:**
```
输入: n = 5
输出: 1
解释: 5! = 120，有一个尾随零。
```

**示例 3:**
```
输入: n = 0
输出: 0
```

## 核心思路

尾随零由因子 10 产生，而 10 = 2 × 5。在 n! 的质因数分解中，因子 2 的数量总是远多于因子 5 的数量，因此尾随零的数量完全由因子 5 的数量决定。

问题转化为：计算 1 到 n 中所有数的因子 5 的总个数。

例如 n = 25：
- 5, 10, 15, 20 各贡献 1 个 5（共 4 个）
- 25 贡献 2 个 5
- 总计 4 + 2 = 6 个

公式：`count = n/5 + n/25 + n/125 + ...`

---

## 解法一：迭代法

每次计算 n / 5，然后将 n 除以 5 继续累加，直到 n < 5。

**算法步骤：**
1. 初始化 `count = 0`
2. 当 `n >= 5` 时循环：
   - `n = n / 5`
   - `count += n`
3. 返回 `count`

**复杂度分析：**
- 时间复杂度：O(log n)，每次 n 缩小为原来的 1/5
- 空间复杂度：O(1)

**C++ 代码：**
```cpp
int trailingZeroes(int n) {
    int count = 0;
    while (n >= 5) {
        n /= 5;
        count += n;
    }
    return count;
}
```

---

## 解法二：递归法

将迭代逻辑转换为递归，本质相同但写法更简洁。

**递归定义：**
- `trailingZeroes(n) = 0`，当 `n < 5`
- `trailingZeroes(n) = n/5 + trailingZeroes(n/5)`，当 `n >= 5`

**复杂度分析：**
- 时间复杂度：O(log n)
- 空间复杂度：O(log n)，递归调用栈深度

**C++ 代码：**
```cpp
int trailingZeroes(int n) {
    if (n < 5) return 0;
    return n / 5 + trailingZeroes(n / 5);
}
```

---

## 解法三：公式直接计算法

直接用 `n/5 + n/25 + n/125 + ...` 累加，用 `long long` 类型的 `power` 变量依次乘以 5。

**C++ 代码：**
```cpp
int trailingZeroes(int n) {
    int count = 0;
    long long power = 5;
    while (power <= n) {
        count += n / power;
        power *= 5;
    }
    return count;
}
```

**复杂度分析：**
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

---

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 迭代法 | O(log n) | O(1) | 最常用，简洁高效 |
| 递归法 | O(log n) | O(log n) | 写法优雅 |
| 公式直接计算法 | O(log n) | O(1) | 直观体现数学原理 |

关键洞察：**尾随零数量 = n! 中因子 5 的个数**。理解这一点后，三种实现只是形式上的差异。

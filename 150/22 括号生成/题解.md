# 22. 括号生成

## 题目描述

> 数字 `n` 代表生成括号的对数，请设计函数生成**所有**由 `n` 对括号组成的、且**有效**（每个左括号都有匹配的右括号、任意前缀中右括号数量不超过左括号）的括号组合。
> 例：`n = 3` → `["((()))", "(()())", "(())()", "()(())", "()()()"]`，共 Catalan(3) = 5 个。
> 数据范围：1 ≤ n ≤ 8。

## 解法一：暴力枚举 + 合法性校验

### 思路
一共 `2n` 个位置，每个位置要么放 `(` 要么放 `)`，枚举全部 `2^(2n)` 种串，再逐个用"计数器判合法"筛掉不合法的：从左往右扫，遇 `(` 计数 +1、遇 `)` 计数 -1，若中途计数为负（右括号多于左括号）或结束时不为 0，则非法。

枚举可以用位掩码（第 k 位为 1 表示第 k 位放右括号），也可以用递归逐位填字符。这个量级在 n ≤ 8 时是 65536 个串，完全跑得动。

### 复杂度
- 时间复杂度: O(2^(2n) · n)（枚举 4ⁿ 个串，每个校验 O(n)）
- 空间复杂度: O(n)（递归栈与临时串）

### 代码
```cpp
bool valid(const string& s) {                  // 前缀合法性检查
    int bal = 0;
    for (char ch : s) {
        bal += (ch == '(') ? 1 : -1;
        if (bal < 0) return false;             // 出现未匹配的右括号
    }
    return bal == 0;
}

void dfsAll(string& path, int n, vector<string>& res) {
    if ((int)path.size() == 2 * n) {
        if (valid(path)) res.push_back(path);
        return;
    }
    path.push_back('('); dfsAll(path, n, res); path.pop_back();
    path.push_back(')'); dfsAll(path, n, res); path.pop_back();
}

vector<string> generateParenthesis(int n) {
    vector<string> res;
    string path;
    dfsAll(path, n, res);
    return res;
}
```

## 解法二：回溯 + 剪枝（推荐）

### 思路
与其先造非法串再筛，不如**只在合法方向上生长**。递归时记录已用的左括号数 `left`、右括号数 `right`，每一步只有两种可能：

- `left < n`：还能再放一个 `(`；
- `right < left`：当前左括号比右括号多，可以放一个 `)`（保证不会出现非法前缀）。

当 `left == right == n` 时得到一个答案。这样每个递归分支都通向合法解，搜索树的叶子数恰好是 Catalan(n) = C(2n, n) / (n + 1)，比 4ⁿ 小得多（n = 8 时约 1430 个答案）。

### 复杂度
- 时间复杂度: O(C(2n, n) · n)（第 n 个 Catalan 数 × 每个答案拷贝 O(n)）
- 空间复杂度: O(n)（递归栈与路径串，不计结果集）

### 代码
```cpp
void dfs(string& path, int left, int right, int n, vector<string>& res) {
    if ((int)path.size() == 2 * n) {           // 左右括号都用完
        res.push_back(path);
        return;
    }
    if (left < n) {                            // 还能放左括号
        path.push_back('(');
        dfs(path, left + 1, right, n, res);
        path.pop_back();                       // 回溯撤销
    }
    if (right < left) {                        // 右括号数必须小于左括号数
        path.push_back(')');
        dfs(path, left, right + 1, n, res);
        path.pop_back();
    }
}

vector<string> generateParenthesis(int n) {
    vector<string> res;
    string path;
    dfs(path, 0, 0, n, res);
    return res;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 暴力枚举 + 校验 | O(4ⁿ · n) | O(n) | 好写好懂，搜索空间大 |
| 回溯 + 剪枝 | O(Catalan(n) · n) | O(n) | 标准解法，只在合法前缀上扩展 |

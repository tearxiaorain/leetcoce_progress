# 205. 同构字符串

## 题目描述
> 给定两个字符串 `s` 和 `t`，判断它们是否是同构的。如果 `s` 中的字符可以按某种映射关系替换得到 `t`，则这两个字符串是同构的。每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上（一对一映射）。

## 解法一: 双哈希表映射
### 思路
使用两个哈希表分别记录 `s -> t` 和 `t -> s` 的双向映射关系。遍历两个字符串的每个字符对 `(s[i], t[i])`：
- 如果 `s[i]` 已经映射过但映射的不是 `t[i]`，返回 false
- 如果 `t[i]` 已经被映射过但映射的不是 `s[i]`，返回 false
- 否则建立双向映射，继续遍历

两个方向的检查保证了映射的一一对应。
### 复杂度
- 时间复杂度: O(n)，其中 n 为字符串长度
- 空间复杂度: O(|Σ|)，其中 Σ 为字符集大小（ASCII 最多 256）
### 代码
```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        unordered_map<char, char> s2t, t2s;
        for (int i = 0; i < s.size(); i++) {
            char a = s[i], b = t[i];
            if (s2t.count(a) && s2t[a] != b) return false;
            if (t2s.count(b) && t2s[b] != a) return false;
            s2t[a] = b;
            t2s[b] = a;
        }
        return true;
    }
};
```

## 解法二: 双数组映射（定长数组优化）
### 思路
由于 ASCII 字符只有 256 个，可以用两个大小为 256 的整型数组代替哈希表，初始化为 0，用下标表示字符，用值表示映射关系。注意需要区分"未映射"和"映射到值为 0 的字符"，可以用 256 以外的哨兵值（如 -1）标记未映射，或用 `i+1` 避开 0 值。

或者更简单：用两个数组记录每个字符上次出现的位置。如果 `s[i]` 和 `t[i]` 上一次出现的位置不同，说明映射不一致。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1) —— 固定大小 256 的数组
### 代码
```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        int s_last[256] = {0}, t_last[256] = {0};
        for (int i = 0; i < s.size(); i++) {
            if (s_last[s[i]] != t_last[t[i]]) return false;
            s_last[s[i]] = i + 1;
            t_last[t[i]] = i + 1;
        }
        return true;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双哈希表 | O(n) | O(\|Σ\|) | 通用性强，支持 Unicode | 哈希操作有常数开销 |
| 双数组 | O(n) | O(1) | 常数级空间，速度最快 | 仅适用于 ASCII 字符集 |

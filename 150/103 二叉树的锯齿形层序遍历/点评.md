# 103. 二叉树的锯齿形层序遍历 — 代码点评
## 使用的方法
BFS 层序遍历 + `factor` 标志 + 层尾倒序反转。在 102 层序遍历基础上，用 `factor = 1 - factor` 在 0/1 间翻转标识当前层方向：`factor == 1` 时把本层结果 `r` 倒序拷贝进新数组 `rr` 再入结果，否则原序入结果，实现锯齿形。

## 复杂度分析
- 时间复杂度：O(n)，每个节点访问一次，倒序拷贝各层合计 O(n)。
- 空间复杂度：O(n)，队列保存最宽一层（空指针也入队），倒序时额外创建 `rr`，最坏 O(n)。

## 代码评价

**优点**：
- 思路正确，方向翻转逻辑（`factor` 初始 1，第一层变 0 不反转、第二层变 1 反转）能正确得到锯齿顺序。
- 用 `if (r.size())` 过滤全空层，结果不含空层。

**可改进**：
- 空指针入队（第 51-52 行未判空），队列混入大量 `nullptr`，应改为 `if (t->left) ... if (t->right) ...`。
- 倒序用新建 `vector<int> rr` 手动 `for` 倒着 push（第 60-66 行），多一次 O(层宽) 空间且啰嗦；可直接 `reverse(r.begin(), r.end())`（就地），或用 `deque` 按层选择 `push_back/push_front` 省去反转。
- `factor` 的 0/1 翻转用 `factor = 1 - factor` 可读性一般，建议 `bool leftToRight` + `leftToRight = !leftToRight`。
- 缺少 `root == nullptr` 显式处理。
- 头文件包含未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`（`<algorithm>` 里的 reverse 本可用但当前未用）。

**风格**：
- 符合 ACM 风格，`using namespace std;`。
- 变量名 `factor`、`rr`、`nn` 语义不够直观。

## 总结
> AC ✓

代码正确实现了锯齿形层序遍历，采用"BFS + 层尾倒序"思路无误，复杂度 O(n)/O(n)。主要问题是空指针入队和"新建数组倒序拷贝"带来的冗余，改用 `reverse` 或双端队列可更简洁。

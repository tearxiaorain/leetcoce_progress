# 103. 二叉树的锯齿形层序遍历
## 题目描述
> 给你二叉树的根节点 `root`，返回其节点值的 **锯齿形层序遍历**（即先从左到右，再从右到左进行下一层遍历，以此类推，层与层之间交替进行）。

## 解法一: BFS + 双端队列（按层选择插入方向）
**思路**：在 102 层序遍历的基础上，根据当前层号的奇偶决定结果插入方向。用一个 `deque<int>` 保存本层结果：偶数层（从左到右）用 `push_back`，奇数层（从右到左）用 `push_front`。仍用 `queue<TreeNode*>` 按层遍历。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(n)，队列 + 双端队列最多保存最宽一层。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> res;
        if (root == nullptr) return res;

        queue<TreeNode*> q;
        q.push(root);
        bool leftToRight = true; // 当前层方向
        while (!q.empty()) {
            int sz = q.size();
            deque<int> level;    // 用双端队列按方向插入
            for (int i = 0; i < sz; ++i) {
                TreeNode* node = q.front(); q.pop();
                if (leftToRight) level.push_back(node->val);
                else             level.push_front(node->val);
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            res.push_back(vector<int>(level.begin(), level.end()));
            leftToRight = !leftToRight;
        }
        return res;
    }
};
```

## 解法二: BFS + 层尾反转（reverse 交替）
**思路**：与 102 完全一致地逐层收集结果，遇到"从右到左"的层时对该层的 `vector` 做一次 `reverse`。实现最简单，代价是奇数层多一次 O(层宽) 的反转。

**复杂度**：
- 时间复杂度：O(n)，总反转代价 O(n)。
- 空间复杂度：O(n)。

```cpp
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> res;
        if (root == nullptr) return res;

        queue<TreeNode*> q;
        q.push(root);
        bool leftToRight = true;
        while (!q.empty()) {
            int sz = q.size();
            vector<int> level;
            for (int i = 0; i < sz; ++i) {
                TreeNode* node = q.front(); q.pop();
                level.push_back(node->val);
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            if (!leftToRight) reverse(level.begin(), level.end());
            res.push_back(level);
            leftToRight = !leftToRight;
        }
        return res;
    }
};
```

## 解法三: DFS（递归 + 层号 + 按层插入）
**思路**：递归时携带层号，偶数层 `push_back`，奇数层 `push_front`（该层的 `vector` 用 `insert(begin)` 或双端队列实现）。与 BFS 本质一致，只是遍历顺序不同。

**复杂度**：
- 时间复杂度：O(n)。
- 空间复杂度：O(h) 递归栈（最坏 O(n)）+ O(n) 结果数组。

```cpp
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> res;
        dfs(root, 0, res);
        return res;
    }

    void dfs(TreeNode* node, int depth, vector<vector<int>>& res) {
        if (node == nullptr) return;
        if (res.size() == depth) res.push_back({});
        if (depth % 2 == 0) res[depth].push_back(node->val);   // 从左到右
        else res[depth].insert(res[depth].begin(), node->val); // 从右到左
        dfs(node->left,  depth + 1, res);
        dfs(node->right, depth + 1, res);
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| BFS + 双端队列 | O(n) | O(n) | 按方向选择 push 端 |
| BFS + 层尾反转 | O(n) | O(n) | 最简洁，reverse 交替 |
| DFS + 层号 | O(n) | O(h) | 递归按层插入 |

> 推荐解法一（双端队列）或解法二（reverse）。解法二代码最省心，实际工程中可直接采用；解法一避免反转，理论常数更小。

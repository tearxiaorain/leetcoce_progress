# 45. 跳跃游戏 II

## 题目描述

> 给定一个长度为 `n` 的整数数组 `nums`。初始位置为下标 `0`，数组中每个元素表示你在该位置可以跳跃的最大长度。目标是**用最少的跳跃次数**到达最后一个下标。题目保证总是可以到达。
> 输入输出示意：`nums = [2,3,1,1,4]` → 2（`0 → 1 → 4`）；`nums = [2,3,0,1,4]` → 2。注意与 55（能否到达）不同，这里要**最少的步数**。

## 解法一: 动态规划

### 思路
`dp[i]` 表示跳到下标 `i` 的最少步数。初始 `dp[0] = 0`，其余为无穷大。对每个 `i`，若它能一步到达 `j`（`i < j ≤ i + nums[i]`），则 `dp[j] = min(dp[j], dp[i] + 1)`。由于每次转移向前扫描可达区间，代价较高。

### 复杂度
- 时间复杂度: O(n²)，最坏每格都向前扫整段
- 空间复杂度: O(n)

### 代码
```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, INT_MAX / 2);
        dp[0] = 0;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j <= i + nums[i] && j < n; ++j)
                dp[j] = min(dp[j], dp[i] + 1);
        return dp[n - 1];
    }
};
```

## 解法二: 贪心 + BFS 式"最远扩展"（O(n)）

### 思路
把跳跃次数当作层数，做隐式 BFS：第 `step` 步能到达的所有下标构成"当前层"，这一层能再往右够到的最远点就是下一层的边界。
- 维护 `curEnd` = 当前这一层能达到的最右下标，`far` = 扫描过程中不断更新的"再跨一步能到的最远点"；
- 从左向右遍历 `i`，只要 `i` 还在当前层内（`i ≤ curEnd`），就更新 `far = max(far, i + nums[i])`；
- 当 `i == curEnd` 且还没到终点，说明当前层走完了，步数 +1，并把 `curEnd` 提升为 `far`，进入下一层。

因为每步都选择"能跳得最远"的下一个位置，贪心成立（一步覆盖区间内更靠左的位置不会带来更优解）。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        int ans = 0, curEnd = 0, far = 0;
        for (int i = 0; i < n - 1; ++i) {     // 无需真正跳到最后一格后再加步
            far = max(far, i + nums[i]);
            if (i == curEnd) {                // 当前层走完，步数+1 进入下一层
                ++ans;
                curEnd = far;
            }
        }
        return ans;
    }
};
```

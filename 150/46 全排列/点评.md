# 46. 全排列 — 代码点评

## 使用的方法
DFS 回溯 + `flag` 占用标记：`fun(nums, flag, res, path, n)` 遍历所有未使用元素填入当前位，递归后 `path.pop_back()` + `flag[i]=0` 撤销；用 `f_flag` 统计"本轮是否还有未放置元素"，为 0 时说明已填满，收集排列。

## 复杂度分析
- 时间复杂度: O(n × n!)，n! 个排列，每个构造/收集 O(n)
- 空间复杂度: O(n)，递归栈 + flag + path

## 代码评价
- 优点:
  - 模板正确：标记 → 递归 → 撤销三步齐全，`n=3` 能稳定输出 6 个全排列且无重复无遗漏（样例验证通过）
  - 输出有序（字典序递增），利于肉眼对答案
- 可改进之处:
  - **终态判定绕**：用 `f_flag==0` 判断"填满"需要先扫描一轮，不如直接 `if (path.size() == n)` 直观且少一次 O(n) 扫描
  - 函数名 `fun` 无含义；`flag`（bool 语义）建议命名 `used`
  - 每次递归都从 0 重新扫 `flag`，属标准做法可接受；若想省拷贝可用**交换法**（`swap(nums[pos], nums[i])`）免去 used 数组
  - 后续做 47（含重复数字）时需加"排序 + 同层跳过相同值"去重，本模板已留好插入位置
- 代码风格: 简洁清晰，主干可读性佳

## 总结
> 排列回溯已掌握（used 标记模板），微调点：终态改 `path.size()==n`、命名规范；进阶可练交换法与含重复的去重写法。

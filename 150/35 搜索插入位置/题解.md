# 35. 搜索插入位置

## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 O(log n) 的算法。

## 解法一：二分查找

### 思路

经典二分查找变体。在有序数组中查找 target：

- 找到 target 则直接返回下标
- 没找到时，`left` 指针最终指向的位置就是 target 应该插入的位置

二分结束时，`left > right`，`left` 指向第一个大于等于 target 的位置。

### 复杂度

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

### C++ 代码

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return left; // 插入位置
    }
};
```

## 解法二：线性扫描

### 思路

遍历数组，找到第一个 >= target 的元素，返回其下标。若遍历完都没找到，则插入到末尾。

虽然 O(log n) 是题目要求，但线性扫描作为最直观的解法值得理解。适合面试中先给出暴力解再优化。

### 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(1)

### C++ 代码

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] >= target) return i;
        }
        return nums.size();
    }
};
```

---

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心技巧 |
|------|-----------|-----------|---------|
| 二分查找 | O(log n) | O(1) | 标准二分，left 即插入位置 |
| 线性扫描 | O(n) | O(1) | 暴力遍历，直观但非最优 |

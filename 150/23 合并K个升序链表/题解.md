# 23. 合并K个升序链表

## 题目描述

> 给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。
> 输入输出示意：`lists = [[1,4,5],[1,3,4],[2,6]]` → `[1,1,2,3,4,4,5,6]`；空数组或全空链表返回空。记共有 `k` 条链表、总节点数 `N`。

## 解法一: 顺序两两合并（暴力）

### 思路
先以空链表为初始结果，然后逐一用"合并两个升序链表"（21 题的双指针归并）把每条链表并入结果。每并入一条都要扫一遍当前结果，代价随结果增长。

### 复杂度
- 时间复杂度: O(k²·L)（L 为平均链长），前 i 条合并需扫 O(i·L) 个节点，累加接近 O(k²L)
- 空间复杂度: O(1)，仅指针（新建节点则 O(N)）

### 代码
```cpp
class Solution {
public:
    ListNode* mergeTwo(ListNode* a, ListNode* b) {
        ListNode dummy(0), *tail = &dummy;
        while (a && b) {
            if (a->val <= b->val) { tail->next = a; a = a->next; }
            else { tail->next = b; b = b->next; }
            tail = tail->next;
        }
        tail->next = a ? a : b;
        return dummy.next;
    }

    ListNode* mergeKLists(vector<ListNode*>& lists) {
        ListNode* res = nullptr;
        for (auto* h : lists) res = mergeTwo(res, h);   // 顺序合并
        return res;
    }
};
```

## 解法二: 优先队列每次取最小头（O(N log k)）

### 思路
与"多路归并"同理：把 `k` 条链表的当前头结点放进一个**最小堆**，每次弹出值最小的节点接到结果尾部，再把它所在链表的下一个节点压入堆。重复直到堆空。因为每个节点都恰好入堆出堆一次，堆大小 ≤ k。

### 复杂度
- 时间复杂度: O(N log k)，N 个节点 × 每次堆操作 O(log k)
- 空间复杂度: O(k)，堆中最多 k 个节点

### 代码
```cpp
class Solution {
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        auto cmp = [](ListNode* a, ListNode* b) { return a->val > b->val; };
        priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> pq(cmp);
        for (auto* h : lists) if (h) pq.push(h);

        ListNode dummy(0), *tail = &dummy;
        while (!pq.empty()) {
            auto* cur = pq.top(); pq.pop();
            tail->next = cur; tail = cur;
            if (cur->next) pq.push(cur->next);
        }
        return dummy.next;
    }
};
```

> 变体：**分治合并**——把链表数组对半切分，递归合并左右两半后再 mergeTwo。复杂度同为 O(N log k)，但空间 O(log k) 栈且不依赖堆，代码同样简洁。

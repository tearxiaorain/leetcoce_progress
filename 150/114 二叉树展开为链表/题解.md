# 114. 二叉树展开为链表
## 题目描述
> 给你二叉树的根结点 `root`，请你将它展开为一个单链表：
> - 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`；
> - 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

## 解法一: 前序遍历 + 重建链表（借助数组）
**思路**：先对原树做一次前序遍历，把所有节点按顺序存入数组 `nodes`，再从头到尾把每个节点的 `left` 置空、`right` 指向下一个节点。实现直观，但需要 O(n) 额外空间。

**复杂度**：
- 时间复杂度：O(n)，两次遍历（收集 + 重建）。
- 空间复杂度：O(n)，数组保存全部节点；递归栈 O(h)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void flatten(TreeNode* root) {
        vector<TreeNode*> nodes;
        preorder(root, nodes);
        for (int i = 0; i + 1 < (int)nodes.size(); ++i) {
            nodes[i]->left = nullptr;
            nodes[i]->right = nodes[i + 1];
        }
    }

    void preorder(TreeNode* node, vector<TreeNode*>& nodes) {
        if (node == nullptr) return;
        nodes.push_back(node);
        preorder(node->left,  nodes);
        preorder(node->right, nodes);
    }
};
```

## 解法二: 原地展开（寻找前驱节点）
**思路**：对每个节点 `cur`，若它有左子树：
1. 找到左子树中的 **最右节点** `pre`（即左子树先序遍历的最后一个节点，也即"前驱"）；
2. 把 `cur` 的右子树整体挂到 `pre->right`；
3. 令 `cur->right = cur->left`，`cur->left = nullptr`；
4. `cur = cur->right` 继续向右推进。

这样每个节点最多被访问两次（找最右 + 推进），无需额外空间。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问常数次。
- 空间复杂度：O(1)，原地修改。

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur = root;
        while (cur != nullptr) {
            if (cur->left != nullptr) {
                // 找左子树的最右节点（先序前驱）
                TreeNode* pre = cur->left;
                while (pre->right != nullptr) pre = pre->right;
                // 右子树接到前驱的 right
                pre->right = cur->right;
                // 左子树搬到 right，左置空
                cur->right = cur->left;
                cur->left = nullptr;
            }
            cur = cur->right;
        }
    }
};
```

## 解法三: 后序遍历（递归逆序连接）
**思路**：按 **右 → 左 → 根** 的逆后序顺序遍历，维护全局 `prev` 指针指向"已经展开完成的链表头"。访问当前节点时，令其 `right = prev`、`left = nullptr`，再更新 `prev = 当前节点`。这样递归返回时链表自然接好，实现非常简洁。

**复杂度**：
- 时间复杂度：O(n)。
- 空间复杂度：O(h)，递归栈深度，最坏 O(n)。

```cpp
class Solution {
public:
    TreeNode* prev = nullptr; // 已展开部分的表头

    void flatten(TreeNode* root) {
        if (root == nullptr) return;
        flatten(root->right); // 逆后序：先右
        flatten(root->left);  // 再左
        root->right = prev;   // 接上已展开部分
        root->left = nullptr;
        prev = root;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 前序遍历 + 数组 | O(n) | O(n) | 直观，需额外数组 |
| 原地展开（前驱） | O(n) | O(1) | 迭代原地，空间最优 |
| 后序递归逆接 | O(n) | O(h) | 代码简洁 |

> 推荐解法二（原地展开），O(1) 空间最优，是本题的标准解法。解法一最容易想到，解法三最简洁，但都需 O(n)/O(h) 额外空间。

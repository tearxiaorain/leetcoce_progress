# 114. 二叉树展开为链表 — 代码点评
## 使用的方法
前序遍历收集 + 重建链表。先用 `preorder` 递归把整棵树按先序遍历顺序收集到 `vector<TreeNode*> arr`，再遍历 `arr`，把每个节点的 `left` 置空、`right` 指向下一个节点，最后一个节点的 `left`/`right` 均置空。

## 复杂度分析
- 时间复杂度：O(n)，先序遍历访问每个节点一次，重建再遍历一次，总计 O(n)。
- 空间复杂度：O(n)，`arr` 保存全部 n 个节点，递归栈深度 O(h)，综合 O(n)。

## 代码评价

**优点**：
- 思路直观正确，先序收集再重建，符合"展开后等于先序顺序"的定义。
- 边界处理完整：`if(!root) return;` 处理空树；第 55-56 行显式把最后一个节点的 `left`/`right` 都置空，避免残留指针。

**可改进**：
- 需 O(n) 额外数组空间，本题有 O(1) 的原地解法（迭代找"左子树最右节点"作为前驱，把右子树挂过去）或 O(h) 的后序逆接递归，空间更优。
- 递归 `preorder` 对极深（链状）树可能爆栈，可用显式栈做迭代先序。
- `preorder` 可改为返回数组的写法，或直接在 `flatten` 里维护一个 `prev` 指针边遍历边连接，省去第二次循环。
- 头文件包含未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`（实际用到 `<iostream>`、`<vector>`）。

**风格**：
- 符合 ACM 风格，`using namespace std;`。
- 变量名 `arr`、`n` 简洁明了。

代码正确实现了二叉树展开为链表，采用"先序遍历 + 数组重建"的直观解法，复杂度 O(n)/O(n)。思路无误、边界处理到位，主要不足是 O(n) 额外空间，进阶可改为 O(1) 的原地展开（前驱法）。

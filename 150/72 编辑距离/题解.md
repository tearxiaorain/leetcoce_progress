# 72. 编辑距离

## 题目描述

> 给定两个单词 `word1` 和 `word2`，返回把 `word1` 转换成 `word2` 所使用的**最少操作数**。每次操作可以：插入一个字符、删除一个字符、替换一个字符。
> 例：`word1 = "horse", word2 = "ros"` → `3`（horse → rorse(替换) → rose(删除) → ros(删除)）。
> 数据范围：0 ≤ 长度 ≤ 500。

## 解法一：记忆化递归（自顶向下）

### 思路
定义 `f(i, j)` = 把 `word1` 的前 `i` 个字符变成 `word2` 的前 `j` 个字符所需的最少操作数，考虑两串的**最后一个字符**：

- `word1[i-1] == word2[j-1]`：最后一位已经匹配，问题缩小为 `f(i-1, j-1)`；
- 否则在三种操作里选最优：
  - **替换**：把 `word1[i-1]` 换成 `word2[j-1]`，代价 `1 + f(i-1, j-1)`；
  - **删除**：删掉 `word1[i-1]`，代价 `1 + f(i-1, j)`；
  - **插入**：在 `word1` 末尾插入 `word2[j-1]`，代价 `1 + f(i, j-1)`。

边界：`f(i, 0) = i`（删光），`f(0, j) = j`（逐个插入）。

直接用递归会重复计算大量子问题，加一张 `memo` 表把算过的状态存下来即可。状态是 (i, j) 共 m·n 个，每个 O(1) 转移。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(m·n)（记忆表 + 递归栈 O(m + n)）

### 代码
```cpp
int m, n;
vector<vector<int>> memo;

int dp(string& w1, string& w2, int i, int j) {
    if (i == 0) return j;                        // w1 空：插入 j 个字符
    if (j == 0) return i;                        // w2 空：删除 i 个字符
    if (memo[i][j] != -1) return memo[i][j];
    if (w1[i - 1] == w2[j - 1])
        return memo[i][j] = dp(w1, w2, i - 1, j - 1);   // 末位相同，无需操作
    int del = dp(w1, w2, i - 1, j);              // 删除 w1[i-1]
    int ins = dp(w1, w2, i, j - 1);              // 插入 w2[j-1]
    int rep = dp(w1, w2, i - 1, j - 1);          // 替换 w1[i-1]
    return memo[i][j] = 1 + min({del, ins, rep});
}

int minDistance(string word1, string word2) {
    m = word1.size(); n = word2.size();
    memo.assign(m + 1, vector<int>(n + 1, -1));
    return dp(word1, word2, m, n);
}
```

## 解法二：二维 DP（自底向上）

### 思路
把上面的递推改成表：`dp[i][j]` 表示 `word1` 前 `i` 个字符转成 `word2` 前 `j` 个字符的最少操作数。

初始化第 0 行、第 0 列（`dp[i][0] = i`、`dp[0][j] = j`），然后按行（或按列）填写：

```
dp[i][j] = dp[i-1][j-1]                                  // w1[i-1] == w2[j-1]
dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) // 否则
```

三个来源正是删除、插入、替换，语义和记忆化版本完全一致，好处是没有递归栈、常数更小。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(m·n)

### 代码
```cpp
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 0; i <= m; i++) dp[i][0] = i;   // 第 0 列：全删除
    for (int j = 0; j <= n; j++) dp[0][j] = j;   // 第 0 行：全插入
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1[i - 1] == word2[j - 1])
                dp[i][j] = dp[i - 1][j - 1];     // 末位相同，直接继承
            else
                dp[i][j] = 1 + min({dp[i - 1][j],     // 删除
                                    dp[i][j - 1],     // 插入
                                    dp[i - 1][j - 1]}); // 替换
        }
    }
    return dp[m][n];
}
```

## 解法三：一维滚动数组

### 思路
观察转移只用到「上一行 `dp[i-1][*]`」和「本行左边一格 `dp[i][j-1]`」，所以可以把二维表压成一维：用 `dp[j]` 表示当前行的状态，遍历 `j` 时 `dp[j]` 还存着上一行的值，`dp[j-1]` 已被更新为本行的值。

关键是替换项 `dp[i-1][j-1]` 会被本行的新值覆盖，所以要先用变量 `prev` 把左上角（上一行的 `dp[j-1]`）暂存下来。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(n)

### 代码
```cpp
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<int> dp(n + 1);
    for (int j = 0; j <= n; j++) dp[j] = j;      // 相当于第 0 行
    for (int i = 1; i <= m; i++) {
        int prev = dp[0];                        // 左上角：上一行的 dp[i-1][0]
        dp[0] = i;                               // 本行的 dp[i][0]
        for (int j = 1; j <= n; j++) {
            int tmp = dp[j];                     // 保存上一行的 dp[i-1][j]
            if (word1[i - 1] == word2[j - 1])
                dp[j] = prev;                    // 末位相同
            else
                dp[j] = 1 + min({dp[j],          // dp[i-1][j] 删除
                                 dp[j - 1],      // dp[i][j-1] 插入
                                 prev});         // dp[i-1][j-1] 替换
            prev = tmp;                          // 为下一列准备左上角
        }
    }
    return dp[n];
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 记忆化递归 | O(m·n) | O(m·n) | 思路顺着"最后一位"展开，最好理解 |
| 二维 DP | O(m·n) | O(m·n) | 标准写法，模板题 |
| 一维滚动 | O(m·n) | O(n) | 空间最优，注意暂存左上角 |

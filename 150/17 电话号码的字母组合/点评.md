# 17. 电话号码的字母组合 — 代码点评

## 使用的方法
DFS 回溯：递归参数 `k` 表示当前处理到第几位数字，命中 `k==n` 时把 `path` 里的字符拼成字符串收集；映射表用 `vector<vector<char>>`，按下标 `digit-1` 访问（`d_s[0]` 为占位空表）。

## 复杂度分析
- 时间复杂度: O(3ⁿ·4ᵐ · n)，组合总数 3ⁿ4ᵐ（n=3字母数字个数、m=4字母数字个数），每片叶子还要 O(n) 拼串
- 空间复杂度: O(n)，递归深度 + path（不含答案）

## 代码评价
- 优点:
  - 回溯"压栈→递归→弹栈"的顺序正确，`path.pop_back()` 撤销到位，主路径（如输入 `"6"`）输出正常
  - 建表下标技巧 `d_s[c-1]` 思路自洽，避免了 hash
- 可改进之处:
  - ⚠️ **边界 bug：空输入 `digits=""` 会返回 `[""]`，而题意应返回 `[]`**。因为 `k=0, n=0` 时直接进 `else` 收集了空串。需在入口 `if(digits.empty()) return {};`
  - `d_s` 每层递归**按值传递**，会反复整表拷贝，应改为 `const vector<vector<char>>&` 或全局/成员变量
  - 映射表可改成更省的 `vector<string> mp={"","","abc",...}`，用 `mp[d-'0']` 一次到位，少一层 vector<char> 的嵌套构造
  - 末尾 `vector<int> flag(n,0)` 声明后从未使用，可删
- 代码风格: 逐字手敲建表非常冗长易错（如 `t.push_back('s')`、`t.push_back('z')` 这种差异分支），换字符串数组后近乎零成本

## 总结
> 回溯骨架没问题，重点是**修掉空输入边界**（返回 `[""]` 会挂隐藏用例）并把映射表改成 const 引用 + 字符串数组。
> AC ✓（主路径通过；注意修正空输入）

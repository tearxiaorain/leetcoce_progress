# 17. 电话号码的字母组合

## 题目描述

> 给定一个仅含数字 `2-9` 的字符串 `digits`，返回它能表示的所有字母组合。答案可以按任意顺序返回。
> 每个数字对应手机九宫格上的字母（与电话按键相同）：
> `2→abc, 3→def, 4→ghi, 5→jkl, 6→mno, 7→pqrs, 8→tuv, 9→wxyz`。
> 示例：`digits = "23"` → `["ad","ae","af","bd","be","bf","cd","ce","cf"]`

本质是一个**多路选择排列**问题：每一位数字选择它对应的多个字母之一，穷举所有组合。数字有 8 个（不含 0/1），`digits` 为空时返回空数组。

## 解法一：回溯 / DFS（递归）

### 思路

递归树：第 `i` 层对应第 `i` 位数字，枚举它映射的每个字母，拼进当前路径 `path`，走到叶子（`i == digits.size()`）时收集答案，然后**撤销上一步选择**（回溯）继续试下一种。

- 需要一个数字→字符串的映射表
- `path` 用字符串累加/删除来维护，避免拷贝

### 复杂度
- 时间复杂度: O(3ⁿ × 4ᵐ)，n = 映射 3 字母的数字个数，m = 映射 4 字母的数字个数，即所有组合总数
- 空间复杂度: O(n)，递归栈深度 + 答案本身不计

### 代码
```cpp
class Solution {
    vector<string> mp = {"", "", "abc", "def", "ghi", "jkl",
                         "mno", "pqrs", "tuv", "wxyz"};
public:
    void dfs(const string& d, int i, string& path, vector<string>& res) {
        if (i == d.size()) { res.push_back(path); return; }
        for (char c : mp[d[i] - '0']) {   // 枚举第 i 位数字的每个字母
            path.push_back(c);
            dfs(d, i + 1, path, res);
            path.pop_back();              // 回溯：撤销选择
        }
    }
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        vector<string> res;
        string path;
        dfs(digits, 0, path, res);
        return res;
    }
};
```

## 解法二：BFS / 队列迭代（自底向上构造）

### 思路

用队列维护"已处理完前若干位"得到的全部前缀，每次读入一个新数字，就把队列里的每个前缀**逐个弹出并拼接该数字的每个字母**，重新入队。

以 `"23"` 为例：初始 `[""]` → 处理 `'2'` 得 `["a","b","c"]` → 处理 `'3'` 把每个前缀 ×3 得 9 个结果。省去显式递归，思路类似"逐层展开"。

### 复杂度
- 时间复杂度: O(3ⁿ × 4ᵐ)，同上（每个中间前缀都被展开一次）
- 空间复杂度: O(3ⁿ × 4ᵐ)，队列中最多存所有前缀

### 代码
```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        vector<string> mp = {"", "", "abc", "def", "ghi", "jkl",
                             "mno", "pqrs", "tuv", "wxyz"};
        queue<string> q;
        q.push("");
        for (char d : digits) {
            int sz = q.size();
            while (sz--) {                // 只处理当前这一层
                string pre = q.front(); q.pop();
                for (char c : mp[d - '0'])
                    q.push(pre + c);
            }
        }
        vector<string> res;
        while (!q.empty()) { res.push_back(q.front()); q.pop(); }
        return res;
    }
};
```

## 总结

- 数字/字母/括号等"多选一穷举"问题，**回溯模板**通用性强：选择 → 递归 → 撤销。
- 每个位置可选字符数不同（3 或 4），复杂度写成 `O(3ⁿ·4ᵐ)` 更严谨。
- `digits` 为空要返回 `[]`，不是 `[""]`——是常见边界坑。

# 141. 环形链表

## 题目描述
> 给定一个链表的头节点 head，判断链表中是否有环。如果链表中存在环，则返回 true；否则返回 false。

## 解法一: 哈希表法
### 思路
遍历链表，使用哈希集合存储已访问过的节点。如果遇到一个节点已经在集合中，说明有环；如果遍历到 nullptr（链表末尾），说明无环。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)，需要存储所有节点

### 代码
```cpp
class Solution {
public:
    bool hasCycle(ListNode *head) {
        unordered_set<ListNode*> visited;
        
        while (head != nullptr) {
            if (visited.count(head)) {
                return true;
            }
            visited.insert(head);
            head = head->next;
        }
        
        return false;
    }
};
```

## 解法二: 快慢指针法（Floyd 判圈算法）
### 思路
使用两个指针 `slow` 和 `fast`，`slow` 每次移动一步，`fast` 每次移动两步：
- 如果链表中没有环，`fast` 会先到达 nullptr。
- 如果链表中有环，`fast` 和 `slow` 最终会在环内相遇（因为 `fast` 比 `slow` 快，相对速度为一格，必定追及）。

### 复杂度
- 时间复杂度: O(n)，slow 最多走 n 步
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode *slow = head;
        ListNode *fast = head;
        
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            
            if (slow == fast) {
                return true;
            }
        }
        
        return false;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n) | O(n) | 哈希表记录已访问节点 |
| 解法二 | O(n) | O(1) | 快慢指针（龟兔赛跑） |

Floyd 判圈算法是链表环检测的经典解法，充分利用了快慢指针在环形结构中的追及特性。务必在 while 条件中检查 `fast` 和 `fast->next` 都不为 nullptr，防止空指针解引用。

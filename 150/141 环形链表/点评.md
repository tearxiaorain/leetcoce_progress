# 141. 环形链表 — 代码点评

## 使用的方法
快慢指针法（Floyd 判圈算法），慢指针 `n1` 每次移动一步，快指针 `n2` 每次移动两步，通过逐步推进并检查每步是否为空来实现。

## 复杂度分析
- 时间复杂度: O(n)，慢指针最多遍历整个链表
- 空间复杂度: O(1)，只使用两个额外指针

## 代码评价
- 优点: 使用了最优的 Floyd 判圈算法，O(1) 空间复杂度，时间复杂度 O(n)；快指针移动时逐步检查空指针，避免了越界访问。
- 可改进之处:
  1. 循环前的两个早期 null 检查可以合并到循环条件中，使代码更简洁：`while (fast != nullptr && fast->next != nullptr)`。
  2. 快指针的移动分为两步（`n2=n2->next` 两次），可在中间检查 null，这是安全写法，但可以合并写为一行再整体检查。
  3. ListNode 结构体中使用了 C 风格的 `NULL`，应统一为 C++ 的 `nullptr`。
  4. main 函数中的测试代码与环形链表完全无关（逆波兰表达式相关），应更换为环形链表测试用例。
- 代码风格: 变量名 `n1`/`n2` 虽有注释可理解，但建议改为更具描述性的 `slow`/`fast`；无用的头文件较多（`<vector>`, `<stack>`, `<map>`, `<set>`, `<string>`）。

## 总结
> Floyd 判圈算法实现正确，O(1) 空间 + O(n) 时间已达最优。代码可简化循环前的冗余判断。

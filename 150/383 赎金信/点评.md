# 383. 赎金信 — 代码点评

## 使用的方法
用户使用**排序 + 双指针匹配法**：将两个字符串分别排序，然后使用双指针在 magazine 中寻找 ransomNote 的每个字符，用 `count` 记录成功匹配的字符数。

## 复杂度分析
- 时间复杂度: O(n log n + m log m) —— 排序为主要开销，双指针遍历为 O(n + m)
- 空间复杂度: O(log n + log m) —— 排序的递归栈空间（C++ sort），额外复制了两个字符串 O(n + m)

## 代码评价
- 优点: 逻辑正确，排序后双指针匹配是解决此类问题的通用方法；`ind2 >= n2` 的提前 break 避免了越界
- 可改进之处: 时间复杂度 O(n log n) 不如数组计数法的 O(n)；创建 `s1`/`s2` 副本不必要（题目参数按值传递，可直接操作）；可以用 `ind1 == n1` 直接判断而无需额外维护 `count` 变量；变量声明 `int ind1,ind2,count;` 建议分别初始化；`s1`/`s2` 命名不够达意
- 代码风格: 排序—双指针结构清晰，但存在冗余副本和不必要的 count 变量

## 总结
> 排序+双指针方法通用且正确，但对于仅含小写字母的场景，数组计数法更优。

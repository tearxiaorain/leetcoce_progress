# 383. 赎金信

## 题目描述
> 给定两个字符串 `ransomNote` 和 `magazine`，判断 `ransomNote` 能否由 `magazine` 中的字符构成。`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。字符串只包含小写字母。

## 解法一: 哈希表/数组计数法
### 思路
由于只有 26 个小写字母，使用一个长度为 26 的整型数组统计 `magazine` 中每个字母的出现次数。然后遍历 `ransomNote`，将对应字母的计数减 1，如果某个字母计数变为负数，说明 `magazine` 中该字母不足，返回 false。

### 复杂度
- 时间复杂度: O(n + m)，分别遍历 magazine 和 ransomNote
- 空间复杂度: O(1)，固定大小 26 的数组
### 代码
```cpp
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        int count[26] = {0};
        for (char c : magazine) {
            count[c - 'a']++;
        }
        for (char c : ransomNote) {
            count[c - 'a']--;
            if (count[c - 'a'] < 0) return false;
        }
        return true;
    }
};
```

## 解法二: 排序 + 双指针
### 思路
将两个字符串分别排序，然后用双指针在 `magazine` 中匹配 `ransomNote` 的字符。对于 `ransomNote` 中的每个字符，在 `magazine` 中寻找相同字符并使用。

### 复杂度
- 时间复杂度: O(n log n + m log m)，排序为主
- 空间复杂度: O(n + m) 或 O(log n + log m)，取决于排序算法的栈空间
### 代码
```cpp
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        sort(ransomNote.begin(), ransomNote.end());
        sort(magazine.begin(), magazine.end());
        int i = 0, j = 0;
        while (i < ransomNote.size() && j < magazine.size()) {
            if (ransomNote[i] == magazine[j]) {
                i++;
                j++;
            } else if (ransomNote[i] > magazine[j]) {
                j++;
            } else {
                return false; // magazine 当前字符更大，无法匹配
            }
        }
        return i == ransomNote.size();
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 数组计数 | O(n+m) | O(1) | 线性时间，空间最优 | 仅适用小写字母 |
| 排序+双指针 | O(n log n + m log m) | O(log n + log m) | 通用，支持任意字符 | 效率较低，修改了输入 |

# 34. 在排序数组中查找元素的第一个和最后一个位置

## 题目描述

> 给定一个按**非递减**顺序排列的整数数组 `nums` 和一个目标值 `target`，找出 `target` 在数组中出现的**起始位置和结束位置**。若不存在，返回 `[-1, -1]`。
> 例：`nums = [5,7,7,8,8,10], target = 8` → `[3,4]`；`target = 6` → `[-1,-1]`。
> 要求算法的时间复杂度为 O(log n)。

## 解法一：线性扫描

### 思路
从左到右扫一遍，第一次遇到 `target` 记录起点，最后一次遇到时更新终点。写法简单，也是判断"题做对了没"的对照实现，但不满足题目 O(log n) 的要求。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
vector<int> searchRange(vector<int>& nums, int target) {
    int first = -1, last = -1;
    for (int i = 0; i < (int)nums.size(); i++) {
        if (nums[i] == target) {
            if (first == -1) first = i;        // 只记录第一次
            last = i;                          // 一直更新最后一次
        }
    }
    return {first, last};
}
```

## 解法二：两次二分（推荐）

### 思路
排序 + O(log n) → 二分。这里要的不是"找到任意一个 target"，而是**左右边界**，所以拆成两个独立的二分：

1. **左边界**：在 `[l, r]` 上二分，只要 `nums[mid] >= target` 就继续往左找（`r = mid`），否则 `l = mid + 1`。循环结束时 `l` 是第一个 ≥ target 的位置，即 `lower_bound`；
2. **右边界**：只要 `nums[mid] <= target` 就继续往右找（`l = mid + 1`），否则 `r = mid`。循环结束时 `l` 是第一个 > target 的位置，右边界就是 `l - 1`。

两个二分都是"闭区间 + 单点收敛"的写法：`while (l < r)`，每次保证答案仍在 `[l, r]` 内。最后校验 `nums[左] == target`，不成立说明 target 不存在。二分过程中若整段已经不可能含 target（例如 `nums[l] > target` 或 `nums[r] < target`），也可以提前返回，但用循环内判断更简洁。

### 复杂度
- 时间复杂度: O(log n)（两次二分）
- 空间复杂度: O(1)

### 代码
```cpp
int lowerBound(vector<int>& nums, int target) {   // 第一个 >= target 的下标
    int l = 0, r = nums.size();                   // 左闭右开，答案可能是 n
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] >= target) r = mid;         // mid 可能是答案，保留
        else l = mid + 1;
    }
    return l;
}

int upperBound(vector<int>& nums, int target) {   // 第一个 > target 的下标
    int l = 0, r = nums.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] <= target) l = mid + 1;
        else r = mid;
    }
    return l;
}

vector<int> searchRange(vector<int>& nums, int target) {
    int first = lowerBound(nums, target);
    if (first == (int)nums.size() || nums[first] != target) return {-1, -1};
    int last = upperBound(nums, target) - 1;      // 第一个 > target 的前一位
    return {first, last};
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 线性扫描 | O(n) | O(1) | 简单直观，不满足题意复杂度要求 |
| 两次二分 | O(log n) | O(1) | 标准解法，可直接复用 `lower_bound` / `upper_bound` 模板 |

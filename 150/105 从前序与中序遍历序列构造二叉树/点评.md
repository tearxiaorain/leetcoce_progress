# 105. 从前序与中序遍历序列构造二叉树 — 代码点评
## 使用的方法
递归 + 拷贝子数组。取前序首元素作根，在中序序列中线性扫描定位根下标 root_index；用 root_index 同时切分前序与中序，分别拷贝出左、右子树的四个子数组（lpre/lin/rpre/rin），再递归构造左右子树。

## 复杂度分析（用户代码）
- 时间复杂度：O(n²)。每个节点都要线性扫描一次中序区间定位根，且递归每一层都拷贝子数组；最坏情况（链状树）下总工作量约 n + (n-1) + … + 1 = O(n²)。
- 空间复杂度：O(n²)。递归栈深度最坏为 O(n)，且每层都新建 4 个 vector 保存子数组拷贝；链状树时沿递归路径的子数组总长度为 O(n²)。

## 代码评价

**优点**：
- 分割思路正确：利用「前序首元素是根 + 中序根位置 = 左子树长度」这一性质，同时切分两个序列，样例 `[3,9,20,15,7]` / `[9,3,15,20,7]` 能正确构造。
- `lpre.push_back(preorder[i+1])` 与 `rpre.push_back(preorder[i])` 的下标技巧巧妙且正确——左子树前序恰好占 `preorder[1..root_index]`，右子树前序占 `preorder[root_index+1..end]`。
- `if (!preorder.size())` 正确兜住空树递归终止条件，单节点、空左右子树等边界均能正确处理。

**可改进**：
- 每层递归都新建 4 个 vector 做子数组拷贝，且每次都线性扫描定位根，导致 O(n²) 时间 + O(n²) 空间，效率偏低。
- 可用 `unordered_map<int,int>` 提前记录「值 → 下标」，把定位根降到 O(1)，并改用「区间下标」而非拷贝子数组，从而降到 O(n) 时间、O(n) 空间（标准最优解）。
- 函数签名建议直接返回 `TreeNode*`，`vr` 变量可省去，直接复用 `preorder[0]`。
- 头文件包含了一些未使用的 `<stack>`、`<queue>`、`<map>`、`<set>`、`<string>`、`<algorithm>`。

**风格**：
- 变量命名（lpre/lin/rpre/rin）能对应左右子树的前序/中序，意图清楚。
- 拷贝子数组的写法可读性好，但作为工程实现应避免频繁堆分配。

## 总结
> AC ✓

代码逻辑正确，能完成构造任务，属于「递归 + 拷贝子数组」的基础写法。主要不足是时间与空间都退化到 O(n²)，建议改用哈希表 + 下标区间切分，即标准 O(n) 解法。

# 242. 有效的字母异位词 — 代码点评

## 使用的方法
用户使用**排序比较法**：将两个字符串分别排序，然后逐字符比较是否相等。同时包含了长度不相等的提前返回优化。

## 复杂度分析
- 时间复杂度: O(n log n) —— 排序为主要开销
- 空间复杂度: O(log n) —— 排序的递归栈空间（C++ sort 为内省排序）

## 代码评价
- 优点: 思路正确，排序后直接比较是最直观的解法；长度不等时提前返回避免了无效排序
- 可改进之处: 排序后逐字符比较不如直接 `return s == t;` 简洁；时间复杂度 O(n log n) 不如数组计数法的 O(n)；main 函数中调用了 `wordPattern` 而非 `isAnagram`，疑似复制粘贴错误；使用了 `flag` 变量做标记，不如直接 return false/true 更清晰
- 代码风格: 代码结构尚可，但 `flag` 模式略显啰嗦；空行控制不一致

## 总结
> 排序法正确有效，但线性计数法在时间和空间上都更优；main 函数调用名有误。

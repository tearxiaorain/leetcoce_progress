# 242. 有效的字母异位词

## 题目描述
> 给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。字母异位词是指由相同的字母按照不同的顺序排列而成的单词。假设字符串只包含小写字母。

## 解法一: 排序比较法
### 思路
将两个字符串分别排序，然后比较排序后的结果是否相等。如果相等则为字母异位词。

### 复杂度
- 时间复杂度: O(n log n)，排序的复杂度
- 空间复杂度: O(n) 或 O(log n)，取决于排序算法和语言实现（C++ sort 需要 O(log n) 栈空间）
### 代码
```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        sort(s.begin(), s.end());
        sort(t.begin(), t.end());
        return s == t;
    }
};
```

## 解法二: 哈希表/数组计数法
### 思路
由于只包含小写字母（26 个），使用一个长度为 26 的整型数组记录每个字母的出现次数。遍历 `s` 时计数加 1，遍历 `t` 时计数减 1。最后检查数组中所有元素是否都为 0。

### 复杂度
- 时间复杂度: O(n)，遍历两个字符串各一次
- 空间复杂度: O(1) —— 固定大小 26 的数组
### 代码
```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        int count[26] = {0};
        for (char c : s) count[c - 'a']++;
        for (char c : t) count[c - 'a']--;
        for (int i = 0; i < 26; i++) {
            if (count[i] != 0) return false;
        }
        return true;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 排序比较 | O(n log n) | O(log n) | 代码极简，一行核心逻辑 | 修改了输入，效率较低 |
| 数组计数 | O(n) | O(1) | 线性时间，不修改输入 | 仅适用小写字母场景 |

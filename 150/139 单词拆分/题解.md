# 139. 单词拆分
## 题目描述
> 给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。注意：字典中的同一个单词可能在拼接中被重复使用。

## 解法一: 暴力回溯
**思路**：从字符串开头开始，尝试匹配 wordDict 中的每个单词，如果某个单词匹配上当前前缀，则递归处理剩余子串。若最终能刚好拼接完成则返回 true。

**复杂度**：
- 时间复杂度：O(2^n)，最坏情况下每个字符位置都有"取/不取"的分支（如 s = "aaaaa"，dict = {"a", "aa", …}）。
- 空间复杂度：O(n)，递归栈最深为字符串长度。

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        return dfs(s, 0, dict);
    }
    
    bool dfs(string& s, int start, unordered_set<string>& dict) {
        if (start == s.size()) return true;
        for (int end = start + 1; end <= s.size(); end++) {
            string prefix = s.substr(start, end - start);
            if (dict.count(prefix) && dfs(s, end, dict)) {
                return true;
            }
        }
        return false;
    }
};
```

## 解法二: 记忆化搜索
**思路**：在回溯的基础上添加 memo 数组，`memo[i]` 记录从位置 i 开始的子串是否能被拆分，-1 表示未计算，0 表示不能，1 表示能。

**复杂度**：
- 时间复杂度：O(n^2)，每个 start 位置处理一次，每次最多尝试 O(n) 个 end。
- 空间复杂度：O(n)，memo 数组 + 递归栈。

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        vector<int> memo(s.size(), -1);
        return dfs(s, 0, dict, memo);
    }
    
    bool dfs(string& s, int start, unordered_set<string>& dict, vector<int>& memo) {
        if (start == s.size()) return true;
        if (memo[start] != -1) return memo[start];
        for (int end = start + 1; end <= s.size(); end++) {
            string prefix = s.substr(start, end - start);
            if (dict.count(prefix) && dfs(s, end, dict, memo)) {
                memo[start] = 1;
                return true;
            }
        }
        memo[start] = 0;
        return false;
    }
};
```

## 解法三: 动态规划
**状态定义**：`dp[i]` 表示字符串 s 的前 i 个字符（即 `s[0..i-1]`）是否可以被字典中的单词拆分。

**转移方程**：
> `dp[i] = dp[j] AND s[j..i-1] in wordDict`（对某个 `0 <= j < i`）

解释：如果前 j 个字符可拆分，且子串 `s[j..i-1]` 是字典中的单词，则前 i 个字符也可拆分。

**初始化**：`dp[0] = true`（空字符串视为可拆分）。

**复杂度**：
- 时间复杂度：O(n^2 * L)，其中 n 是字符串长度，L 是单词最大长度（substr 和哈希查找的开销）。若用单词长度剪枝可优化。
- 空间复杂度：O(n)，dp 数组。

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && dict.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};
```

## 解法四: DP + 单词长度剪枝
**思路**：记录字典中单词的最大长度 maxLen，内层循环 j 只需要从 `i - maxLen` 开始枚举，大幅减少无效匹配。

**复杂度**：
- 时间复杂度：O(n * maxLen)，显著优于 O(n^2)。
- 空间复杂度：O(n)，dp 数组。

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        int maxLen = 0;
        for (auto& w : wordDict) maxLen = max(maxLen, (int)w.size());
        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = max(0, i - maxLen); j < i; j++) {
                if (dp[j] && dict.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 暴力回溯 | O(2^n) | O(n) | 枚举所有拆分方式，大量重复 |
| 记忆化搜索 | O(n^2) | O(n) | 自顶向下缓存中间结果 |
| 动态规划 | O(n^2) | O(n) | 自底向上填充 dp 表 |
| DP + 剪枝 | O(n * maxLen) | O(n) | 用单词最大长度限制内层循环 |

> 单词拆分是典型的"分割型"DP 问题。关键在于 dp[i] 的定义（前 i 个字符是否可拆分）和剪枝优化（用 maxLen 缩小内层循环范围）。面试中建议先写出 O(n^2) 的 DP，再主动讨论剪枝优化。

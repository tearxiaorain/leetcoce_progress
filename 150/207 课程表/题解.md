# 207. 课程表

## 题目描述

> 你需要选修 `numCourses` 门课程，编号 `0 ~ numCourses-1`。先修关系由 `prerequisites` 给出，`prerequisites[i] = [a, b]` 表示"修课程 `a` 之前必须先修完课程 `b`"。
> 判断是否可能完成所有课程的学习（即判断这个**有向图是否存在环**：有环则互相依赖，永远修不完）。
> 例：`numCourses = 2, prerequisites = [[1,0]]` → `true`；`numCourses = 2, prerequisites = [[1,0],[0,1]]` → `false`。
> 数据范围：1 ≤ numCourses ≤ 2000，0 ≤ 先修对数 ≤ 5000。

## 解法一：Kahn 拓扑排序（BFS 剥入度为 0 的点）

### 思路
把课程看成有向图的点，`b → a` 表示先修关系。没有环 ⇔ 能找出一个拓扑序把所有点都排进去。

实现：统计每个点的**入度**（有多少门课依赖它作为先修），把所有入度为 0 的点放进队列（这些课可以立刻修）；每从队列取出一门课就"修完"，把它指向的后续课程入度减 1，若某门课入度变成 0 就入队。最后统计出队的课程数量：等于 `numCourses` 说明无环，否则存在环。

队列可以用 `queue<int>`，也可以用 `vector<int>` 加下标指针（常数更小）。

### 复杂度
- 时间复杂度: O(V + E)（V = numCourses，E = prerequisites.size()，每个点和边各访问一次）
- 空间复杂度: O(V + E)（邻接表 + 入度数组 + 队列）

### 代码
```cpp
bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> next(numCourses);          // 邻接表: b -> 所有以 b 为先修的课
    vector<int> indeg(numCourses, 0);              // 入度：还需先修几门课
    for (auto& p : prerequisites) {
        next[p[1]].push_back(p[0]);
        indeg[p[0]]++;
    }

    queue<int> q;
    for (int i = 0; i < numCourses; i++)
        if (indeg[i] == 0) q.push(i);              // 无先修要求的课先入队

    int done = 0;
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        done++;                                    // 修完一门
        for (int nxt : next[cur]) {
            if (--indeg[nxt] == 0) q.push(nxt);    // 先修全部满足，可以修了
        }
    }
    return done == numCourses;                     // 有环则部分课程无法入队
}
```

## 解法二：DFS 三色标记（判环）

### 思路
直接做**有向图判环**：对每个点 DFS，用三种颜色记录状态：

- `0` 未访问；
- `1` 正在当前 DFS 栈中（访问中）；
- `2` 已完成（它出发的所有路径都探过了，无环）。

DFS 过程中如果遇到一个状态为 `1` 的点，说明沿着有向边又绕回了当前路径上的结点 → **存在环**，直接返回 false。如果某点出发的所有邻居都安全（都是 `2`），把它标记为 `2`。

每个点只需完整 DFS 一次，因为一旦标成 `2`，后续从别的点到达它时可以直接跳过（这是比"每次重新搜索"省时间的关键）。

### 复杂度
- 时间复杂度: O(V + E)（每个点、每条边各访问一次）
- 空间复杂度: O(V + E)（邻接表 + 颜色数组 + 递归栈最深 O(V)）

### 代码
```cpp
vector<vector<int>> g;
vector<int> color;      // 0 未访问, 1 访问中(在栈上), 2 已完成

bool dfs(int cur) {
    color[cur] = 1;                                  // 进入当前路径
    for (int nxt : g[cur]) {
        if (color[nxt] == 1) return false;           // 回到路径上的点 → 有环
        if (color[nxt] == 0 && !dfs(nxt)) return false;
    }
    color[cur] = 2;                                  // 该点出发无环，完成
    return true;
}

bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    g.assign(numCourses, {});
    color.assign(numCourses, 0);
    for (auto& p : prerequisites) g[p[1]].push_back(p[0]);   // b -> a
    for (int i = 0; i < numCourses; i++) {
        if (color[i] == 0 && !dfs(i)) return false;  // 任一路径存在环即失败
    }
    return true;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| Kahn 拓扑排序 | O(V+E) | O(V+E) | 迭代实现无递归栈，顺带能产出拓扑序 |
| DFS 三色标记 | O(V+E) | O(V+E) | 直接判环，代码短；注意"访问中"状态必须回溯式维护 |

> 延伸：若题目要求返回一种合法的修课顺序（LeetCode 210），在 Kahn 法里把出队顺序记录下来即可。

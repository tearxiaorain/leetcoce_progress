# 120. 三角形最小路径和

## 题目描述
> 给定一个三角形 `triangle`，找出自顶向下的最小路径和。每一步只能移动到下一行中相邻的节点（即下标 `i` 可以移动到 `i` 或 `i+1`）。

## 解法一: 自底向上 DP（原地）

### 思路
从倒数第二行开始向上递推，每个位置加上它下方两个位置中较小的那个：
`dp[i][j] += min(dp[i+1][j], dp[i+1][j+1])`

最终 `dp[0][0]` 就是答案。可以原地修改 triangle 数组。

### 复杂度
- 时间复杂度: O(n²) — n 为三角形行数
- 空间复杂度: O(1) — 原地修改

### 代码
```cpp
int minimumTotal(vector<vector<int>>& triangle) {
    int n = triangle.size();
    for (int i = n - 2; i >= 0; i--) {
        for (int j = 0; j <= i; j++) {
            triangle[i][j] += min(triangle[i+1][j], triangle[i+1][j+1]);
        }
    }
    return triangle[0][0];
}
```

## 解法二: 自顶向下 DP（一维）

### 思路
`dp[j]` 表示到达当前行第 j 个位置的最小路径和。每行从右向左更新，避免覆盖。

### 复杂度
- 时间复杂度: O(n²)
- 空间复杂度: O(n)

### 代码
```cpp
int minimumTotal(vector<vector<int>>& triangle) {
    int n = triangle.size();
    vector<int> dp(n, 0);
    dp[0] = triangle[0][0];
    for (int i = 1; i < n; i++) {
        dp[i] = dp[i-1] + triangle[i][i];  // 最右侧
        for (int j = i - 1; j > 0; j--) {
            dp[j] = min(dp[j], dp[j-1]) + triangle[i][j];
        }
        dp[0] += triangle[i][0];  // 最左侧
    }
    return *min_element(dp.begin(), dp.end());
}
```

## 解法三: 自底向上 DP（一维）

### 思路
用一维数组 `dp[j]` 表示从底到当前位置的最小路径和，逐行向上滚动。

### 复杂度
- 时间复杂度: O(n²)
- 空间复杂度: O(n)

### 代码
```cpp
int minimumTotal(vector<vector<int>>& triangle) {
    int n = triangle.size();
    vector<int> dp(triangle[n-1]);  // 初始化为最后一行
    for (int i = n - 2; i >= 0; i--) {
        for (int j = 0; j <= i; j++) {
            dp[j] = min(dp[j], dp[j+1]) + triangle[i][j];
        }
    }
    return dp[0];
}
```

## 总结

| 解法 | 时间 | 空间 | 方向 |
|------|------|------|------|
| 原地DP | O(n²) | O(1) | 自底向上 |
| 一维DP(顶→底) | O(n²) | O(n) | 自顶向下 |
| 一维DP(底→顶) | O(n²) | O(n) | 自底向上 |

推荐自底向上 + 一维DP，代码最简洁。

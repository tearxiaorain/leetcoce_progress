# 98. 验证二叉搜索树
## 题目描述
> 给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树。有效二叉搜索树定义如下：
> - 节点的左子树只包含 **小于** 当前节点的数；
> - 节点的右子树只包含 **大于** 当前节点的数；
> - 所有左子树和右子树自身必须也是二叉搜索树。

## 解法一: 递归（DFS + 上下界）
**思路**：不能只比较"左子节点 < 当前节点 < 右子节点"，因为左子树的**所有**节点都要小于根，右子树所有节点都要大于根。因此给每个节点维护一个合法值域 `(lower, upper)`，递归判断：
- 若节点为空 → 合法；
- 若 `node->val <= lower` 或 `node->val >= upper` → 非法；
- 否则递归检查左子树，值域收紧为 `(lower, node->val)`；右子树收紧为 `(node->val, upper)`。

初始值域取 `(LONG_MIN, LONG_MAX)`，避免边界值溢出问题。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return dfs(root, LONG_MIN, LONG_MAX);
    }

    // 判断以 root 为根的子树是否所有节点都落在 (lower, upper) 开区间内
    bool dfs(TreeNode* root, long long lower, long long upper) {
        if (root == nullptr) return true;
        if (root->val <= lower || root->val >= upper) return false;
        // 左子树值域 (lower, root->val)，右子树值域 (root->val, upper)
        return dfs(root->left, lower, root->val) &&
               dfs(root->right, root->val, upper);
    }
};
```

## 解法二: 中序遍历（递归，检查严格递增）
**思路**：二叉搜索树的**中序遍历**序列一定是严格递增的。用一个变量 `prev` 记录上一个访问到的节点值，中序遍历过程中若出现 `当前值 <= prev` 则不是 BST。利用 `prev` 是 `long long` 初始化为 `LONG_MIN`，或用指针记录"上一个节点"。

**复杂度**：
- 时间复杂度：O(n)，中序遍历访问所有节点。
- 空间复杂度：O(h)，递归栈深度。

```cpp
class Solution {
public:
    long long prev = LONG_MIN; // 记录中序遍历的上一个值

    bool isValidBST(TreeNode* root) {
        if (root == nullptr) return true;
        // 左子树
        if (!isValidBST(root->left)) return false;
        // 当前节点必须严格大于前驱
        if (root->val <= prev) return false;
        prev = root->val;
        // 右子树
        return isValidBST(root->right);
    }
};
```

## 解法三: 中序遍历（迭代 + 栈）
**思路**：与解法二同理，用显式栈做迭代中序遍历，避免递归爆栈。遍历时维护 `prev` 指针判断是否严格递增。

**复杂度**：
- 时间复杂度：O(n)。
- 空间复杂度：O(h)，栈深为树高，最坏 O(n)。

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        stack<TreeNode*> stk;
        TreeNode* prev = nullptr; // 上一个访问的节点
        TreeNode* cur = root;
        while (cur != nullptr || !stk.empty()) {
            // 一路向左压栈
            while (cur != nullptr) {
                stk.push(cur);
                cur = cur->left;
            }
            cur = stk.top(); stk.pop();
            // 中序：访问当前节点，要求严格大于前驱
            if (prev != nullptr && cur->val <= prev->val) return false;
            prev = cur;
            cur = cur->right;
        }
        return true;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 + 上下界 | O(n) | O(h) | 维护值域，最直观 |
| 中序遍历（递归） | O(n) | O(h) | 利用 BST 中序递增性质 |
| 中序遍历（迭代） | O(n) | O(h) | 显式栈，避免爆栈 |

> 推荐解法一（上下界递归），它直接反映 BST 定义，且不易出错。解法二/三利用"中序遍历严格递增"这一等价性质，是常见的替代写法。

# 637. 二叉树的层平均值
## 题目描述
> 给定一个非空二叉树的根节点 `root`，以数组的形式返回每一层节点的平均值（与实际答案相差 10⁻⁵ 以内的答案视为正确）。

## 解法一: BFS 层序遍历
**思路**：用队列做层序遍历，逐层累加节点值并统计节点数，每层结束后把 `sum / sz` 加入结果。平均值用 `double` 累加避免整数溢出与精度损失。

**复杂度**：
- 时间复杂度：O(n)，每个节点入队、出队各一次。
- 空间复杂度：O(w)，队列最多保存最宽一层的节点数，最坏（满二叉树底层）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<double> averageOfLevels(TreeNode* root) {
        vector<double> res;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            double sum = 0;
            for (int i = 0; i < sz; i++) {
                TreeNode* node = q.front(); q.pop();
                sum += node->val;
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            res.push_back(sum / sz);
        }
        return res;
    }
};
```

## 解法二: DFS（按深度记录层和与层节点数）
**思路**：递归遍历，用 `depth` 作为下标，把每个节点的值累加到 `sums[depth]`，并统计 `counts[depth]`。遍历结束后，每层的平均值 = `sums[i] / counts[i]`。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)；此外 `sums`、`counts` 各占 O(层数)。

```cpp
class Solution {
public:
    vector<double> averageOfLevels(TreeNode* root) {
        vector<double> sums;
        vector<int> counts;
        dfs(root, 0, sums, counts);
        vector<double> res(sums.size());
        for (int i = 0; i < sums.size(); i++)
            res[i] = sums[i] / counts[i];
        return res;
    }

    void dfs(TreeNode* node, int depth, vector<double>& sums, vector<int>& counts) {
        if (node == nullptr) return;
        if (depth == sums.size()) {   // 首次进入该层
            sums.push_back(node->val);
            counts.push_back(1);
        } else {
            sums[depth] += node->val;
            counts[depth]++;
        }
        dfs(node->left,  depth + 1, sums, counts);
        dfs(node->right, depth + 1, sums, counts);
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| BFS 层序遍历 | O(n) | O(n) | 逐层累加求均值 |
| DFS 记录层和/层数 | O(n) | O(h) | 按深度统计，最后相除 |

> 推荐解法一（BFS 层序遍历），最符合"按层"的直觉，且是层序类问题的通用模板。解法二（DFS）空间更省，仅与树高相关。

# 97. 交错字符串

## 题目描述

> 给定三个字符串 `s1`、`s2`、`s3`，判断 `s3` 是否能由 `s1` 和 `s2` **交错**组成。交错指：`s3` 中的每个字符要么来自 `s1`，要么来自 `s2`，且 `s1`、`s2` 的字符在 `s3` 中保持各自的原有顺序。
> 例：`s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"` → `true`；`s3 = "aadbbbaccc"` → `false`。
> 数据范围：0 ≤ |s1|, |s2| ≤ 100，|s3| = |s1| + |s2|（不满足则必为 false）。

## 解法一：记忆化 DFS

### 思路
设 `f(i, j)` 表示"`s1` 的前 `i` 个字符与 `s2` 的前 `j` 个字符，能否交错拼出 `s3` 的前 `i + j` 个字符"。此时 `s3` 的待匹配位置固定为 `k = i + j - 1`，只有两种转移：

- 若 `s1[i-1] == s3[i+j-1]`，可以消耗一个 `s1` 字符，转成 `f(i-1, j)`；
- 若 `s2[j-1] == s3[i+j-1]`，可以消耗一个 `s2` 字符，转成 `f(i, j-1)`。

两者任一是 true，则 `f(i, j)` 为 true。递归边界 `f(0, 0) = true`。

朴素的递归会重复到达同一 (i, j)（两条不同的消耗顺序可能汇到同一状态），所以要加记忆表。

### 复杂度
- 时间复杂度: O(m·n)（每个状态算一次）
- 空间复杂度: O(m·n)（记忆表）+ O(m + n) 递归栈

### 代码
```cpp
int m, n;
vector<vector<int>> memo;          // -1 未算, 0 false, 1 true

bool dp(const string& s1, const string& s2, const string& s3, int i, int j) {
    if (i == 0 && j == 0) return true;                 // 两个空串拼出空串
    if (memo[i][j] != -1) return memo[i][j];
    bool ok = false;
    int k = i + j;                                     // s3 当前待匹配位的前一位
    if (i > 0 && s1[i - 1] == s3[k - 1]) ok |= dp(s1, s2, s3, i - 1, j);
    if (!ok && j > 0 && s2[j - 1] == s3[k - 1]) ok |= dp(s1, s2, s3, i, j - 1);
    return memo[i][j] = ok;
}

bool isInterleave(string s1, string s2, string s3) {
    m = s1.size(); n = s2.size();
    if (m + n != (int)s3.size()) return false;         // 长度不符直接否决
    memo.assign(m + 1, vector<int>(n + 1, -1));
    return dp(s1, s2, s3, m, n);
}
```

## 解法二：二维 DP

### 思路
把递归转成表。`dp[i][j]` 表示 `s1` 前 `i` 个 + `s2` 前 `j` 个能否拼出 `s3` 前 `i + j` 个。

- 初始化：`dp[0][0] = true`；第一行 `dp[0][j]` 表示只用 `s2`，判断 `s2[0..j-1] == s3[0..j-1]`；第一列同理。
- 转移：

```
dp[i][j] = (dp[i-1][j] && s1[i-1] == s3[i+j-1])
        || (dp[i][j-1] && s2[j-1] == s3[i+j-1])
```

含义是：`s3` 的最后一位要么由 `s1` 的最后一位提供，要么由 `s2` 的最后一位提供。这里用 `||` 而不是 `|=` 也一样，只要两个条件独立判断即可。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(m·n)

### 代码
```cpp
bool isInterleave(string s1, string s2, string s3) {
    int m = s1.size(), n = s2.size();
    if (m + n != (int)s3.size()) return false;
    vector<vector<bool>> dp(m + 1, vector<bool>(n + 1, false));
    dp[0][0] = true;
    for (int i = 0; i <= m; i++) {
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) continue;
            int k = i + j - 1;                                   // s3 当前位
            if (i > 0 && s1[i - 1] == s3[k]) dp[i][j] = dp[i][j] || dp[i - 1][j];
            if (j > 0 && s2[j - 1] == s3[k]) dp[i][j] = dp[i][j] || dp[i][j - 1];
        }
    }
    return dp[m][n];
}
```

## 解法三：一维滚动数组

### 思路
转移只依赖「上一行同列 `dp[i-1][j]`」和「本行左列 `dp[i][j-1]`」，因此可以压成一维：外层枚举 `i`，内层枚举 `j`，`dp[j]` 在更新前代表上一行的值。

注意第一行要先单独初始化：`i = 0` 时 `dp[j]` 表示只用 `s2` 能否拼出 `s3` 前缀。

### 复杂度
- 时间复杂度: O(m·n)
- 空间复杂度: O(n)

### 代码
```cpp
bool isInterleave(string s1, string s2, string s3) {
    int m = s1.size(), n = s2.size();
    if (m + n != (int)s3.size()) return false;
    vector<bool> dp(n + 1, false);
    dp[0] = true;
    for (int j = 1; j <= n; j++)                    // 第 0 行：只用 s2
        dp[j] = dp[j - 1] && s2[j - 1] == s3[j - 1];
    for (int i = 1; i <= m; i++) {
        dp[0] = dp[0] && s1[i - 1] == s3[i - 1];    // 每行的第一列：只用 s1
        for (int j = 1; j <= n; j++) {
            int k = i + j - 1;
            bool fromS1 = dp[j]     && s1[i - 1] == s3[k];   // dp[j] 尚为上一行
            bool fromS2 = dp[j - 1] && s2[j - 1] == s3[k];   // 本行已更新
            dp[j] = fromS1 || fromS2;
        }
    }
    return dp[n];
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 记忆化 DFS | O(m·n) | O(m·n) | 顺着"最后一个字符谁提供"展开，好理解 |
| 二维 DP | O(m·n) | O(m·n) | 标准递推表 |
| 一维滚动 | O(m·n) | O(n) | 空间最优，注意第 0 行/列单独初始化 |

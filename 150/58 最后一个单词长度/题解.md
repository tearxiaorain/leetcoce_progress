# 58. 最后一个单词的长度

## 题目描述
> 给定一个由若干单词组成、单词间由空格分隔的字符串 s，返回字符串中最后一个单词的长度。单词指仅由非空格字符组成的最大子字符串。注意字符串末尾可能有空格。

## 解法一: 从右向左扫描（直接法）
### 思路
从字符串末尾开始扫描：
1. 跳过末尾的空格（找到最后一个非空格字符的位置）
2. 从该位置继续向左扫描，统计非空格字符数量，直到遇到空格或字符串开头

**图解：**
```
s = "Hello World   "
             ↑
跳过末尾空格 → 指针指向 'd'
从 'd' 向左数 → "World" 共 5 个字符 → 返回 5
```

### 复杂度
- 时间复杂度: O(n)，最坏扫描整个字符串
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        int i = s.size() - 1;
        // 跳过末尾空格
        while (i >= 0 && s[i] == ' ') i--;
        // 统计最后一个单词长度
        int len = 0;
        while (i >= 0 && s[i] != ' ') {
            len++;
            i--;
        }
        return len;
    }
};
```

## 解法二: 字符串分割法
### 思路
使用字符串流或按空格分割字符串，取最后一个非空单词求长度。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)，存储分割结果

### 代码
```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        istringstream iss(s);
        string word;
        while (iss >> word);  // 一直读到最后一个单词
        return word.size();
    }
};
```

## 总结
| 解法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 从右向左扫描 | O(n) | O(1) | 空间最优，不分配额外空间 | 需处理边界 |
| 字符串分割 | O(n) | O(n) | 代码极简 | 额外分配字符串 |

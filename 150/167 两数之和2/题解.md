# 167. 两数之和2 - 输入有序数组

## 题目描述
> 给定一个下标从 1 开始的升序整数数组 numbers，找出两个数使它们的和为 target。返回这两个数的下标（从 1 开始）。假设有且只有一个解，且不能重复使用同一个元素。要求只使用常量额外空间。

## 解法一: 暴力枚举
### 思路
双重循环枚举所有数对 (i, j)，检查 `numbers[i] + numbers[j] == target`。

### 复杂度
- 时间复杂度: O(n^2)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int n = numbers.size();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (numbers[i] + numbers[j] == target) {
                    return {i + 1, j + 1};
                }
            }
        }
        return {};
    }
};
```

## 解法二: 双指针法（对撞指针）
### 思路
利用数组有序的特性，使用左右双指针：
- 左指针 `l` 指向数组开头，右指针 `r` 指向数组末尾。
- 计算 `sum = numbers[l] + numbers[r]`：
  - 如果 `sum == target`，返回 `{l+1, r+1}`。
  - 如果 `sum < target`，则 `l++`（需要一个更大的数）。
  - 如果 `sum > target`，则 `r--`（需要一个更小的数）。
- 由于题目保证有唯一解，双指针必然相遇在答案处。

### 复杂度
- 时间复杂度: O(n)，最坏情况两个指针各遍历 n/2 步
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int l = 0, r = numbers.size() - 1;
        
        while (l < r) {
            int sum = numbers[l] + numbers[r];
            if (sum == target) {
                return {l + 1, r + 1};
            } else if (sum < target) {
                l++;
            } else {
                r--;
            }
        }
        
        return {};
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n^2) | O(1) | 暴力枚举所有数对 |
| 解法二 | O(n) | O(1) | 利用数组有序性，双指针向中间收缩 |

双指针法充分利用了"数组升序"这一条件，是本题的最优解。与 LeetCode 1（无序两数之和用哈希表）不同，本题有序数组给了更高效的 O(n) + O(1) 解法。

# 215. 数组中的第 K 个最大元素

## 题目描述

> 给定整数数组 `nums` 和整数 `k`，返回数组中**第 k 个最大**的元素（排序后从大到小第 k 个）。要求不复制数组，直接在原数组上解决。
> 输入输出示意：`nums = [3,2,1,5,6,4], k = 2` → `5`。

## 解法一: 全排序（直观）

### 思路
对整个数组降序排序（或升序后取下标 `n-k`），直接返回第 k 个元素。思路最直白，但做了多余工作——我们只关心第 k 大，不关心其余元素的确切次序。

### 复杂度
- 时间复杂度: O(n log n)
- 空间复杂度: O(log n)（排序栈/内部空间，视具体排序实现；多数库为 O(log n)）

### 代码
```cpp
int findKthLargest(vector<int>& nums, int k) {
    sort(nums.begin(), nums.end(), greater<int>());
    return nums[k - 1];
}
```

## 解法二: 快速选择（快速排序的 partition，平均 O(n)）

### 思路
借鉴快排的 `partition`：任选一个基准（如取区间中点，避免有序数组退化），把区间分成「> 基准」与「≤ 基准」两半，得到基准的最终下标 `pos`。
- 若 `pos == k-1`：基准就是第 k 大；
- 若 `pos > k-1`：第 k 大在左半，只递归左半；
- 否则只递归右半。

每轮只处理一侧区间，平均规模 n + n/2 + n/4 + … → O(n)。这是求第 k 大/小的经典「减治」算法。为避免最坏 O(n²)（如已排序数组配最差基准），可引入随机选基准。

### 复杂度
- 时间复杂度: 平均 O(n)，最坏 O(n²)（随机化基准后最坏概率极低）
- 空间复杂度: O(log n)（递归栈，平均）

### 代码
```cpp
int findKthLargest(vector<int>& nums, int k) {
    int n = nums.size(), target = n - k;          // 第 k 大 = 升序第 n-k 小
    int l = 0, r = n - 1;
    while (true) {
        int pivot = nums[l + (r - l) / 2];
        int i = l, j = r;
        while (i <= j) {                          // 三路切分：pivot 归位
            while (nums[i] < pivot) i++;
            while (nums[j] > pivot) j--;
            if (i <= j) { swap(nums[i], nums[j]); i++; j--; }
        }
        if (target <= j)      r = j;              // 在左段
        else if (target >= i) l = i;              // 在右段
        else return nums[target];                 // 恰落在基准区
    }
}
```

## 解法三: 大小为 k 的最小堆（无需改原数组）

### 思路
维护一个容量为 k 的**最小堆**：逐个把元素入堆，堆满 k 个后再入时若新元素大于堆顶，则弹出堆顶、压入新元素。遍历结束后堆里恰好是前 k 大的数，堆顶就是其中最小者 = 第 k 大。
此法不改原数组、不递归，尤其适合元素来自数据流、需要多次查询的场景。

### 复杂度
- 时间复杂度: O(n log k)
- 空间复杂度: O(k)

### 代码
```cpp
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> pq;   // 最小堆
    for (int x : nums) {
        pq.push(x);
        if ((int)pq.size() > k) pq.pop();                 // 只保留最大的 k 个
    }
    return pq.top();
}
```

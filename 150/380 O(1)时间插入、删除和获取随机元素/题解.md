# 380. O(1) 时间插入、删除和获取随机元素

## 题目描述

> 实现一个集合 `RandomizedSet`，支持 `insert(val)`、`remove(val)`、`getRandom()` 三个操作，且**每个操作平均 O(1) 时间**。元素唯一（重复 insert 返回 false），`getRandom()` 等概率返回集合中任意一个元素（可多次取到同一元素）。
> 输入输出示意：`insert(1)=true, insert(2)=true, remove(1)=true, insert(2)=false, getRandom()∈{2}`。

## 解法: 哈希表 + 动态数组（交换删除）

### 思路
单个哈希表能 O(1) 判断存在，但取随机元素要遍历；单个数组能 O(1) 按下标随机，但 O(1) 判断/删除做不到。二者结合：
- **数组 `v`** 存放元素 → `getRandom()` 用 `v[rand() % v.size()]` O(1) 等概率取；
- **哈希表 `pos`**（值 → 在数组中的下标）→ 支持 O(1) 存在性判断与定位。

关键技巧是 **交换删除**：删除 `val` 时，不直接在前中部删（后面的元素会整体前移，O(n)），而是先取 `val` 的下标 `i`，把**数组最后一个元素**搬到 `i` 处，再 `pop_back()`，同时更新哈希表中那个被搬动元素的新下标，最后 erase `val`。这样删除恒为 O(1)，数组无需保持插入顺序。

### 复杂度
- 时间复杂度: insert / remove / getRandom 均摊 O(1)
- 空间复杂度: O(n)

### 代码
```cpp
class RandomizedSet {
    vector<int> v;                 // 存元素，供随机访问
    unordered_map<int, int> pos;   // 值 → 下标
public:
    RandomizedSet() {}
    bool insert(int val) {
        if (pos.count(val)) return false;
        pos[val] = v.size();
        v.push_back(val);
        return true;
    }
    bool remove(int val) {
        if (!pos.count(val)) return false;
        int i = pos[val];                 // val 所在下标
        int last = v.back();              // 末尾元素
        v[i] = last;                      // 末位搬到 i
        pos[last] = i;                    // 更新末位的新下标
        v.pop_back();                     // 删掉（原）末尾
        pos.erase(val);
        return true;
    }
    int getRandom() {
        return v[rand() % v.size()];      // 等概率随机
    }
};
```

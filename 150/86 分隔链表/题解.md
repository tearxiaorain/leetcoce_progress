# 86. 分隔链表

## 题目描述

> 给定一个链表头 `head` 和一个特定值 `x`，对链表进行分隔，使得所有**小于 x 的节点**都出现在**大于或等于 x 的节点之前**，且**两部分内部保持原有相对顺序**。返回重排后的链表头。
> 输入输出示意：`head = [1,4,3,2,5,2], x = 3` → `[1,2,2,4,3,5]`。

## 解法一: 借助数组收集重建（直观）

### 思路
遍历两遍：第一遍把值 `< x` 的节点指针依次收进 `less`，第二遍把 `>= x` 的收进 `ge`（或一遍遍历按条件分别 push 到两个 vector）。最后把 `less` 的节点逐个重链，再接上 `ge`，`ge` 末尾置空。

思路直白、天然稳定（保持相对顺序），代价是用了 O(n) 的额外数组存指针。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)（两个指针数组）

### 代码
```cpp
ListNode* partition(ListNode* head, int x) {
    vector<ListNode*> less, ge;
    for (ListNode* p = head; p; p = p->next)
        (p->val < x ? less : ge).push_back(p);

    ListNode dummy(0), *t = &dummy;
    for (ListNode* p : less) { t->next = p; t = p; }
    for (ListNode* p : ge)   { t->next = p; t = p; }
    t->next = nullptr;                 // 结尾断开，防止残留环
    return dummy.next;
}
```

## 解法二: 双哑节点原地拆链（O(n) O(1)）

### 思路
用两个哑节点 `small` / `large` 各建一条链，单次遍历原链表：
1. 当前节点值 `< x` → 接到 `small` 链尾；否则接到 `large` 链尾；
2. 遍历完把 `small` 链尾接到 `large` 链头（`largeHead->next`），`large` 链尾置空；
3. 返回 `smallHead->next`。

从头到尾只改指针、不新建节点、只遍历一次，且按原顺序接入两条链，天然稳定。这是本题的标准解。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)（仅两个哑节点）

### 代码
```cpp
ListNode* partition(ListNode* head, int x) {
    ListNode smallHead(0), largeHead(0);
    ListNode *s = &smallHead, *l = &largeHead;
    for (ListNode* p = head; p; p = p->next) {
        if (p->val < x) { s->next = p; s = p; }
        else            { l->next = p; l = p; }
    }
    l->next = nullptr;          // large 链尾断开
    s->next = largeHead.next;   // 小链接大链
    return smallHead.next;
}
```

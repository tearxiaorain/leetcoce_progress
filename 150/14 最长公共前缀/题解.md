# 14. 最长公共前缀

## 题目描述
> 给定一个字符串数组 strs，查找所有字符串的最长公共前缀。如果不存在公共前缀，返回空字符串 ""。

## 解法一: 纵向扫描
### 思路
以第一个字符串为基准，逐个字符位置向后扫描。对于每个位置，检查所有字符串在该位置是否都有相同字符。一旦发现不匹配或某个字符串长度不足，立即返回当前已匹配的前缀。

### 复杂度
- 时间复杂度: O(S)，S 为所有字符串的字符总数。最坏情况下需要比较所有字符。
- 空间复杂度: O(1)，只使用常数额外空间。

### 代码
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    
    for (int i = 0; i < strs[0].size(); i++) {
        char c = strs[0][i];
        for (int j = 1; j < strs.size(); j++) {
            if (i >= strs[j].size() || strs[j][i] != c) {
                return strs[0].substr(0, i);
            }
        }
    }
    return strs[0];
}
```

## 解法二: 横向扫描（两两比较）
### 思路
初始化前缀为第一个字符串，然后依次和后面每个字符串比较，不断缩短前缀直到成为当前字符串的前缀为止。相当于逐个取交集。

### 复杂度
- 时间复杂度: O(S)，S 为所有字符串的字符总数。
- 空间复杂度: O(1)。

### 代码
```cpp
string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    
    string prefix = strs[0];
    for (int i = 1; i < strs.size(); i++) {
        while (strs[i].find(prefix) != 0) {
            prefix = prefix.substr(0, prefix.size() - 1);
            if (prefix.empty()) return "";
        }
    }
    return prefix;
}
```

## 解法三: 排序后比较首尾
### 思路
将字符串数组排序后，公共前缀只需比较第一个和最后一个字符串——因为排序后差异最大的两个字符串排在首尾，它们的公共前缀就是所有字符串的公共前缀。

### 复杂度
- 时间复杂度: O(n log n * m)，n 为字符串数量，m 为字符串平均长度。
- 空间复杂度: O(log n)，排序所需的递归栈空间。

### 代码
```cpp
string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    sort(strs.begin(), strs.end());
    string& first = strs.front();
    string& last = strs.back();
    int i = 0;
    while (i < first.size() && i < last.size() && first[i] == last[i]) {
        i++;
    }
    return first.substr(0, i);
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 纵向扫描 | O(S) | O(1) | 最直观，提前终止 |
| 横向扫描 | O(S) | O(1) | 逐字符串缩短 |
| 排序后比较 | O(n log n * m) | O(log n) | 代码简洁，但排序开销较大 |

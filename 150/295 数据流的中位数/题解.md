# 295. 数据流的中位数

## 题目描述

> 设计一个支持以下两种操作的数据结构:`addNum(num)` 从数据流中添加一个整数,`findMedian()` 返回目前所有元素的中位数(数据量为偶数时返回中间两数的平均值)。
> 输入输出示意:`addNum(1), addNum(2), findMedian()=1.5, addNum(3), findMedian()=2`。

## 解法一: 维护有序容器（直观）

### 思路
每次 `addNum` 用二分插入到有序 `vector`,`findMedian` 直接取中间位置 O(1)。思路直白,但中间插入要整体搬移,O(n) 每次,数据量大时偏慢。

### 复杂度
- 时间复杂度: addNum O(n)(插入搬移),findMedian O(1)
- 空间复杂度: O(n)

### 代码
```cpp
class MedianFinder {
    vector<int> v;
public:
    void addNum(int num) {
        auto it = lower_bound(v.begin(), v.end(), num);
        v.insert(it, num);
    }
    double findMedian() {
        int n = v.size();
        return n % 2 ? v[n/2] : (v[n/2-1] + v[n/2]) / 2.0;
    }
};
```

## 解法二: 双堆（最大堆 + 最小堆，O(log n)）

### 思路
把数据流**从中间劈成两半**:左侧 `left` 用**最大堆**存较小的一半,右侧 `right` 用**最小堆**存较大的一半。维持两条不变量:
1. `left.size() >= right.size()`(左比右至多多 1);
2. `left` 堆顶 ≤ `right` 堆顶(左半最大值 ≤ 右半最小值)。

`addNum`:先按值决定进哪个堆,再**平衡两边大小**——若插入后失衡(左比右多 2 或右比左多),把堆顶挪到另一边。
`findMedian`:总数奇数是 `left.top()`(左多一个,中位即其堆顶);偶数是 `(left.top() + right.top()) / 2.0`。
任何时刻中位数 = 两堆顶交界处的值,两边各自 O(1) 可取顶、O(log n) 入堆。

### 复杂度
- 时间复杂度: addNum O(log n),findMedian O(1)
- 空间复杂度: O(n)

### 代码
```cpp
class MedianFinder {
    priority_queue<int> left;                          // 最大堆(左半)
    priority_queue<int, vector<int>, greater<int>> right; // 最小堆(右半)
public:
    void addNum(int num) {
        if (left.empty() || num <= left.top()) left.push(num);
        else right.push(num);
        // 平衡:左比右最多多 1
        if (left.size() > right.size() + 1) { right.push(left.top()); left.pop(); }
        if (right.size() > left.size())       { left.push(right.top()); right.pop(); }
    }
    double findMedian() {
        if (left.size() > right.size()) return left.top();
        return (left.top() + right.top()) / 2.0;
    }
};
```

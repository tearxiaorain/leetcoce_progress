# 300. 最长递增子序列 (Longest Increasing Subsequence)

## 题目描述

给定一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。

**示例 1:**
```
输入: nums = [10,9,2,5,3,7,101,18]
输出: 4
解释: 最长递增子序列是 [2,3,7,101]，因此长度为 4。
```

**示例 2:**
```
输入: nums = [0,1,0,3,2,3]
输出: 4
```

**示例 3:**
```
输入: nums = [7,7,7,7,7,7,7]
输出: 1
```

---

## 解法一：动态规划 O(n²)

**状态定义：**
`dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列的长度。

**状态转移方程：**
对于每个 `i`，遍历所有 `j < i`：
- 如果 `nums[j] < nums[i]`，则 `nums[i]` 可以接在 `nums[j]` 后面
- `dp[i] = max(dp[i], dp[j] + 1)`

**初始化：**
每个元素自身构成一个长度为 1 的子序列，`dp[i] = 1`。

**最终答案：**
`max(dp[0], dp[1], ..., dp[n-1])` —— 最长递增子序列不一定以最后一个元素结尾。

**C++ 代码：**
```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int ans = 1;
    
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    
    return ans;
}
```

**复杂度分析：**
- 时间复杂度：O(n²)，双重循环
- 空间复杂度：O(n)，dp 数组

**优点：** 思路直观，容易理解和实现；同时能输出具体的最长子序列（通过记录前驱）。

**缺点：** O(n²) 在 n 较大时（如 10⁵）会超时。

---

## 解法二：贪心 + 二分查找 O(n log n)（耐心排序）

**核心思想（耐心排序 / Patience Sorting）：**

维护一个数组 `tails`，其中 `tails[k]` 表示**长度为 k+1 的递增子序列的最小可能末尾元素**。

遍历每个 `num`：
- 在 `tails` 中二分查找第一个 `>= num` 的位置 `pos`
- 如果 `pos` 等于 `tails` 当前长度，说明 `num` 大于所有末尾元素，直接追加
- 否则，用 `num` 替换 `tails[pos]`（因为找到了更小的末尾元素）

**为什么这样做是对的？**

当我们用较小的值替换 `tails[pos]` 时，并没有改变当前最长递增子序列的长度，但使得长度为 `pos+1` 的子序列的末尾更小，为后续扩展创造了更好的条件。

**C++ 代码：**
```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;
    
    for (int num : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), num);
        if (it == tails.end()) {
            tails.push_back(num);
        } else {
            *it = num;
        }
    }
    
    return tails.size();
}
```

**复杂度分析：**
- 时间复杂度：O(n log n)，每个元素一次二分查找
- 空间复杂度：O(n)，tails 数组

**注意：** `tails` 数组中的序列**不一定是**真正的最长递增子序列，但长度是正确的。

---

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 动态规划 | O(n²) | O(n) | n ≤ 10⁴，需要输出具体子序列 |
| 贪心+二分 | O(n log n) | O(n) | n ≤ 10⁵，只需长度 |

**关键对比：**
- DP 解法直观且能还原子序列，适合面试中快速给出正确解法
- 贪心+二分解法是更优解，理解了"耐心排序"的物理意义后也很容易记忆

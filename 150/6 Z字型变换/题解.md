# 6. Z字型变换

## 题目描述
> 给定一个字符串 s 和一个整数 numRows，将字符串按 Z 字形排列成 numRows 行，然后按行读取并返回新的字符串。Z 字形指的是从上到下、再从下到上、反复书写的模式。

## 解法一: 模拟法（按行填充）
### 思路
创建 numRows 个字符串（对应每一行），遍历原字符串的每个字符，按 Z 字形方向（向下或向上）依次将字符追加到对应行的字符串中。使用一个变量 curRow 记录当前行，一个布尔变量 goingDown 控制方向。当到达第一行或最后一行时反转方向。

### 复杂度
- 时间复杂度: O(n)，n 为字符串长度，每个字符只处理一次。
- 空间复杂度: O(n)，存储 numRows 个字符串的总空间。

### 代码
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

string convert(string s, int numRows) {
    if (numRows == 1) return s;
    
    vector<string> rows(min(numRows, (int)s.size()));
    int curRow = 0;
    bool goingDown = false;
    
    for (char c : s) {
        rows[curRow] += c;
        if (curRow == 0 || curRow == numRows - 1) {
            goingDown = !goingDown;
        }
        curRow += goingDown ? 1 : -1;
    }
    
    string result;
    for (string& row : rows) {
        result += row;
    }
    return result;
}
```

## 解法二: 按周期直接访问
### 思路
Z 字形变换具有周期性规律。每个周期包含 2 * numRows - 2 个字符（除了首尾行）。对于第 i 行（0-indexed），周期内的两个字符位置分别是：周期起点 + i 和 周期起点 + (cycleLen - i)。直接按行遍历，跳过中间字符。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)（不计结果字符串）

### 代码
```cpp
string convert(string s, int numRows) {
    if (numRows == 1) return s;
    
    int n = s.size();
    int cycleLen = 2 * numRows - 2;
    string result;
    result.reserve(n);
    
    for (int i = 0; i < numRows; i++) {
        for (int j = 0; j + i < n; j += cycleLen) {
            result += s[j + i];  // 周期内第一个字符
            if (i != 0 && i != numRows - 1 && j + cycleLen - i < n) {
                result += s[j + cycleLen - i];  // 周期内第二个字符（非首尾行）
            }
        }
    }
    return result;
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 按行填充模拟 | O(n) | O(n) | 直观模拟，易于理解 |
| 周期直接访问 | O(n) | O(1) | 数学推导，空间更优 |

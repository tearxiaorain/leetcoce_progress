# 77. 组合

## 题目描述

> 给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。你可以按任何顺序返回答案。
> 示例：`n = 4, k = 2` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

"组合"的特点是**不关心顺序**，`[1,2]` 与 `[2,1]` 视为同一组合。去重的关键做法是：**每次从当前位置的下一个元素开始取（`i+1` 起步），不回头**，即保证组合内元素下标严格递增。

## 解法一：回溯（起始下标 i+1）

### 思路

- `dfs(start, 还剩多少个要选)`：从 `[start, n]` 中选数填进当前组合
- 选第 `i` 个后，下一次从 `i+1` 开始，保证不会取到已考虑过的更小值 → 天然去重且不产生排列重复
- 终止：`k` 个已凑齐即收集；也常用 `start > n - 剩余数` 之类的剪枝（见解法二）

### 复杂度
- 时间复杂度: O(C(n, k) × k)，组合总数 C(n,k)，每个结果拷贝 O(k)
- 空间复杂度: O(k)，递归深度 + path

### 代码
```cpp
class Solution {
public:
    void dfs(int n, int k, int start, vector<int>& path, vector<vector<int>>& res) {
        if (path.size() == k) { res.push_back(path); return; }
        for (int i = start; i <= n; ++i) {
            path.push_back(i);
            dfs(n, k, i + 1, path, res);   // 关键：i+1，避免回头产生 [1,2]/[2,1] 重复
            path.pop_back();
        }
    }
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> res;
        vector<int> path;
        dfs(n, k, 1, path, res);
        return res;
    }
};
```

## 解法二：回溯 + 剩余空间剪枝

### 思路

在解法一基础上：若当前还需 `need = k - path.size()` 个数，而 `[start, n]` 最多能提供 `n - start + 1` 个，当 `n - start + 1 < need` 时**后面无论如何都凑不齐**，可直接结束循环（`i` 最多取到 `n - need + 1`）。把循环上界收紧成 `n - (k - path.size()) + 1`，能跳过大量注定失败的搜索。

### 复杂度
- 时间复杂度: O(C(n, k) × k)，剪枝不改变渐进上界但常数显著减小
- 空间复杂度: O(k)

### 代码
```cpp
class Solution {
public:
    void dfs(int n, int k, int start, vector<int>& path, vector<vector<int>>& res) {
        if (path.size() == k) { res.push_back(path); return; }
        int need = k - path.size();
        for (int i = start; i <= n - need + 1; ++i) {  // 剩余不足 need 个就停
            path.push_back(i);
            dfs(n, k, i + 1, path, res);
            path.pop_back();
        }
    }
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> res;
        vector<int> path;
        dfs(n, k, 1, path, res);
        return res;
    }
};
```

## 总结

- 组合模板：**`dfs(start)` + 选完 `start=i` 后递归传 `i+1`**，与 39（可重复选，传 `i`）、46（排列，用 used/swap）对比记忆。
- 剪枝表达式 `i <= n - (k - path.size()) + 1` 是组合题常见的加速手段。
- 注意循环从 `1` 开始（数字范围 `[1,n]`），不是从 `0`。

# 70. 爬楼梯
## 题目描述
> 假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶？

## 解法一: 暴力递归（回溯）
**思路**：从第 0 级开始，每一步可以选择爬 1 级或 2 级，递归计算所有可能的路径数。当到达第 n 级时返回 1（找到一种方案），超过 n 时返回 0。

**复杂度**：
- 时间复杂度：O(2^n)，每个递归节点分叉为两个子问题，指数级增长。
- 空间复杂度：O(n)，递归栈最深为 n 层。

```cpp
class Solution {
public:
    int climbStairs(int n) {
        return dfs(0, n);
    }
    
    int dfs(int i, int n) {
        if (i > n) return 0;
        if (i == n) return 1;
        return dfs(i + 1, n) + dfs(i + 2, n);
    }
};
```

## 解法二: 记忆化搜索（自顶向下 DP）
**思路**：在暴力递归的基础上引入 memo 数组，存储已经计算过的 f(i) 值，避免重复计算。

**复杂度**：
- 时间复杂度：O(n)，每个状态只计算一次。
- 空间复杂度：O(n)，递归栈 + memo 数组。

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> memo(n + 1, -1);
        return dfs(0, n, memo);
    }
    
    int dfs(int i, int n, vector<int>& memo) {
        if (i > n) return 0;
        if (i == n) return 1;
        if (memo[i] != -1) return memo[i];
        memo[i] = dfs(i + 1, n, memo) + dfs(i + 2, n, memo);
        return memo[i];
    }
};
```

## 解法三: 动态规划（自底向上 DP）
**状态定义**：`dp[i]` 表示爬到第 i 级台阶的方法数。

**转移方程**：
> `dp[i] = dp[i-1] + dp[i-2]`

解释：要到达第 i 级，可以从第 i-1 级爬 1 步，或从第 i-2 级爬 2 步。

**初始化**：`dp[0] = 1`（地面），`dp[1] = 1`（第一级只有一种爬法）。

**复杂度**：
- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(n)，dp 数组。可优化至 O(1)（见解法四）。

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 1) return 1;
        vector<int> dp(n + 1);
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
};
```

## 解法四: 滚动变量优化（空间 O(1)）
**思路**：观察转移方程发现 dp[i] 仅依赖于前两个状态，用两个变量滚动更新即可。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(1)

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 1) return 1;
        int prev2 = 1; // dp[0]
        int prev1 = 1; // dp[1]
        for (int i = 2; i <= n; i++) {
            int curr = prev1 + prev2;
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 暴力递归 | O(2^n) | O(n) | 指数级递归，大量重复计算 |
| 记忆化搜索 | O(n) | O(n) | 自顶向下 + memo 剪枝 |
| 动态规划 | O(n) | O(n) | 自底向上填表，本质上就是斐波那契数列 |
| 滚动变量 | O(n) | O(1) | 仅保留前两个状态，空间最优 |

> 爬楼梯是最经典的 DP 入门题，其状态转移方程就是斐波那契数列递推式。推荐在面试中从暴力递归推到记忆化再推到 DP 数组最后到滚动变量，展示完整的优化路径。

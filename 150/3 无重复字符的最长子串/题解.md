# 3. 无重复字符的最长子串

## 题目描述

> 给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。
> 输入输出示意：`s = "abcabcbb"` → 3（`"abc"`）；`s = "bbbbb"` → 1（`"b"`）；`s = "pwwkew"` → 3（`"wke"`）。子串要求连续，与子序列不同。

## 解法一: 暴力 + 哈希集合去重

### 思路
枚举所有起点 `i`，从 `i` 开始向右延伸并不断把字符加入集合；一旦碰到集合中已有的字符就停止。每次更新答案。最坏情况下 `[i, j]` 区间会被反复扫描，代价高。

### 复杂度
- 时间复杂度: O(n²)，每个起点都向尾部扫描（辅助哈希使单字符判定 O(1)，但整体仍接近 O(n²)）
- 空间复杂度: O(min(n, |Σ|))，去重集合最多装下所有不同字符

### 代码
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            unordered_set<char> seen;
            for (int j = i; j < n; ++j) {
                if (seen.count(s[j])) break;      // 出现重复，以 i 为起点的最长到此为止
                seen.insert(s[j]);
                ans = max(ans, j - i + 1);
            }
        }
        return ans;
    }
};
```

## 解法二: 双指针滑动窗口（哈希集合，O(n)）

### 思路
用一个左指针 `l` 维护当前无重复窗口的左边界，右指针 `r` 逐个把字符纳入窗口：
1. `r` 每向右扩展一位，先看 `s[r]` 是否已在窗口集合中；
2. 若在，说明窗口内有重复，左指针 `l` 不断右移并从集合中移除 `s[l]`，直到把那个重复字符移出窗口（此时窗口内恢复无重复）；
3. 把 `s[r]` 放入集合，更新 `ans = max(ans, r - l + 1)`。

因为 `l`、`r` 都只向右移动，每个字符至多进出集合一次，线性完成。若字符集较小，可用 `int[128]` 数组代替集合进一步提速。

### 复杂度
- 时间复杂度: O(n)，左右指针各扫描一遍
- 空间复杂度: O(min(n, |Σ|))，窗口内不同字符数

### 代码
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> win;
        int l = 0, ans = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            while (win.count(s[r])) {        // 右端与窗口内字符重复
                win.erase(s[l]);             // 收缩左端直至去重
                ++l;
            }
            win.insert(s[r]);
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

> 优化变体：若记 `s[r]` 上一次出现的位置，可让左指针**直接跳到** `max(l, last[s[r]] + 1)`，无需 while 逐格收缩，仍是 O(n)。

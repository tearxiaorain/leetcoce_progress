# 427. 建立四叉树

## 题目描述

> 给你一个 `n × n` 矩阵 `grid`，其中 `n` 是 2 的幂。请用四叉树表示这个矩阵。
> 四叉树每个节点有 4 个子节点（topLeft / topRight / bottomLeft / bottomRight）。若一个节点代表的子矩阵**所有值都相同**，它就是叶子节点（`isLeaf = true, val = 该值`），不再细分；否则非叶子（`val` 任意，惯例 `true`），继续把矩阵**四等分**递归建树。
> 示例：全 0 的 2×2 矩阵 → 一个 `isLeaf=true, val=false` 的根。

本质：**对网格做四分递归**，先判定当前区块是否同值，是则建叶；否则切 4 块递归。

## 解法一：递归判定 + 四等分

### 思路

定义 `build(x, y, len)`：`(x,y)` 为区块左上角，`len` 为边长，构建该区块对应的子树。

1. 先扫描该区块是否全同值（与 `grid[x][y]` 比较），是 → 返回叶子节点
2. 否则以 `len/2` 为边长切出 4 个区块，分别递归：`(x,y)`、`(x, y+len/2)`、`(x+len/2, y)`、`(x+len/2, y+len/2)`
3. 返回的父节点 `isLeaf=false`

判定同值也可在递归里顺带完成，整体一个函数即可。

### 复杂度
- 时间复杂度: O(n² log n)：每层四等分，每层每个格子可能被所属节点扫描一次用于判同值；总判定开销 O(n² log n)（若合并判定到递归可优化到 O(n²)）
- 空间复杂度: O(log n)，递归栈深度

### 代码
```cpp
class Solution {
    vector<vector<int>> g;
public:
    Node* build(int x, int y, int len) {
        int v = g[x][y];
        bool same = true;
        for (int i = x; i < x + len && same; ++i)
            for (int j = y; j < y + len; ++j)
                if (g[i][j] != v) { same = false; break; }
        if (same) return new Node(v == 1, true);

        int h = len / 2;
        return new Node(
            true, false,
            build(x, y, h),                 // topLeft
            build(x, y + h, h),             // topRight
            build(x + h, y, h),             // bottomLeft
            build(x + h, y + h, h)          // bottomRight
        );
    }
    Node* construct(vector<vector<int>>& grid) {
        g = grid;
        return build(0, 0, grid.size());
    }
};
```

## 解法二：二维前缀和优化"同值判定"

### 思路

解法一对每个区块都 O(len²) 扫一遍判同值，整体 O(n² log n)。若先预处理**二维前缀和**，则任意区块的和可 O(1) 求出：若该区块面积 = 和（全 1）或 = 0（全 0），即判定同值。这样总复杂度降到 O(n²)（前缀和 O(n²) + 每节点 O(1) 判定）。

适合追问"能否更快判定同值"时给出。

### 复杂度
- 时间复杂度: O(n²)，预处理前缀和 O(n²)，每个树节点判定 O(1)
- 空间复杂度: O(n²)，前缀和数组 + 递归栈 O(log n)

### 代码
```cpp
class Solution {
    vector<vector<int>> pre;   // 前缀和，下标从 1 开始
    int sum(int x1,int y1,int x2,int y2){       // 闭区间求和
        return pre[x2+1][y2+1]-pre[x1][y2+1]-pre[x2+1][y1]+pre[x1][y1];
    }
public:
    Node* build(int x,int y,int len){
        int s = sum(x,y,x+len-1,y+len-1);
        if (s == 0) return new Node(false, true);
        if (s == len*len) return new Node(true, true);
        int h = len/2;
        return new Node(true, false,
            build(x, y, h), build(x, y+h, h),
            build(x+h, y, h), build(x+h, y+h, h));
    }
    Node* construct(vector<vector<int>>& grid){
        int n = grid.size();
        pre.assign(n+1, vector<int>(n+1, 0));
        for (int i=0;i<n;++i)
            for (int j=0;j<n;++j)
                pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] - pre[i][j] + grid[i][j];
        return build(0, 0, n);
    }
};
```

## 总结

- 递归四分的坐标要小心：`len` 代表边长，四块分别取 `(x,y)`、`(x, y+h)`、`(x+h, y)`、`(x+h, y+h)`，其中 `h = len/2`。
- 全同值判定是高频开销点，可用**二维前缀和**优化到 O(1) 每块。
- `n` 保证是 2 的幂，因此总能整除以 2 到边长 1。

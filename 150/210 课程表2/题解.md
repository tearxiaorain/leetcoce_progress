# 210. 课程表 II

## 题目描述

> 你需要选修 `numCourses` 门课（编号 `0 ~ numCourses-1`）。先修关系由 `prerequisites` 给出，`prerequisites[i] = [a, b]` 表示"修课程 `a` 前必须先修完课程 `b`"。
> 返回**任意一种**学完所有课程的顺序；如果不可能修完所有课程（存在循环依赖），返回空数组。
> 例：`numCourses = 2, prerequisites = [[1,0]]` → `[0,1]`；`numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]` → `[0,2,1,3]`（或 `[0,1,2,3]`）。
> 数据范围：1 ≤ numCourses ≤ 2000，0 ≤ 先修对数 ≤ numCourses × (numCourses - 1) / 2。

## 解法一：Kahn 拓扑排序（BFS 剥入度 0 的点）

### 思路
把课程看成有向图：`b → a` 表示"先修 b 再修 a"。修课顺序其实就是图的**拓扑序**：

1. 统计每门课的入度（还有几门先修课没修）；
2. 把所有入度为 0 的课放进队列（现在就能修）；
3. 每次从队首取出一门课放进答案，把它指向的后续课程入度减 1，减到 0 就入队；
4. 结束时若答案里的课程数等于 `numCourses`，就是合法顺序；否则有环，返回空数组。

因为每次取出的都是"当前所有先修条件已满足"的课，顺序天然合法；队列里随时可能有多门课可选，所以答案不唯一（题目允许任意一种）。

### 复杂度
- 时间复杂度: O(V + E)（V = numCourses，E = prerequisites.size()，每个点、每条边各处理一次）
- 空间复杂度: O(V + E)（邻接表 + 入度数组 + 队列 + 答案）

### 代码
```cpp
vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> next(numCourses);          // 邻接表: b -> 所有以 b 为先修的课
    vector<int> indeg(numCourses, 0);              // 入度：还剩几门先修课没修
    for (auto& p : prerequisites) {
        next[p[1]].push_back(p[0]);
        indeg[p[0]]++;
    }

    queue<int> q;
    for (int i = 0; i < numCourses; i++)
        if (indeg[i] == 0) q.push(i);              // 没有先修要求的课先入队

    vector<int> order;
    order.reserve(numCourses);
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        order.push_back(cur);                      // 这门课现在可以修
        for (int nxt : next[cur])
            if (--indeg[nxt] == 0) q.push(nxt);    // 先修全部满足，可以修了
    }
    return (int)order.size() == numCourses ? order : vector<int>{};   // 有环则长度不够
}
```

## 解法二：DFS 三色标记 + 逆后序

### 思路
DFS 有一个经典结论：**对图做完深度优先遍历后，把节点按"完成时间"从晚到早排列，得到的就是拓扑序**（即后序遍历结果的逆序）。

为了顺便判环，用三种颜色记录状态：

- `0` 未访问；
- `1` 正在当前 DFS 路径上（访问中）；
- `2` 已完成（它出发的所有路径都探过且无环）。

DFS 时若遇到状态为 `1` 的点，说明沿有向边绕回了当前路径 → 有环，直接返回失败。每个节点在"完成"时压入答案数组，最后把数组 `reverse` 就是修课顺序。

### 复杂度
- 时间复杂度: O(V + E)（每个点、每条边各访问一次）
- 空间复杂度: O(V + E)（邻接表 + 颜色数组 + 递归栈最深 O(V)）

### 代码
```cpp
vector<vector<int>> g;
vector<int> color;                                  // 0 未访问, 1 访问中, 2 已完成
vector<int> order;
bool hasCycle = false;

void dfs(int cur) {
    color[cur] = 1;                                 // 进入当前路径
    for (int nxt : g[cur]) {
        if (color[nxt] == 1) { hasCycle = true; return; }        // 绕回路径上的点 → 有环
        if (color[nxt] == 0) { dfs(nxt); if (hasCycle) return; }
    }
    color[cur] = 2;                                 // 该点出发无环，完成
    order.push_back(cur);                           // 后序：完成时记录
}

vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
    g.assign(numCourses, {});
    color.assign(numCourses, 0);
    order.clear();
    hasCycle = false;
    for (auto& p : prerequisites) g[p[1]].push_back(p[0]);       // b -> a

    for (int i = 0; i < numCourses; i++) {
        if (color[i] == 0) { dfs(i); if (hasCycle) return {}; }
    }
    reverse(order.begin(), order.end());            // 后序的逆序才是拓扑序
    return order;
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| Kahn 拓扑排序 | O(V+E) | O(V+E) | 迭代实现、无递归栈，顺带能反映"同时可选"的课 |
| DFS 三色 + 逆后序 | O(V+E) | O(V+E) | 代码短，注意"完成时入栈 + 最后反转"这个细节 |

> 与 207 题的关系：207 只问"能不能修完"（判环即可），210 还要给出顺序；207 的两种解法在这里都能直接改成"顺带输出顺序"。

# 530. 二叉搜索树的最小绝对差
## 题目描述
> 给你一个二叉搜索树的根节点 `root`，返回树中任意两个不同节点值之间的最小差值。差值是一个正数，其数值等于两值之差的绝对值。

## 解法一: 中序遍历收集有序数组
**思路**：二叉搜索树的中序遍历序列是严格递增的，任意两个节点值的最小绝对差一定出现在**相邻元素**之间。先把中序遍历结果收集到数组，再遍历数组求相邻元素差的最小值。

**复杂度**：
- 时间复杂度：O(n)，中序遍历 + 一次数组扫描。
- 空间复杂度：O(n)，存放所有节点值的数组。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        vector<int> vals;
        inorder(root, vals);
        int ans = INT_MAX;
        for (int i = 1; i < vals.size(); i++)
            ans = min(ans, vals[i] - vals[i - 1]);
        return ans;
    }

    void inorder(TreeNode* node, vector<int>& vals) {
        if (node == nullptr) return;
        inorder(node->left, vals);
        vals.push_back(node->val);
        inorder(node->right, vals);
    }
};
```

## 解法二: 中序遍历实时比较（记录前驱节点）
**思路**：无需收集数组。中序遍历过程中维护"上一个访问的节点" `prev`，每次访问当前节点时用 `node->val - prev->val` 更新答案。由于中序递增，当前节点必然大于前驱，直接相减即可。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        int ans = INT_MAX;
        TreeNode* prev = nullptr;
        inorder(root, prev, ans);
        return ans;
    }

    void inorder(TreeNode* node, TreeNode*& prev, int& ans) {
        if (node == nullptr) return;
        inorder(node->left, prev, ans);
        if (prev) ans = min(ans, node->val - prev->val);  // 与前驱比较
        prev = node;
        inorder(node->right, prev, ans);
    }
};
```

## 解法三: Morris 中序遍历（O(1) 空间）
**思路**：用线索二叉树实现无栈、无递归的中序遍历，遍历过程中同样维护前驱 `prev` 并实时更新最小差，将空间降到 O(1)。

**复杂度**：
- 时间复杂度：O(n)，每个节点均摊常数次访问。
- 空间复杂度：O(1)，仅用少量指针变量。

```cpp
class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        int ans = INT_MAX;
        TreeNode* cur = root;
        TreeNode* prev = nullptr;
        while (cur) {
            if (cur->left == nullptr) {
                if (prev) ans = min(ans, cur->val - prev->val);
                prev = cur;
                cur = cur->right;
            } else {
                TreeNode* pre = cur->left;
                while (pre->right && pre->right != cur) pre = pre->right;
                if (pre->right == nullptr) {
                    pre->right = cur;
                    cur = cur->left;
                } else {
                    pre->right = nullptr;
                    if (prev) ans = min(ans, cur->val - prev->val);
                    prev = cur;
                    cur = cur->right;
                }
            }
        }
        return ans;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 中序 + 有序数组 | O(n) | O(n) | 相邻元素差取最小 |
| 中序实时比较 | O(n) | O(h) | 记录前驱，边遍历边更新 |
| Morris 中序遍历 | O(n) | O(1) | 线索二叉树，无额外空间 |

> 推荐解法二（中序实时比较），利用 BST 中序递增 + "最小差必在相邻" 的性质，O(n)/O(h) 且无需数组。解法三（Morris）在要求 O(1) 空间时使用。

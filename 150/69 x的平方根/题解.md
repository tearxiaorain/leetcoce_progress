# 69. x 的平方根

## 题目描述
> 给你一个非负整数 `x`，计算并返回 `x` 的算术平方根。由于返回类型是整数，结果只保留整数部分，小数部分将被舍去。
> 不允许使用任何内置指数函数和算符（如 `pow(x, 0.5)` 或 `x ** 0.5`）。

## 解法一: 二分查找

### 思路
在 `[0, x]` 范围内二分搜索，找到最大的整数 `mid` 满足 `mid² <= x`。
- 若 `mid² == x`，直接返回 mid
- 若 `mid² < x`，记录 mid 并向右侧搜索
- 若 `mid² > x`，向左侧搜索
- 注意 `mid²` 可能溢出 int，用 `long long` 存储

### 复杂度
- 时间复杂度: O(log x)
- 空间复杂度: O(1)

### 代码
```cpp
int mySqrt(int x) {
    if (x <= 1) return x;
    int l = 0, r = x;
    int ans = 0;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        long long sq = (long long)mid * mid;
        if (sq == x) return mid;
        if (sq < x) {
            ans = mid;
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return ans;
}
```

## 解法二: 牛顿迭代法

### 思路
求 `√x` 等价于求 `f(t) = t² - x` 的正根。使用牛顿法迭代：
- 迭代公式：`t = (t + x / t) / 2`
- 从 `t = x` 开始，当 `t² <= x` 时停止
- 收敛速度极快，每次迭代精度翻倍

### 复杂度
- 时间复杂度: O(log log x)，收敛非常快
- 空间复杂度: O(1)

### 代码
```cpp
int mySqrt(int x) {
    if (x <= 1) return x;
    long long t = x;
    while (t * t > x) {
        t = (t + x / t) / 2;
    }
    return (int)t;
}
```

## 解法三: 袖珍计算器算法

### 思路
利用指数和对数关系：`√x = e^{½ · ln x}`，但由于浮点精度问题，需要判断 `ans` 和 `ans+1` 哪个才是正确答案。

### 复杂度
- 时间复杂度: O(1)
- 空间复杂度: O(1)

### 代码
```cpp
int mySqrt(int x) {
    if (x <= 1) return x;
    int ans = (int)exp(0.5 * log(x));
    return ((long long)(ans + 1) * (ans + 1) <= x) ? ans + 1 : ans;
}
```

## 总结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 二分查找 | O(log x) | O(1) | 经典解法，稳定可靠 |
| 牛顿迭代 | O(log log x) | O(1) | 收敛极快，工业常用 |
| 袖珍计算器 | O(1) | O(1) | 依赖浮点精度，需修正 |

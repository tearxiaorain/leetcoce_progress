# 69. x 的平方根 — 代码点评

## 使用的方法

代码中提供了两个版本：

1. **`mySqrt1`**: 线性搜索法 — 从 2 到 x 逐个检查 `i*i > x`
2. **`mySqrt`**: 二分查找法 — 在 [0, x] 范围二分搜索目标平方根

两者均用查表法处理 x≤4 的小数情况。

## 复杂度分析

### mySqrt1（线性搜索）
- 时间复杂度: **O(√x)** — 约 46340 次循环（√2³¹ ≈ 46341），勉强可过但非最优
- 空间复杂度: **O(1)**

### mySqrt（二分查找）
- 时间复杂度: **O(log x)** — 约 31 次循环
- 空间复杂度: **O(1)**

## 代码评价

### 优点
- 小数（0-4）查表快速返回，减少不必要的循环
- 二分查找版本逻辑结构正确，能用 `le`/`ri`/`mid` 正确推进搜索区间
- `mySqrt1` 用 `long long i` 避免了乘法溢出

### 可改进之处
1. **整数溢出（mySqrt）**: 第 36 行 `mid*mid<x` 和第 40 行 `mid*mid>x` 中，`mid` 是 `int`，`mid*mid` 也是 `int` 乘法，会溢出。例如 `x = INT_MAX` 时 `mid` 可能很大导致溢出，比较结果错误。应改为 `(long long)mid * mid`
2. **二分边界未记录 ans**: 没有用 `ans` 变量记录满足条件的结果，而是靠末尾 `if(mid*mid>x)` 判断修正。在 `mid*mid == x` 时正确，但 `mid*mid < x` 的最终情况依赖 `while` 退出后的 `mid` 值和额外判断，不够稳健。建议在 `mid*mid < x` 时记录 `ans = mid`
3. **`le` 和 `ri` 初始化可优化**: `ri = x` 对于大数范围正确，但可缩到 `ri = min(x, 46340)`（因为 √2³¹ ≈ 46340）
4. **冗余变量/函数**: `mySqrt1` 中的 `q` 定义即有默认值 0；`main` 中的 `n`/`arr` 是固定测试代码，每次复制

### 代码风格
- `le`/`ri` 命名简短但不影响阅读
- `mySqrt1` 的 `q` 变量初始化 `int q=0` 后被覆盖，无关紧要但多余
- 两个版本共存方便对比，但提交时应只保留一个

## 修正后的二分查找参考
```cpp
int mySqrt(int x) {
    if (x <= 1) return x;
    int l = 0, r = x, ans = 0;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        long long sq = (long long)mid * mid;
        if (sq == x) return mid;
        if (sq < x) { ans = mid; l = mid + 1; }
        else r = mid - 1;
    }
    return ans;
}
```

## 总结
> 二分查找方向正确，但有 int 乘法溢出隐患。mySqrt1 线性搜索可用但不推荐。建议改用 `long long` 防溢出 + 记录 ans 的稳健写法。

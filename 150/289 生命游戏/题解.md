# 289. 生命游戏

## 题目描述
> 给定一个 `m x n` 的网格面板，每个格子可以是活的（1）或死的（0）。根据以下四条规则同时更新每个细胞的状态：
> 1. 活细胞周围有少于2个活邻居 → 死亡
> 2. 活细胞周围有2或3个活邻居 → 存活
> 3. 活细胞周围有超过3个活邻居 → 死亡
> 4. 死细胞周围恰好有3个活邻居 → 复活
>
> 要求**原地**更新，同时所有更新必须同时发生。

## 解法一: 复制面板法
### 思路
创建一个与原面板相同大小的副本，在原面板上统计邻居（使用副本数据），将新状态写入原面板。这样避免了"读脏数据"问题。

### 复杂度
- 时间复杂度: O(m * n)，遍历每个细胞及其 8 个邻居
- 空间复杂度: O(m * n)，需要完整副本
### 代码
```cpp
class Solution {
public:
    void gameOfLife(vector<vector<int>>& board) {
        int m = board.size(), n = board[0].size();
        auto copy = board;
        int dx[8] = {-1,-1,-1,0,0,1,1,1};
        int dy[8] = {-1,0,1,-1,1,-1,0,1};
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int live = 0;
                for (int d = 0; d < 8; d++) {
                    int ni = i + dx[d], nj = j + dy[d];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && copy[ni][nj] == 1)
                        live++;
                }
                if (copy[i][j] == 1) {
                    if (live < 2 || live > 3) board[i][j] = 0;
                } else {
                    if (live == 3) board[i][j] = 1;
                }
            }
        }
    }
};
```

## 解法二: 状态标记法（原地解法）
### 思路
在原数组上用额外状态标记转换过程，避免使用额外空间：
- `2` 表示原来是活的（1），将要变成死的（0）—— 活 → 死
- `3` 表示原来是死的（0），将要变成活的（1）—— 死 → 活

统计邻居时，`board[ni][nj] == 1` 或 `board[ni][nj] == 2` 都算活细胞（因为它们原来是活的）。全部统计完后，将 `2 → 0`，`3 → 1`。

### 复杂度
- 时间复杂度: O(m * n)
- 空间复杂度: O(1)
### 代码
```cpp
class Solution {
public:
    void gameOfLife(vector<vector<int>>& board) {
        int m = board.size(), n = board[0].size();
        int dx[8] = {-1,-1,-1,0,0,1,1,1};
        int dy[8] = {-1,0,1,-1,1,-1,0,1};
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int live = 0;
                for (int d = 0; d < 8; d++) {
                    int ni = i + dx[d], nj = j + dy[d];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                        if (board[ni][nj] == 1 || board[ni][nj] == 2)
                            live++;
                    }
                }
                if (board[i][j] == 1) {
                    if (live < 2 || live > 3) board[i][j] = 2; // 活→死
                } else {
                    if (live == 3) board[i][j] = 3; // 死→活
                }
            }
        }
        // 将标记转换为最终状态
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 2) board[i][j] = 0;
                else if (board[i][j] == 3) board[i][j] = 1;
            }
        }
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 复制面板 | O(m*n) | O(m*n) | 逻辑直观，不易出错 | 额外空间大 |
| 状态标记 | O(m*n) | O(1) | 原地操作，空间最优 | 需要额外状态编码，略复杂 |

# 74. 搜索二维矩阵

## 题目描述

编写一个高效的算法来判断 `m x n` 矩阵中，是否存在一个目标值。该矩阵具有如下特性：

- 每行中的整数从左到右按非递减顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

## 解法一：全局二分查找（二维转一维）

### 思路

由于每行有序且行间连续（下一行首元素 > 上一行末元素），整个矩阵可以看成一个长度为 `m * n` 的一维有序数组。

对于下标 `idx`，它在矩阵中的位置为：
- 行：`row = idx / n`
- 列：`col = idx % n`

直接在这个虚拟一维数组上进行二分查找。

### 复杂度

- 时间复杂度：O(log(mn))
- 空间复杂度：O(1)

### C++ 代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int left = 0, right = m * n - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int val = matrix[mid / n][mid % n];
            if (val == target) return true;
            if (val < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return false;
    }
};
```

## 解法二：两次二分（先定行，再定列）

### 思路

1. 先对第一列做二分查找，找到 target 可能所在的行（最后一个首元素 <= target 的行）
2. 再对该行做标准二分查找

### 复杂度

- 时间复杂度：O(log m + log n) = O(log(mn))
- 空间复杂度：O(1)

### C++ 代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();

        // 第一次二分：找目标行
        int top = 0, bottom = m - 1;
        while (top <= bottom) {
            int mid = top + (bottom - top) / 2;
            if (matrix[mid][0] == target) return true;
            if (matrix[mid][0] < target) {
                top = mid + 1;
            } else {
                bottom = mid - 1;
            }
        }
        int row = bottom; // 目标行
        if (row < 0) return false;

        // 第二次二分：在目标行中查找
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (matrix[row][mid] == target) return true;
            if (matrix[row][mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return false;
    }
};
```

## 解法三：右上角搜索（Z 字形查找）

### 思路

从矩阵的**右上角**开始：

- 若当前值 == target，返回 true
- 若当前值 > target，往左移一列（排除当前列）
- 若当前值 < target，往下移一行（排除当前行）

最多移动 `m + n` 步。

### 复杂度

- 时间复杂度：O(m + n)
- 空间复杂度：O(1)

### C++ 代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int row = 0, col = n - 1; // 右上角
        while (row < m && col >= 0) {
            if (matrix[row][col] == target) return true;
            if (matrix[row][col] > target) {
                col--;
            } else {
                row++;
            }
        }
        return false;
    }
};
```

> 注：解法三充分利用了矩阵的行内有序和行间有序两个特性，即使不满足"下一行首元素 > 上一行末元素"的严格条件也能工作。而解法一、二依赖该严格条件。

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心技巧 |
|------|-----------|-----------|---------|
| 全局二分 | O(log(mn)) | O(1) | 二维坐标映射一维下标 |
| 两次二分 | O(log m + log n) | O(1) | 先定行再定列 |
| 右上角搜索 | O(m + n) | O(1) | Z字形缩小搜索空间 |

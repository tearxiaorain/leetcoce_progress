# 74. 搜索二维矩阵 — 代码点评

## 用户算法概述

用户采用全局二分查找法：将 `m x n` 二维矩阵映射为一个长度为 `m * n` 的一维有序数组，通过下标转换 `row = mid / n`, `col = mid % n` 在虚拟一维数组上进行标准二分查找。

## 用户复杂度分析

- 时间复杂度：O(log(mn)) — 在长度为 mn 的有序序列上二分
- 空间复杂度：O(1) — 仅使用几个整型变量

## 代码质量评价

### 优点

1. **思路正确**：全局二分是本题的最优解法，时间 O(log(mn))，空间 O(1)
2. **下标映射准确**：`r = mid / n`, `c = mid % n` 的二维坐标转换完全正确
3. **整体逻辑清晰**：标准二分模板 + 二维坐标转换，结构简洁

### 可改进之处

1. **无效的 mid 初始化**

```cpp
int mid = right / 2;
```

这个初始值在进入 while 循环后会被 `mid = (left + right) / 2` 立即覆盖，属于无效代码。

2. **循环外的冗余计算**

```cpp
int r = mid / n;
int c = mid % n;
if (matrix[r][c] == target) return true;
return false;
```

当 while 循环因 `left > right` 正常退出（未找到 target）时，`mid` 指向的是最后一次检查的位置，而不是 target 应该所在的位置。虽然 `matrix[r][c] == target` 判断会正确处理（返回 false），但这里可以简化为直接 `return false`。

不过，当循环通过 `break` 退出（即找到 target）时，此处再次检查是冗余的——可以改为在循环内直接 `return true`。

3. **偶数分界可能溢出**

```cpp
mid = (left + right) / 2;
```

虽在本题数据范围内不会溢出，但更安全的写法是 `mid = left + (right - left) / 2`。

### 测试用例

`main()` 中使用 3x4 矩阵 `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]` 搜索 `2`，结果正确（返回 false/0）。但建议补充更多场景：
- target 在矩阵中存在
- target 小于所有元素
- target 大于所有元素
- 单行 / 单列矩阵

用户的实现**本质正确**，采用全局二分法达到了最优复杂度 O(log(mn)) O(1)。代码存在些许可优化的细节（无效初始化、冗余计算），但不影响正确性。整体而言是一份高质量的解答。

# 108. 将有序数组转换为二叉搜索树 — 代码点评

## 使用的方法
递归分治：以 `merge(nums, l, r)` 在区间内建树——对特判过的小区间直接处理，大区间取 `mid=(l+r)/2` 后把左半边 `[l,mid]` 交给左子树、右半边 `[mid+2, r]` 交给右子树，根取 `nums[mid+1]`。

## 复杂度分析
- 时间复杂度: O(n)，每个元素恰好建一次节点（无数组拷贝）
- 空间复杂度: O(log n)，递归调用栈深度（树大致平衡）

## 代码评价
- 优点:
  - 思路正确，样例 `[-10,-3,0,5,9]` 能构造出中序与原数组一致的 BST，且高度差 ≤ 1
  - 只建节点不做数组拷贝，空间上比"拷贝子数组"的做法优
- 可改进之处:
  - **边界特判过多**：`l==r`、`l==r-1`、`l==r-2` 三套手写逻辑让主递归被掩盖，可统一成 `if (l > r) return nullptr; mid=(l+r)/2;` 的标准递归，代码量减半且更不易错
  - 函数名 `merge` 有误导性——这里没有"合并"，叫 `build/construct` 更贴切
  - 取根用 `nums[mid+1]`、左半 `[l,mid]`、右半 `[mid+2,r]` 的"跳过 mid"写法反直觉，不如直接 `root=nums[mid]`、左右各取 `mid±1`，平衡性也更好证明
  - `(l+r)/2` 建议写 `l+(r-l)/2` 防大整数溢出
- 代码风格: 结构清晰、注释可再补足平衡性说明

## 总结
> 分治取中点构造 BST 的主干是对的，主要是把特殊情况"手工展开"导致代码冗余，收敛成一条 `if(l>r) return null` 的递归即可。

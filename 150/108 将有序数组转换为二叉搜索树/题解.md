# 108. 将有序数组转换为二叉搜索树

## 题目描述

> 给定一个**升序排列**的整数数组 `nums`，将它转换为一棵**高度平衡**的二叉搜索树（BST）。
> 高度平衡指：每个节点的左右子树高度差绝对值不超过 1。
> 输入：`nums = [-10, -3, 0, 5, 9]`；输出：任一棵满足条件的根节点即可。

核心要求：把有序数组映射成 BST，等价于 **中序遍历结果等于该数组** 的二叉树，且要尽量平衡。

## 解法一：递归（取中间元素为根）

### 思路

BST 中序遍历是升序，所以数组的**中间元素**天然是某个子树的根：左半边全是比它小的值 → 左子树，右半边全是比它大的值 → 右子树。

对区间 `[l, r]`：
1. 取 `mid = (l + r) / 2`，用 `nums[mid]` 建根节点
2. 递归构造左子树（`[l, mid-1]`）和右子树（`[mid+1, r]`）

每次均匀对半分，保证树高为 `O(log n)`，天然满足"高度平衡"。取 `l + (r-l)/2` 可避免大数溢出。

### 复杂度
- 时间复杂度: O(n)，每个元素恰好被访问一次建节点
- 空间复杂度: O(log n)，递归栈深度 = 树高

### 代码
```cpp
class Solution {
public:
    TreeNode* build(vector<int>& nums, int l, int r) {
        if (l > r) return nullptr;
        int mid = l + (r - l) / 2;          // 取中间元素做根
        TreeNode* root = new TreeNode(nums[mid]);
        root->left  = build(nums, l, mid - 1);   // 左半边 → 左子树
        root->right = build(nums, mid + 1, r);   // 右半边 → 右子树
        return root;
    }
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums, 0, (int)nums.size() - 1);
    }
};
```

## 解法二：迭代法（显式栈模拟递归）

### 思路

把递归的"调用栈"搬到显式栈上：栈内存三元组 `(父节点, 区间[l,r], 左右方向)`。每次弹出一个区间，创建节点并接到父节点上，再把左右子区间压栈。

本质上与解法一同构，只是用栈避免递归，适合需要显式控制栈空间或面试追问"不用递归怎么写"的场景。工程上写法较繁琐，作为对解法一的理解加深。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(log n)，栈深度 ≤ 树高（最坏仍平衡）

### 代码
```cpp
class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        if (nums.empty()) return nullptr;
        // 栈元素: {父节点, 区间左, 区间右, isLeft(1=接到左 0=接到右)}
        using T = tuple<TreeNode*, int, int, bool>;
        stack<T> st;
        int n = nums.size();
        TreeNode* dummy = new TreeNode(0);          // 哨兵根，最后返回其左孩子
        st.push({dummy, 0, n - 1, true});

        while (!st.empty()) {
            auto [par, l, r, isLeft] = st.top(); st.pop();
            if (l > r) continue;
            int mid = l + (r - l) / 2;
            TreeNode* cur = new TreeNode(nums[mid]);
            if (isLeft) par->left = cur; else par->right = cur;
            st.push({cur, mid + 1, r, false});      // 先压右，栈后进先出则先处理左
            st.push({cur, l, mid - 1, true});
        }
        TreeNode* root = dummy->left;
        delete dummy;
        return root;
    }
};
```

## 总结

- 抓住"**BST 中序 = 升序**"这一性质，取中点分治即可。
- 取 `mid = l + (r-l)/2` 不仅是惯例，也能稳定构造平衡树。

# 173. 二叉搜索树迭代器

## 题目描述

> 实现一个 `BSTIterator` 类，表示一个按**中序遍历**顺序遍历二叉搜索树 `root` 的迭代器：
> - `BSTIterator(TreeNode* root)`：初始化对象，指针指向中序序列第一个（最小）元素之前；
> - `int next()`：把指针移到下一个元素并返回它的值（相当于按从小到大依次取出）；
> - `bool hasNext()`：指针是否还能继续右移。
> 要求 `next()` 与 `hasNext()` 的**均摊**时间复杂度为 O(1)，空间复杂度 O(h)（h 为树高）。
> 例：`root = [7,3,15,null,null,9,20]` 依次 `next()` 得到 3、7、9、15、20。

## 解法一：构造时一次性中序展开到数组

### 思路
最直接的思路：构造对象时做一次完整的中序遍历，把节点值按升序存进 `vector`，再用一个下标指向当前元素的位置。

- `next()`：返回 `nums[idx++]`，O(1)；
- `hasNext()`：判断 `idx < nums.size()`，O(1)。

缺点是初始化就把整棵树读完，空间 O(n) 而不是题目要求的 O(h)；如果中途不再使用迭代器，这些工作就白做了。

### 复杂度
- 时间复杂度: 构造 O(n)，`next` / `hasNext` 均摊 O(1)
- 空间复杂度: O(n)

### 代码
```cpp
class BSTIterator {
public:
    BSTIterator(TreeNode* root) { inorder(root); }

    int next() { return nums[idx++]; }

    bool hasNext() { return idx < (int)nums.size(); }

private:
    vector<int> nums;                       // 中序序列（升序）
    int idx = 0;                            // 下一个待取元素的下标

    void inorder(TreeNode* node) {
        if (!node) return;
        inorder(node->left);
        nums.push_back(node->val);
        inorder(node->right);
    }
};
```

## 解法二：显式栈模拟中序（推荐）

### 思路
递归中序遍历的调用栈，本质上就是"沿着左链一路压栈、弹出后转向右子树"。把这条栈自己维护起来，就能按需产出元素：

- 构造函数：从根出发，把整条左链压栈（栈底到栈顶 = 从最小元素往上）；
- `next()`：弹出栈顶（这就是当前最小未访问节点），**再把它右子树的左链压栈**，返回该节点的值；
- `hasNext()`：栈非空即还有元素。

每个节点一生只被压栈、弹栈各一次，所以 n 次 `next()` 总共 O(n)，均摊 O(1)；栈的深度不超过树高 h。

### 复杂度
- 时间复杂度: 构造 O(h)，`next` 均摊 O(1)，`hasNext` O(1)
- 空间复杂度: O(h)

### 代码
```cpp
class BSTIterator {
public:
    BSTIterator(TreeNode* root) { pushLeft(root); }

    int next() {
        TreeNode* cur = st.top(); st.pop();
        pushLeft(cur->right);               // 转向右子树，继续压左链
        return cur->val;
    }

    bool hasNext() { return !st.empty(); }

private:
    stack<TreeNode*> st;

    void pushLeft(TreeNode* node) {         // 把一条左链全部压栈
        while (node) {
            st.push(node);
            node = node->left;
        }
    }
};
```

## 小结

| 解法 | 构造 | next / hasNext | 空间 | 说明 |
|------|------|----------------|------|------|
| 中序展开数组 | O(n) | O(1) | O(n) | 最简单，但不满足 O(h) 空间要求 |
| 显式栈模拟中序 | O(h) | 均摊 O(1) | O(h) | 本题标准解，懒加载、随取随算 |

> 延伸：如果想做到 O(1) 额外空间，可用 Morris 中序遍历（借右空指针做线索）——它在不修改树结构的解法里空间最优，但会临时改动指针，实现起来更绕。

# 64. 最小路径和 — 代码点评

## 使用的方法
**一维滚动数组 DP**。与 63 题相同模式：两个 `int*` 数组 + `swap`，`arr` 存上一行，`brr` 存当前行，取 `min(上方, 左方) + 当前值`。

## 复杂度分析
- 时间复杂度: **O(m×n)**
- 空间复杂度: **O(n)**

## 代码评价

### 优点
- 空间优化到 O(n)，与 63 题风格统一
- DP 转移逻辑正确：`brr[j] = min(上(arr[j]), 左(brr[j-1])) + grid[i][j]`
- 与 63 题代码结构高度一致，风格统一

### 可改进之处
1. **内存泄漏**: `new int[n]` 未 `delete[]`
2. **多余初始化**: `l1 = INT_MAX; l2 = INT_MAX;` 后立即被覆盖，INT_MAX 赋值无意义
3. **手动 min 啰嗦**: `if (l2 < l1) brr[j] = l2` 不如 `brr[j] = min(l1, l2)`
4. **冗余 include**: stack、map、set 等未使用

### 代码风格
- 与 63 题高度一致的模板化写法，形成个人风格
- 变量名 `l1`/`l2` 不如 `fromLeft`/`fromUp` 直观

## 总结
> 滚动数组 DP 正确，代码结构清晰。仅需处理内存泄漏和简化 min 写法。

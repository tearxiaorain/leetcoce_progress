# 64. 最小路径和

## 题目描述
> 给定一个 `m x n` 的非负整数网格，从左上角出发，只能向右或向下移动，求到达右下角的最小路径和。

## 解法一: 动态规划（二维）

### 思路
`dp[i][j]` = 到达 `(i, j)` 的最小路径和：
- `dp[0][0] = grid[0][0]`
- 第一行: `dp[0][j] = dp[0][j-1] + grid[0][j]`
- 第一列: `dp[i][0] = dp[i-1][0] + grid[i][0]`
- 其他: `dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`

### 复杂度
- 时间复杂度: O(m×n)
- 空间复杂度: O(m×n)

### 代码
```cpp
int minPathSum(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n, 0));
    dp[0][0] = grid[0][0];
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j-1] + grid[0][j];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i-1][0] + grid[i][0];
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
    return dp[m-1][n-1];
}
```

## 解法二: 原地修改 + 一维DP

### 思路
直接在原数组上修改，用 `grid[i][j]` 本身存储最小路径和。或进一步压缩为一维 DP 数组。

### 复杂度
- 时间复杂度: O(m×n)
- 空间复杂度: O(1)（原地）/ O(n)（一维）

### 代码
```cpp
// 原地修改
int minPathSum(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    for (int j = 1; j < n; j++) grid[0][j] += grid[0][j-1];
    for (int i = 1; i < m; i++) grid[i][0] += grid[i-1][0];
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            grid[i][j] += min(grid[i-1][j], grid[i][j-1]);
    return grid[m-1][n-1];
}
```

## 总结

| 解法 | 时间 | 空间 |
|------|------|------|
| 二维DP | O(m×n) | O(m×n) |
| 原地修改 | O(m×n) | O(1) |

# 121. 买卖股票的最佳时机 — 代码点评

## 使用的方法
一次遍历 + 贪心，维护历史最低价格的下标 `ind`，每次遇到更低的价格则更新买入点，否则计算当前卖出利润并更新最大值。

## 复杂度分析
- 时间复杂度: O(n)，遍历一次数组
- 空间复杂度: O(1)，只使用常数额外空间

## 代码评价
- 优点: 思路清晰正确，本质就是经典的一次遍历法；用下标 `ind` 追踪最低价，逻辑直观；时间复杂度已达最优。
- 可改进之处:
  1. 变量命名不够规范：`max` 与标准库宏/函数同名，建议改为 `maxProfit` 或 `ans`；`ind` 建议改为 `minIdx` 或 `buy`。
  2. 代码可进一步简化：直接用 `minPrice` 存储最低价格值而不是下标，可以省去 `prices[ind]` 的间接访问。
  3. `max` 变量可以初始化为 0，当价格单调递减时返回 0 符合题意（不交易），此逻辑正确。
  4. main 函数中拼写错误：`prises` 应为 `prices`。
- 代码风格: 整体结构尚可，但建议使用更规范的代码格式化（如 `if` 后的空格），并去掉无用的 `<algorithm>` 头文件。

## 总结
> 算法思路完全正确，用 O(n) 一次遍历解决问题，小幅改进命名和精简代码即可。

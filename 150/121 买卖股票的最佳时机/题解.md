# 121. 买卖股票的最佳时机

## 题目描述
> 给定一个数组 prices，其中 prices[i] 表示第 i 天的股票价格。你只能选择某一天买入这只股票，并选择在未来的某一天卖出。设计一个算法计算你所能获取的最大利润。如果无法获取任何利润，返回 0。

## 解法一: 暴力枚举法
### 思路
枚举所有买入日和卖出日的组合，计算每一对 (i,j) (i < j) 的利润 `prices[j] - prices[i]`，取最大值。

### 复杂度
- 时间复杂度: O(n^2)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        int maxProfit = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int profit = prices[j] - prices[i];
                if (profit > maxProfit) {
                    maxProfit = profit;
                }
            }
        }
        return maxProfit;
    }
};
```

## 解法二: 一次遍历（贪心DP）
### 思路
遍历价格数组，同时维护两个值：
1. `minPrice`：到目前为止遇到的最低价格（最佳买入点）。
2. `maxProfit`：到目前为止的最大利润。

对于每一天的价格，计算"如果今天卖出能获得的利润"，即 `prices[i] - minPrice`，并更新最大利润。同时更新最低价格。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minPrice = INT_MAX;
        int maxProfit = 0;
        
        for (int price : prices) {
            // 更新最低买入价
            minPrice = min(minPrice, price);
            // 计算当前利润并更新最大利润
            maxProfit = max(maxProfit, price - minPrice);
        }
        
        return maxProfit;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n^2) | O(1) | 暴力枚举所有买入卖出对 |
| 解法二 | O(n) | O(1) | 一次遍历维护最小值和最大利润 |

解法二是经典解法，本质是 DP 思想的压缩：`dp[i]` 表示前 i 天的最大利润，`dp[i] = max(dp[i-1], prices[i] - minPrice)`，最终只用两个变量即可。

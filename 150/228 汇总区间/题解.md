# 228. 汇总区间

## 题目描述
> 给定一个无重复元素的有序整数数组 `nums`，返回恰好覆盖数组中所有数字的最小有序区间范围列表。即 `nums` 的每个元素都恰好被某个区间范围覆盖，并且不存在属于某个范围但不属于 `nums` 的数字。例如 `[0,1,2,4,5,7]` 返回 `["0->2","4->5","7"]`。

## 解法一: 一次遍历 + 双指针
### 思路
使用两个指针 `start` 和 `end` 标记当前连续区间的起止位置。遍历数组：
- 如果 `nums[i]` 与 `nums[i-1]` 连续（差值为 1），扩展 end
- 如果不连续，将当前区间 `[start, end]` 转化为字符串加入结果，然后重置 start 和 end 为当前元素
- 遍历结束后处理最后一个区间

### 复杂度
- 时间复杂度: O(n)，遍历一次数组
- 空间复杂度: O(1)，不计返回结果所用的空间
### 代码
```cpp
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> res;
        int n = nums.size();
        if (n == 0) return res;
        
        int start = 0;
        for (int i = 1; i <= n; i++) {
            if (i == n || nums[i] != nums[i - 1] + 1) {
                if (start == i - 1) {
                    res.push_back(to_string(nums[start]));
                } else {
                    res.push_back(to_string(nums[start]) + "->" + to_string(nums[i - 1]));
                }
                start = i;
            }
        }
        return res;
    }
};
```

## 解法二: while 循环区间扩展
### 思路
使用 while 循环，每次处理一个区间：从当前位置 `i` 开始，用 `j` 不断向后扩展直到不连续。然后根据 `i` 和 `j` 的关系构造字符串，将 `i` 更新为 `j + 1`。

### 复杂度
- 时间复杂度: O(n)，每个元素访问一次
- 空间复杂度: O(1)
### 代码
```cpp
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> res;
        int n = nums.size();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j + 1 < n && nums[j + 1] == nums[j] + 1) {
                j++;
            }
            if (i == j) {
                res.push_back(to_string(nums[i]));
            } else {
                res.push_back(to_string(nums[i]) + "->" + to_string(nums[j]));
            }
            i = j + 1;
        }
        return res;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 一次遍历+双指针 | O(n) | O(1) | 逻辑简洁，一气呵成 | 循环条件稍复杂（i <= n） |
| while区间扩展 | O(n) | O(1) | 思路直观，区间概念清晰 | 嵌套 while 循环 |

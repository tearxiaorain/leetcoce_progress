# 26. 删除有序数组中的重复项

## 题目描述
> 给定一个非严格递增排列的数组 nums，原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。要求 O(1) 额外空间（原地修改），元素的相对顺序保持不变。不需要考虑数组中超出新长度后面的元素。

## 解法一: 双指针法（快慢指针）
### 思路
使用快慢双指针。慢指针 i 指向已处理的不重复元素的最后一个位置，快指针 j 遍历整个数组。当 nums[j] != nums[i] 时，说明遇到了新元素，将其放在 i+1 的位置，并移动慢指针。

### 复杂度
- 时间复杂度: O(n)，遍历一次数组。
- 空间复杂度: O(1)，只使用两个指针。

### 代码
```cpp
#include <iostream>
#include <vector>
using namespace std;

int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    
    int i = 0;  // 慢指针，指向最后一个不重复元素
    for (int j = 1; j < nums.size(); j++) {
        if (nums[j] != nums[i]) {
            i++;
            nums[i] = nums[j];
        }
    }
    return i + 1;
}
```

## 解法二: 使用 STL unique
### 思路
直接利用 C++ STL 中的 `std::unique` 函数，它将重复元素移到末尾，返回新结尾的迭代器。虽然调用方便，但本质上是双指针的实现。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
int removeDuplicates(vector<int>& nums) {
    auto it = unique(nums.begin(), nums.end());
    return distance(nums.begin(), it);
}
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双指针法 | O(n) | O(1) | 经典解法，面试推荐 |
| STL unique | O(n) | O(1) | 代码极简，适合实际工程 |

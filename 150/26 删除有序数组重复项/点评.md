# 26. 删除有序数组中的重复项 — 代码点评

## 使用的方法
单指针 + 原地去重。使用 `count` 作为已去重元素的最后一个索引（从 0 开始，首个元素默认保留），遍历数组，每当 `nums[i] != nums[i-1]` 时将新元素放到 `nums[count]` 位置并递增 count，最后返回 `count + 1`。

## 复杂度分析
- 时间复杂度: O(n)，一次遍历完成。
- 空间复杂度: O(1)，原地修改，只使用常数额外空间。

## 代码评价
- 优点: 核心算法逻辑正确，单指针 + `if(i)` 处理边界使代码紧凑。
- 可改进之处: 
  1. `if (i)` 在循环内每次判断略显冗余——可以改为从 `i = 1` 开始循环，count 从 1 开始（第一个元素确定保留），避免每次迭代的条件判断。
  2. `return count + 1;` 后面的代码（输出循环和第二个 return）是死代码，永远不会执行，应清理。
  3. 变量名 `count` 容易误解为"重复个数"，实际上它表示"最后一个非重复元素的索引"，建议改为 `k` 或 `uniqueIdx`。
  4. 主逻辑写在 `main()` 函数中而非独立函数，应抽取为 `removeDuplicates` 函数以方便测试和复用。
- 代码风格: 逻辑基本清晰，但有死代码和命名歧义，代码组织不规范。

## 总结
> 双指针（快慢指针）思想掌握正确，实现可以更规范——抽取函数、清理死代码、从 i=1 开始避免 if(i) 判断。

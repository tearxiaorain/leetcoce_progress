# 146. LRU 缓存

## 题目描述

> 设计一个满足 LRU（最近最少使用）缓存约束的数据结构，实现 `LRUCache`：
> - `LRUCache(int capacity)` 以正整数初始化容量；
> - `int get(int key)`：关键字存在返回其值，否则返回 -1；
> - `void put(int key, int value)`：存在则更新值，不存在则插入；若容量已满，**逐出最久未使用**的关键字后插入。
>
> `get` 与 `put` 都必须以 **O(1)** 平均时间复杂度运行。

## 解法一: STL 实现——哈希表 + `std::list`

### 思路
LRU 需要同时支持"O(1) 找键"和"O(1) 调访问顺序 / 逐出最旧"，用三个容器配合：
- `unordered_map<int,int> val`：key → value，O(1) 判断存在与取值；
- `list<int> order`：按访问时间从新到旧存 key，头部 = 最近使用；
- `unordered_map<int,list<int>::iterator> pos`：key → 它在 order 中的迭代器，才能 O(1) 摘除。

`get`：命中则 `order.splice(order.begin(), order, pos[key])` 把该键提到头部并返回值。
`put`：命中则更新值并同样置顶；未命中且已满，先按尾部键删 `val/pos` 并 `pop_back`，再把新键 `push_front` 并登记。

### 复杂度
- 时间复杂度: O(1) 平均（哈希 O(1)，`list::splice` 常数）
- 空间复杂度: O(capacity)

### 代码
```cpp
class LRUCache {
    int cap;
    list<int> order;                                  // MRU...LRU
    unordered_map<int,int> val;                       // key->value
    unordered_map<int,list<int>::iterator> pos;       // key->迭代器
public:
    LRUCache(int capacity) : cap(capacity) {}
    int get(int key) {
        auto it = val.find(key);
        if (it == val.end()) return -1;
        order.splice(order.begin(), order, pos[key]); // 提到头
        return it->second;
    }
    void put(int key, int value) {
        if (auto it = val.find(key); it != val.end()) {
            it->second = value;
            order.splice(order.begin(), order, pos[key]);
            return;
        }
        if ((int)order.size() == cap) {               // 满则逐出 LRU
            int old = order.back(); order.pop_back();
            val.erase(old); pos.erase(old);
        }
        order.push_front(key);
        pos[key] = order.begin();
        val[key] = value;
    }
};
```

## 解法二: 手写双向链表 + 哈希定位（面试手写版）

### 思路
面试常要求不依赖 STL，自己维护一条双向链表，链表顺序即访问顺序，头 = 最近使用、尾 = 最久未使用：
- `unordered_map<int, Node*> pos`：key → 节点地址，命中时才能 **O(1) 定位**并把节点拆下插到头部；
- 节点存 key 与 value（key 用于逐出时反查哈希表）。

`get`：`pos` 命中 → 把该节点从原位置摘除、插到头部，返回值。
`put`：命中 → 更新值并置顶；未命中 → 若满，删尾节点并 `erase` 其 key，再复用它或新建节点插到头部。

手写版要点：哑节点避免头尾空指针特判；拆装节点时注意先补链再断链。

### 复杂度
- 时间复杂度: O(1) 平均（map 定位 O(1)，链表中部摘除 O(1)）
- 空间复杂度: O(capacity)

### 代码
```cpp
struct Node {
    int key, val;
    Node *prev, *next;
    Node(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
};

class LRUCache {
    int cap;
    unordered_map<int, Node*> pos;
    Node head, tail;                     // 哑节点：head.next = 最近使用
    void moveToHead(Node* p) {           // 摘除并插到头部
        p->prev->next = p->next;  p->next->prev = p->prev;
        p->next = head.next;      p->prev = &head;
        head.next->prev = p;      head.next = p;
    }
    void pushFront(int k, int v) {
        Node* p = new Node(k, v);
        p->next = head.next;  p->prev = &head;
        head.next->prev = p;  head.next = p;
    }
    void popBack() {                     // 逐出尾节点
        Node* p = tail.prev;
        p->prev->next = &tail;  tail.prev = p->prev;
        pos.erase(p->key); delete p;
    }
public:
    LRUCache(int capacity) : cap(capacity), head(0,0), tail(0,0) {
        head.next = &tail; tail.prev = &head;
    }
    int get(int key) {
        auto it = pos.find(key);
        if (it == pos.end()) return -1;
        moveToHead(it->second);
        return it->second->val;
    }
    void put(int key, int value) {
        auto it = pos.find(key);
        if (it != pos.end()) { it->second->val = value; moveToHead(it->second); return; }
        if ((int)pos.size() == cap) popBack();
        pushFront(key, value);
        pos[key] = head.next;
    }
};
```

# 101. 对称二叉树
## 题目描述
> 给你一个二叉树的根节点 `root`，检查它是否轴对称。轴对称意味着树的左子树和右子树互为镜像。

## 解法一: 递归（DFS 镜像比较）
**思路**：一棵树是对称的，当且仅当它的左子树与右子树互为镜像。定义辅助函数 `isMirror(t1, t2)` 判断两棵树是否互为镜像：
- 两个节点都为空 → 互为镜像；
- 只有一个为空 → 不是镜像；
- 两个节点值不同 → 不是镜像；
- 否则递归判断 `t1->left` 与 `t2->right`、`t1->right` 与 `t2->left` 是否互为镜像（交叉比较）。

最后返回 `isMirror(root->left, root->right)`。

**复杂度**：
- 时间复杂度：O(n)，每个节点恰好访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏情况（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        if (root == nullptr) return true;
        return isMirror(root->left, root->right);
    }

    bool isMirror(TreeNode* t1, TreeNode* t2) {
        if (t1 == nullptr && t2 == nullptr) return true;  // 都为空，互为镜像
        if (t1 == nullptr || t2 == nullptr) return false; // 只有一个为空
        if (t1->val != t2->val) return false;             // 值不同
        // 交叉比较：左的左 vs 右的右，左的右 vs 右的左
        return isMirror(t1->left, t2->right) && isMirror(t1->right, t2->left);
    }
};
```

## 解法二: 迭代（队列 BFS 成对比较）
**思路**：用队列维护"待比较的节点对"，每次出队两个节点，判断它们是否满足镜像条件；满足则把 `(t1->left, t2->right)` 和 `(t1->right, t2->left)` 两对入队继续比较。队列可以处理空节点，因此结构差异也能被发现。

**复杂度**：
- 时间复杂度：O(n)，每个节点对比较一次。
- 空间复杂度：O(n)，队列最多存储最宽一层的节点对数量。

```cpp
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        if (root == nullptr) return true;
        queue<TreeNode*> q;
        q.push(root->left);
        q.push(root->right);
        while (!q.empty()) {
            TreeNode* t1 = q.front(); q.pop();
            TreeNode* t2 = q.front(); q.pop();
            if (t1 == nullptr && t2 == nullptr) continue; // 都为空，继续
            if (t1 == nullptr || t2 == nullptr) return false;
            if (t1->val != t2->val) return false;
            // 交叉入队
            q.push(t1->left);  q.push(t2->right);
            q.push(t1->right); q.push(t2->left);
        }
        return true;
    }
};
```

## 解法三: 迭代（栈 DFS 成对比较）
**思路**：与解法二同理，只是用栈模拟深度优先搜索，把"待比较的节点对"同步压栈、同步弹出。栈的实现避免递归可能导致的爆栈问题。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)，栈深与树高相关，最坏 O(n)。

```cpp
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        if (root == nullptr) return true;
        stack<TreeNode*> stk;
        stk.push(root->left);
        stk.push(root->right);
        while (!stk.empty()) {
            TreeNode* t1 = stk.top(); stk.pop();
            TreeNode* t2 = stk.top(); stk.pop();
            if (t1 == nullptr && t2 == nullptr) continue;
            if (t1 == nullptr || t2 == nullptr) return false;
            if (t1->val != t2->val) return false;
            stk.push(t1->left);  stk.push(t2->right);
            stk.push(t1->right); stk.push(t2->left);
        }
        return true;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 DFS | O(n) | O(h) | 交叉镜像比较，简洁直观 |
| 迭代 BFS | O(n) | O(n) | 队列成对比较，空间可能更大 |
| 迭代 DFS | O(n) | O(h) | 栈模拟递归，避免爆栈 |

> 推荐解法一（递归），是二叉树对称问题最经典的模板。解法二/三是同一思路的迭代版本，实际编码中二选一即可。

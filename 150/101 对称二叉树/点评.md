# 101. 对称二叉树 — 代码点评
## 使用的方法
BFS 层序遍历 + 每层回文检查。借助队列按层收集节点，用 `vector<TreeNode*>` 保存当前层（含空指针占位），再对每层的节点值序列做首尾双指针回文判断；若某层不是回文则返回 false。

## 复杂度分析
- 时间复杂度：O(n)，每个节点入队、出队各一次，回文检查对每层元素各扫描一次，总计 O(n)。
- 空间复杂度：O(n)，队列保存最宽一层的节点数（O(w)），`vec` 额外保存当前层节点，最坏均为 O(n)。

## 代码评价

**优点**：
- 思路直观，用"层序遍历 + 每层回文"判断对称，空节点用 `nullptr` 占位，能正确识别结构上的不对称（如 `[1,2,2,null,3,null,3]`）。
- 空指针占位后做回文判断，逻辑等价于递归镜像比较，正确性成立。

**可改进**：
- 第 38-53 行用 `count` 和 `k` 两个变量手工记账下一层节点数（`k+=2`、`k--`）比较绕，容易出错。可以直接在每层开始时用 `int sz = q.size();` 记录本层节点数，循环 `sz` 次即可，省去 `k`。
- 第 59-60 行的 `if(!vec[le]&&!vec[ri]) ;` 空语句写法不规范，建议改为带注释或 `if(!vec[le] && !vec[ri]) { /* 都为空，继续 */ }`，避免"裸分号"让人误以为漏写逻辑。
- 整层存入 `vec` 再做回文判断多了一次额外空间，可改为队列成对比较（每次弹出两个节点交叉比较），空间更省（O(h)）。
- 头文件包含了一些未使用的 `<stack>`、`<map>`、`<set>`、`<string>`、`<unordered_map>`、`<algorithm>`（实际用到 `<iostream>`、`<vector>`、`<queue>`）。

**风格**：
- 符合一般 ACM 风格的写法，使用了 `using namespace std;`。
- 变量命名 `le`/`ri` 简洁但可读性一般，建议 `left`/`right`。

## 总结
> AC ✓

代码正确实现了对称二叉树的判断，采用"层序 + 回文"思路无误，复杂度 O(n)/O(n)。主要问题在于下一层节点数的 `k`/`count` 手工记账和裸分号空语句，可读性与健壮性可优化，建议用 `q.size()` 和队列成对比较进一步精简。

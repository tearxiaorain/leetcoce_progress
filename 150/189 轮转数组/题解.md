# 189. 轮转数组

## 题目描述
> 给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。要求原地修改数组。

## 解法一: 使用额外数组
### 思路
创建一个与原数组大小相同的新数组，遍历原数组，将每个元素放到新数组的 `(i + k) % n` 的位置上，最后将新数组拷贝回原数组。
### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)
### 代码
```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k = k % n;
        vector<int> temp(n);
        for (int i = 0; i < n; i++) {
            temp[(i + k) % n] = nums[i];
        }
        nums = temp;
    }
};
```

## 解法二: 三次反转法（原地解法）
### 思路
通过三次反转来实现原地轮转：
1. 先反转整个数组
2. 再反转前 k 个元素
3. 最后反转剩余 n-k 个元素

例如 `nums = [1,2,3,4,5,6,7], k = 3`：
- 全部反转: `[7,6,5,4,3,2,1]`
- 反转前3个: `[5,6,7,4,3,2,1]`
- 反转后4个: `[5,6,7,1,2,3,4]`

### 复杂度
- 时间复杂度: O(n)，每个元素被访问两次
- 空间复杂度: O(1)
### 代码
```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k = k % n;
        // 反转整个数组
        reverse(nums.begin(), nums.end());
        // 反转前 k 个
        reverse(nums.begin(), nums.begin() + k);
        // 反转后 n-k 个
        reverse(nums.begin() + k, nums.end());
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 额外数组 | O(n) | O(n) | 思路直观，实现简单 | 需要额外空间 |
| 三次反转 | O(n) | O(1) | 原地操作，空间最优 | 需要理解反转原理 |

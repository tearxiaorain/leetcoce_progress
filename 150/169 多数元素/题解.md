# 169. 多数元素

## 题目描述
> 给定一个大小为 n 的数组 nums，返回其中的多数元素。多数元素是指在数组中出现次数大于 n/2 的元素。题目保证多数元素一定存在。

## 解法一: 排序取中间法
### 思路
将数组排序。由于多数元素出现次数超过 n/2，排序后位于数组中间位置的元素一定是多数元素。

### 复杂度
- 时间复杂度: O(n log n)
- 空间复杂度: O(1) 或 O(log n)（取决于排序算法）

### 代码
```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        return nums[nums.size() / 2];
    }
};
```

## 解法二: Boyer-Moore 投票算法
### 思路
维护一个候选元素 `candidate` 和一个计数器 `count`。遍历数组：
- 如果 `count == 0`，将当前元素设为候选元素。
- 如果当前元素 == candidate，`count++`；否则 `count--`。
- 最终 candidate 即为多数元素。

原理：多数元素出现次数 > n/2，它能抵消所有其他元素后仍有剩余。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = 0;
        int count = 0;
        
        for (int num : nums) {
            if (count == 0) {
                candidate = num;
            }
            count += (num == candidate) ? 1 : -1;
        }
        
        return candidate;
    }
};
```

## 解法三: 哈希表计数法
### 思路
使用哈希表统计每个元素的出现次数，找到出现次数 > n/2 的元素。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)

### 代码
```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        unordered_map<int, int> countMap;
        int threshold = nums.size() / 2;
        
        for (int num : nums) {
            countMap[num]++;
            if (countMap[num] > threshold) {
                return num;
            }
        }
        
        return -1;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n log n) | O(1) | 排序后取中间元素 |
| 解法二 | O(n) | O(1) | Boyer-Moore 投票（抵消法） |
| 解法三 | O(n) | O(n) | 哈希表统计频次 |

Boyer-Moore 投票算法是本问题的最优解，同时满足 O(n) 时间和 O(1) 空间，在面试中经常被考察。其核心直觉是：多数元素最终无法被少数元素完全抵消。

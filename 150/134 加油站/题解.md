# 134. 加油站

## 题目描述

在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的汽车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 `gas` 和 `cost`，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 `-1`。如果存在解，则**保证它是唯一的**。

## 解法一：暴力模拟（直观理解）

### 思路

从每个加油站出发，模拟绕行一圈，检查油量是否始终非负。

### C++ 代码

```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        for (int start = 0; start < n; ++start) {
            int tank = 0;
            bool ok = true;
            for (int step = 0; step < n; ++step) {
                int idx = (start + step) % n;
                tank += gas[idx] - cost[idx];
                if (tank < 0) {
                    ok = false;
                    break;
                }
            }
            if (ok) return start;
        }
        return -1;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n²)，最坏情况下每个起点都要模拟一圈。
- **空间复杂度**：O(1)。

---

## 解法二：贪心——两次遍历

### 思路

引理：如果从 A 站出发无法到达 B 站，那么 A 与 B 之间的任何一站出发也无法到达 B 站。

证明：从 A 出发到达某中间站 C 时油箱剩余 >= 0；如果直接从 C 出发，油箱初始为 0，情况只会更差，更不可能到达 B。

基于此：
1. 第一遍计算 `total_tank = sum(gas) - sum(cost)`，若 `total_tank < 0` 则无解，直接返回 -1。
2. 第二遍贪心找起点：从 0 出发，维护 `cur_tank`，当 `cur_tank < 0` 时将起点重置为下一站，`cur_tank` 清零。

### C++ 代码

```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();

        // 第一遍：检查总油量是否足够
        int total_tank = 0;
        for (int i = 0; i < n; ++i) {
            total_tank += gas[i] - cost[i];
        }
        if (total_tank < 0) return -1;

        // 第二遍：贪心找起点
        int start  = 0;
        int cur_tank = 0;
        for (int i = 0; i < n; ++i) {
            cur_tank += gas[i] - cost[i];
            if (cur_tank < 0) {
                // 从 start 到 i 的任意一站都无法作为起点
                start = i + 1;
                cur_tank = 0;
            }
        }
        return start;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，两次遍历。
- **空间复杂度**：O(1)。

## 解法三：贪心——一次遍历（最优）

### 思路

将两次遍历合并为一次：同时维护 `total_tank` 和 `cur_tank`。若 `cur_tank < 0` 则重置起点；最后检查 `total_tank` 是否 >= 0。

### C++ 代码

```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        int total_tank = 0;  // 总剩余油量
        int cur_tank   = 0;  // 当前油箱
        int start      = 0;  // 候选起点

        for (int i = 0; i < n; ++i) {
            int diff = gas[i] - cost[i];
            total_tank += diff;
            cur_tank   += diff;

            if (cur_tank < 0) {
                // 无法从当前 start 到达 i+1，重置
                start = i + 1;
                cur_tank = 0;
            }
        }

        return total_tank >= 0 ? start : -1;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，仅一次遍历。
- **空间复杂度**：O(1)。

---

## 总结

| 解法 | 核心思想 | 时间 | 空间 |
|------|---------|------|------|
| 暴力模拟 | 枚举每个起点，模拟绕圈 | O(n²) | O(1) |
| 贪心（两次遍历） | 先判可行性，再滑动窗口找起点 | O(n) | O(1) |
| 贪心（一次遍历） | 合并判断与查找，一次扫描 | O(n) | O(1) |

**关键直觉**：如果 `sum(gas) >= sum(cost)`，则一定有解。贪心法的核心在于，一旦 `cur_tank < 0`，当前区间的所有站都不可行，直接跳到 `i+1` 作为新起点。

# 392. 判断子序列

## 题目描述
> 给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的子序列。子序列是指通过删除 `t` 中的一些（或不删除）字符，而不改变剩余字符相对位置所形成的新字符串。例如 `"ace"` 是 `"abcde"` 的子序列，而 `"aec"` 不是。

## 解法一: 双指针法
### 思路
使用两个指针 `i` 和 `j` 分别指向 `s` 和 `t` 的开头。遍历 `t`，当 `t[j] == s[i]` 时 `i` 前进。如果最终 `i == s.size()`，说明 `s` 的所有字符都在 `t` 中按顺序找到了，返回 true。

### 复杂度
- 时间复杂度: O(n + m)，其中 n = s.size(), m = t.size() —— 最坏情况下需要遍历整个 t
- 空间复杂度: O(1)
### 代码
```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0, j = 0;
        while (i < s.size() && j < t.size()) {
            if (s[i] == t[j]) {
                i++;
            }
            j++;
        }
        return i == s.size();
    }
};
```

## 解法二: 动态规划（预处理 t，应对多次查询）
### 思路
当需要多次判断不同的 `s` 是否为同一个 `t` 的子序列时，可以预处理 `t`，用 DP 记录每个位置之后每个字母首次出现的位置。`dp[i][c]` 表示在 `t` 的第 `i` 个位置之后，字母 `c` 首次出现的索引。然后对于每个 `s`，可以在 O(n) 时间内完成判断。

### 复杂度
- 预处理时间: O(m * |Σ|)，其中 m = t.size()，|Σ| = 26
- 每次查询: O(n)
- 空间复杂度: O(m * |Σ|)
### 代码
```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int m = t.size();
        // dp[i][c]: 在位置 i 及之后，字符 c 首次出现的位置
        vector<vector<int>> dp(m + 1, vector<int>(26, m));
        for (int i = m - 1; i >= 0; i--) {
            for (int c = 0; c < 26; c++) {
                dp[i][c] = dp[i + 1][c];
            }
            dp[i][t[i] - 'a'] = i;
        }
        int pos = 0;
        for (char c : s) {
            if (dp[pos][c - 'a'] == m) return false;
            pos = dp[pos][c - 'a'] + 1;
        }
        return true;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双指针 | O(n+m) | O(1) | 简单高效，适合单次查询 | 多次查询时效率低 |
| DP 预处理 | 预处理 O(m*26)，查询 O(n) | O(m*26) | 多次查询场景下性能极佳 | 预处理开销大，单次查询浪费 |

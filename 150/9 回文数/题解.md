# 9. 回文数

## 题目描述
> 判断一个整数是否是回文数。回文数是指正序和倒序读都是一样的整数。
> 进阶：不将整数转为字符串来解决。

## 解法一: 转为字符串 + 双指针

### 思路
将整数转为字符串，用左右双指针向中间扫描，比较对应字符是否相等。

### 复杂度
- 时间复杂度: O(n)，n 为数字位数
- 空间复杂度: O(n)，存储字符串

### 代码
```cpp
bool isPalindrome(int x) {
    if (x < 0) return false;
    string s = to_string(x);
    int l = 0, r = s.size() - 1;
    while (l < r) {
        if (s[l] != s[r]) return false;
        l++; r--;
    }
    return true;
}
```

## 解法二: 反转一半数字（最优）

### 思路
不转字符串，直接对数字操作：
- 负数一定不是回文数
- 末尾为 0 且不为 0 的数也不是（如 10、100，反转后 01 无法表示）
- 每次取出 x 的最后一位，构建反转数字 `reverted`，同时 x 除以 10
- 当 x <= reverted 时说明已处理一半，停止
- 最终判断 x == reverted（偶数位）或 x == reverted / 10（奇数位）

### 复杂度
- 时间复杂度: O(log₁₀ n)，处理一半数字
- 空间复杂度: O(1)

### 代码
```cpp
bool isPalindrome(int x) {
    if (x < 0 || (x % 10 == 0 && x != 0)) return false;
    int reverted = 0;
    while (x > reverted) {
        reverted = reverted * 10 + x % 10;
        x /= 10;
    }
    return x == reverted || x == reverted / 10;
}
```

## 解法三: 完全反转数字

### 思路
将整个数字反转，与原数字比较。需要注意反转后可能溢出 int 范围，可用 `long long` 存储。

### 复杂度
- 时间复杂度: O(log₁₀ n)
- 空间复杂度: O(1)

### 代码
```cpp
bool isPalindrome(int x) {
    if (x < 0) return false;
    long long rev = 0, cur = x;
    while (cur) {
        rev = rev * 10 + cur % 10;
        cur /= 10;
    }
    return rev == x;
}
```

## 总结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 字符串 + 双指针 | O(n) | O(n) | 简单直观，额外空间 |
| 反转一半数字 | O(log n) | O(1) | 最优解，满足进阶要求 |
| 完全反转 | O(log n) | O(1) | 需注意 int 溢出问题 |

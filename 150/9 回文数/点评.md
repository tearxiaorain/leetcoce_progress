# 9. 回文数 — 代码点评

## 使用的方法
**取模提取每位数字 + 双指针比较**。将整数各位存入 `vector<int>`，然后从两端向中间逐一比对。

## 复杂度分析
- 时间复杂度: **O(log₁₀ n)** — 数字位数决定了循环次数
- 空间复杂度: **O(log₁₀ n)** — 使用 vector 存储每位数字

## 代码评价

### 优点
- 负数处理正确：`x < 0` 直接返回 false
- 双指针比较逻辑清晰，`n/2` 次循环简洁
- 用取模和除法提取每位数字是标准做法

### 可改进之处
1. **空间可优化为 O(1)**: 使用 vector 存储每位数字，空间 O(log n)。最优解只需反转一半数字，O(1) 空间。建议学习「反转一半数字」技巧
2. **flag 变量冗余**: 当前用 `flag` 记录是否发现不匹配，再用 `if (!flag)` 判断。直接在循环内 `return false` 即可，省掉 flag 变量和最后的条件判断
3. **`x = 0` 的边界**: `while (a)` 不会执行，arr 为空，循环不执行，flag 为 0，最终返回 true。结果正确但属于「碰巧对」，建议显式处理或改用对 0 安全的逻辑
4. **冗余头文件**: 包含了 `stack`、`map`、`set`、`string` 等未使用的头文件

### 代码风格
- `flag` 命名可读性一般，不如直接用 `isNotPalindrome` 或干脆去掉
- 整体结构清晰，有基本的边界处理意识

## 代码精简建议
```cpp
bool isPalindrome(int x) {
    if (x < 0) return false;
    vector<int> arr;
    while (x) { arr.push_back(x % 10); x /= 10; }
    int n = arr.size();
    for (int i = 0; i < n / 2; i++)
        if (arr[i] != arr[n - 1 - i]) return false;
    return true;
}
```

## 总结
> 逻辑正确，flag 冗余，空间 O(n) 可优化为 O(1)。建议学习「反转一半数字」的最优解。

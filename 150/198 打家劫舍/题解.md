# 198. 打家劫舍
## 题目描述
> 你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。如果你偷窃了相邻的两间房屋，就会触发警报。给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。

## 解法一: 暴力回溯
**思路**：对于每间房屋，有两种选择——偷或不偷。如果偷当前房屋，则不能偷下一间；如果不偷，则可以偷下一间。递归枚举所有可能的选择组合，取最大收益。

**复杂度**：
- 时间复杂度：O(2^n)，每间房屋两种选择，指数级。
- 空间复杂度：O(n)，递归栈深度。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        return dfs(nums, 0);
    }
    
    int dfs(vector<int>& nums, int i) {
        if (i >= nums.size()) return 0;
        // 偷当前：跳过下一间；不偷当前：从下一间继续
        return max(dfs(nums, i + 1), nums[i] + dfs(nums, i + 2));
    }
};
```

## 解法二: 记忆化搜索
**思路**：用 memo 数组缓存每个起始位置 i 对应的最优结果，避免重复计算。

**复杂度**：
- 时间复杂度：O(n)，每个位置只计算一次。
- 空间复杂度：O(n)，memo 数组 + 递归栈。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        vector<int> memo(nums.size(), -1);
        return dfs(nums, 0, memo);
    }
    
    int dfs(vector<int>& nums, int i, vector<int>& memo) {
        if (i >= nums.size()) return 0;
        if (memo[i] != -1) return memo[i];
        memo[i] = max(dfs(nums, i + 1, memo), nums[i] + dfs(nums, i + 2, memo));
        return memo[i];
    }
};
```

## 解法三: 动态规划
**状态定义**：`dp[i]` 表示偷窃前 i 间房屋（编号 0 到 i-1）能够获得的最大金额。

**转移方程**：
> `dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`

解释：
- `dp[i-1]`：不偷第 i-1 间房屋，金额等于前 i-1 间的最大收益。
- `dp[i-2] + nums[i-1]`：偷第 i-1 间房屋，则必须跳过第 i-2 间，收益为前 i-2 间的最大收益 + 当前房屋金额。

**初始化**：`dp[0] = 0`（0 间房屋），`dp[1] = nums[0]`（只有一间则必偷）。

**复杂度**：
- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(n)，dp 数组。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        if (n == 1) return nums[0];
        vector<int> dp(n + 1, 0);
        dp[1] = nums[0];
        for (int i = 2; i <= n; i++) {
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[n];
    }
};
```

## 解法四: 滚动变量优化
**思路**：dp[i] 只依赖 dp[i-1] 和 dp[i-2]，用两个变量即可完成迭代。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(1)

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0; // dp[i-2]
        int prev1 = 0; // dp[i-1]
        for (int num : nums) {
            int curr = max(prev1, prev2 + num);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 暴力回溯 | O(2^n) | O(n) | 枚举所有"偷/不偷"组合 |
| 记忆化搜索 | O(n) | O(n) | 自顶向下缓存 |
| 动态规划 | O(n) | O(n) | 自底向上递推 |
| 滚动变量 | O(n) | O(1) | 仅保留前两个状态 |

> 打家劫舍是经典的"相邻限制"型 DP，核心在于 dp[i] 只与 dp[i-1] 和 dp[i-2] 相关。面试中可以先给出 DP 数组写法，再追问优化到 O(1) 空间。进阶变体有 213. 打家劫舍 II（环形）和 337. 打家劫舍 III（树形）。

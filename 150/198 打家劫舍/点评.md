# 198. 打家劫舍 — 代码点评
## 使用的方法
动态规划（自底向上）。`arr[i]` 表示考虑到第 i 间房屋（0-indexed）时的最大偷窃金额。转移方程：`arr[i] = max(arr[i-1], arr[i-2] + nums[i])`，即"不偷当前"与"偷当前+跳过前一间"两种方案取最大值。

## 复杂度分析
- 时间复杂度：O(n)，一次 for 循环遍历全部房屋。
- 空间复杂度：O(n)，动态分配了大小为 n 的数组 `arr`。

## 代码评价

**优点**：
- DP 状态定义和转移方程完全正确，核心逻辑清晰无误。
- 对 n=0 和 n=1 的边界情况做了妥善处理。
- arr[0] 和 arr[1] 的初始化正确：arr[0] = nums[0]，arr[1] = max(nums[0], nums[1])。

**可改进**：
- **内存泄漏**：使用 `new int[n]` 但无 `delete[] arr`，应改用 `vector<int> arr(n)`。
- **空间可优化到 O(1)**：dp[i] 只依赖前两个状态，用 `prev2` 和 `prev1` 两个变量即可，无需整个数组。
- **头文件冗余**：包含了 `<stack>`、`<map>`、`<set>`、`<string>` 等未使用的头文件。
- **控制流可简化**：`if(k1>k2) arr[i]=k1; else arr[i]=k2;` 可以直接用 `arr[i] = max(k1, k2);`，更简洁。
- **变量中间存储多余**：`k1` 和 `k2` 可以直接内联到 `max()` 调用中。

**风格**：
- 代码格式紧凑，`if`/`else` 和控制结构缺少空格（如 `if(n==0)`），建议使用 `if (n == 0)`。
- 数组名 `arr` 建议改为 `dp`，更贴近算法语义。变量 `k1`、`k2` 可以用更表意的命名如 `robCurr`、`skipCurr`。

## 总结
> AC ✓

DP 核心逻辑正确，转移方程理解到位。主要问题是裸指针内存泄漏和代码风格可改进。空间优化到 O(1) 是加分项，面试中可以作为 follow-up 展示。

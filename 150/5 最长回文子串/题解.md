# 5. 最长回文子串

## 题目描述

> 给定一个字符串 `s`，找到 `s` 中最长的**回文子串**。回文串指正着读和反着读完全相同的字符串，子串要求字符在原串中连续。
> 例：`s = "babad"` → `"bab"`（`"aba"` 也算正确答案）；`s = "cbbd"` → `"bb"`。
> 数据范围：1 ≤ |s| ≤ 1000。存在多个等长答案时返回任意一个即可。

## 解法一：暴力枚举所有子串

### 思路
枚举所有左右端点 `[i, j]`，逐一判断 `s[i..j]` 是否为回文，记录最长的那一个。判断回文用双指针首尾向中间比较，不需要真的切片（切片会额外消耗 O(n) 空间）。

这是最直观的做法，但枚举 O(n²) 个子串、每个再花 O(n) 判断，n = 1000 时约 10⁹ 次比较，只能作为思路起点。

### 复杂度
- 时间复杂度: O(n³)（枚举 O(n²) × 判回文 O(n)）
- 空间复杂度: O(1)（不计返回的子串）

### 代码
```cpp
bool isPalindrome(const string& s, int l, int r) {   // 双指针判 [l, r] 是否回文
    while (l < r) {
        if (s[l] != s[r]) return false;
        l++; r--;
    }
    return true;
}

string longestPalindrome(string s) {
    int n = s.size(), start = 0, maxLen = 1;
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            if (j - i + 1 > maxLen && isPalindrome(s, i, j)) {
                maxLen = j - i + 1;
                start = i;
            }
        }
    }
    return s.substr(start, maxLen);
}
```

## 解法二：中心扩展（推荐）

### 思路
回文串一定关于某个中心对称：奇数长度回文的中心是**一个字符**，偶数长度的中心是**两个字符之间的缝隙**，一共 `2n - 1` 个中心。

对每个中心向左、右同时扩展，只要两侧字符相同就继续扩，扩不动时停下，就得到了该中心对应的最长回文。这样省掉了"逐个判断子串是否回文"的重复扫描。

小技巧：用 `c` 从 `0` 枚举到 `2n - 2`，令 `l = c / 2`、`r = l + c % 2`，当 `c` 为偶数时 `l == r`（奇数长度中心），`c` 为奇数时 `r = l + 1`（偶数长度中心），两种中心用一套循环统一处理。

### 复杂度
- 时间复杂度: O(n²)（2n - 1 个中心，每个最多扩展 O(n)）
- 空间复杂度: O(1)

### 代码
```cpp
string longestPalindrome(string s) {
    int n = s.size(), start = 0, maxLen = 1;
    for (int c = 0; c < 2 * n - 1; c++) {
        int l = c / 2, r = l + c % 2;        // c 偶: 单字符中心; c 奇: 双字符中心
        while (l >= 0 && r < n && s[l] == s[r]) { l--; r++; }
        int len = r - l - 1;                 // 退出循环时 [l+1, r-1] 才是回文
        if (len > maxLen) {
            maxLen = len;
            start = l + 1;
        }
    }
    return s.substr(start, maxLen);
}
```

## 解法三：Manacher（马拉车）

### 思路
中心扩展在"aaaa...a"这类串上会重复扫描大量字符。Manacher 利用回文的对称性做到线性：

1. 在字符间插入分隔符（如 `#`），把奇数、偶数长度回文统一成奇数长度，再在两端加哨兵省去越界判断；
2. 记当前已触及的**最右回文右边界** `r` 及其中心 `c`（回文半径数组记作 `p`）。对位置 `i`：若 `i < r`，则 `p[i]` 至少等于其关于 `c` 的对称点 `2c - i` 的半径，且不超过 `r - i`；否则从 1 开始；
3. 从这个下界继续暴力扩展。由于每扩展成功一次 `r` 只会单调右移，总扩展次数是 O(n)。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)（变换后的字符串与半径数组）

### 代码
```cpp
string longestPalindrome(string s) {
    string t = "^#";
    for (char ch : s) { t += ch; t += '#'; }
    t += '$';                                  // 两侧哨兵，扩展循环不必判越界
    int n = t.size();
    vector<int> p(n, 0);                       // p[i]: 以 t[i] 为中心的回文半径(含中心)
    int c = 0, r = 0, best = 0;                // c/r: 当前最右回文的中心与右边界+1
    for (int i = 1; i < n - 1; i++) {
        p[i] = (r > i) ? min(r - i, p[2 * c - i]) : 1;   // 复用镜像点半径
        while (t[i - p[i]] == t[i + p[i]]) p[i]++;       // 继续向外扩
        if (i + p[i] > r) { c = i; r = i + p[i]; }       // 刷新最右边界
        if (p[i] > p[best]) best = i;
    }
    int len = p[best] - 1;                     // 变换串半径 - 1 即原串回文长度
    return s.substr((best - p[best]) / 2, len);
}
```

## 小结

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 暴力枚举 | O(n³) | O(1) | 思路最直白，n = 1000 勉强够用 |
| 中心扩展 | O(n²) | O(1) | 面试首选，代码短、常数小 |
| Manacher | O(n) | O(n) | 理论最优，模板题必背 |

# 5. 最长回文子串 — 代码点评

## 使用的方法
**区间 DP（按区间长度递增）**：`dp[i][j]` 表示 `s[i..j]` 是否为回文。先把长度 1（对角线）和长度 2（相邻相等）单独初始化，再从长度 3 起用 `dp[j][j+i] = dp[j+1][j+i-1] && s[j] == s[j+i]` 递推，命中为真时更新 `max / l / r`。

## 复杂度分析
- 时间复杂度: O(n²)（约 n²/2 个状态，每个状态 O(1) 转移）
- 空间复杂度: O(n²)（长度为 n 的 n 张 int 表；n = 1000 时约 4 MB）

## 代码评价
- 优点:
  - 递推式正确且顺序安全：按长度从小到大填表，用到的 `dp[j+1][j+i-1]` 必然已算过；`dp[i][i] = 1`、相邻相等置 1 两个初始化覆盖了全部奇数/偶数基础区间
  - 边界稳：空串时 `len = 0`，两层循环都不进，`s.substr(0, 1)` 在空串上合法返回 `""`；单字符时 `max` 保持 1、`l = r = 0` 正确
  - 只记录最长区间的 `l / r`，最后一次性 `substr` 出结果，没有中途反复拷贝子串
- 可改进之处:
  - **局部变量 `max` 把 `std::max` 遮蔽了**（又用了 `using namespace std`），后续只要写 `max(1, 2)` 就编译不过；改名 `maxLen` 即可
  - `dp` 用 `int` 存布尔值，内存是 `bool` / `vector<char>` 的 4 倍；改掉后 n = 1000 时从 4 MB 降到 1 MB
  - 长度 1 的初始化与 `if (max < 2)` 特判可以去掉：`max` 初值给 1，统一从长度 2 起枚举，能少一层特判
  - 空间还能降：中心扩展 O(n²) 时间 / O(1) 空间、Manacher O(n) 时间 / O(n) 空间（见题解解法二、三），本题 n ≤ 1000 用区间 DP 够用，但补上这两种思路才算吃透
  - 二维下标 `dp[j][j+i]` 的实际含义是"起点 + 长度"，代码里没有注释，读的时候要自己反推；建议补一行"`dp[l][r]`：s[l..r] 是否回文"，或直接把循环变量改成左右端点
- 代码风格: `l / r / max` 命名偏简，与 STL 名字撞车是本文件最该改的一处

## 总结
> 区间 DP 的思路和实现都正确、O(n²) / O(n²) AC；需要处理的是变量名遮蔽 `std::max`、用 int 存布尔的额外内存，并补上空间更优的中心扩展 / Manacher 作为对照实现。
> AC ✓

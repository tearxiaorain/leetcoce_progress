# 66. 加一

## 题目描述

> 给定一个由**整数组成的非空数组** `digits` 所表示的非负整数，在该数的基础上加一。最高位数字存放在数组首位，数组中的每个元素只存储**单个数字**。
> 示例：`digits = [1,2,3]` → `[1,2,4]`；`digits = [9,9]` → `[1,0,0]`

本质是**竖式加法的个位进位**问题，从最低位（数组末尾）开始向前处理进位，注意最高位溢出时要**数组头插一个新位**。

## 解法一：从后向前模拟进位（一次遍历）

### 思路

从数组末尾开始：
- 若当前位 `< 9`，直接 `+1` 即可返回（后面没有进位了）
- 若当前位 `== 9`，置 `0` 并向左进位（继续循环）
- 若循环结束仍没返回，说明全部是 9（如 `999`），需要进位到最高位之前——`new` 一个长度 `n+1` 的数组，首位为 1，其余为 0

只在末尾一次性 `insert` 到头部，避免多次前插的 O(n) 开销重复发生。

### 复杂度
- 时间复杂度: O(n)，最坏 `999…9` 时扫描整串；平均很快返回
- 空间复杂度: O(1)（返回值不计）——注意插入到 vector 头部本身 O(n)，但只发生一次

### 代码
```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int n = digits.size();
        for (int i = n - 1; i >= 0; --i) {
            if (digits[i] < 9) {        // 本位不进位
                ++digits[i];
                return digits;
            }
            digits[i] = 0;              // 本位置 0，进位继续向左
        }
        // 全为 9：需要在最前面补 1
        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

## 解法二：统一用"进位标志"（模板化写法）

### 思路

不提前 return，而是用变量 `carry` 统一从末位向前推进位：`sum = digits[i] + carry`，`digits[i] = sum % 10`，`carry = sum / 10`。循环结束后若 `carry == 1`（即全 9 情况），头插 1。该写法可读性稍弱但**易于推广**到任意"加 k 次 / 大数相加"的题目。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int carry = 1;                       // 相当于最开始的 +1
        for (int i = digits.size() - 1; i >= 0 && carry; --i) {
            int sum = digits[i] + carry;
            digits[i] = sum % 10;
            carry = sum / 10;
        }
        if (carry) digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

## 总结

- 关键在**处理 `9` 的连续进位**与**全 9 溢出补最高位**两个边界。
- 解法一是最优最简洁的：`<9` 直接返回、`==9` 置 0 进位、全 9 头插 1。
- 注意 `vector::insert(begin(), 1)` 是 O(n) 的，好在只有"全 9"时才触发一次。

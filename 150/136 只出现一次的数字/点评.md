# 136. 只出现一次的数字 — 代码点评

## 使用的方法
**异或累积**：`res = nums[0]` 起逐个 `^=`，利用 `a^a=0`、`a^0=a`、交换律，把成对出现的数字全部抵消，剩下的就是只出现一次的数。初始化直接取 `nums[0]` 作为起点。

## 复杂度分析
- 时间复杂度: O(n)
- 空间复杂度: O(1)

## 代码评价
- 优点:
  - 一步命中本题最优解法：O(n) 时间 + O(1) 空间，无需哈希表/排序，标准答案
  - 实现极简，几乎无出错面
- 可改进之处:
  - 用 `res = 0` 起头再 `for (int x : nums) res ^= x;` 更通用——当前写法假设 `nums` 非空直接取 `nums[0]`，虽然题目保证非空，但以 0 起头能顺带处理空数组边界，风格更稳
  - 可加一行注释说明异或三性质，利于复习时回忆原理
- 代码风格: 干净、易读

## 总结
> 异或 O(n) O(1) 一步到位，正确 AC；建议改以 `0` 起头、用范围 for，语义更清晰。
> AC ✓

# 136. 只出现一次的数字

## 题目描述

> 给定一个**非空**整数数组 `nums`,其中恰好有一个元素只出现一次,其余每个元素均出现**两次**。找出那个只出现一次的元素。要求时间 O(n)、额外空间 O(1)。
> 输入输出示意:`nums = [4,1,2,1,2]` → `4`。

## 解法一: 哈希表计数（直观）

### 思路
用哈希表统计每个数字出现次数,再扫一遍找出次数为 1 的数。思路直白、易推广(如"一个出现 1 次、其余出现 3 次"),但用了 O(n) 额外空间,不满足题目的 O(1) 空间要求。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)

### 代码
```cpp
int singleNumber(vector<int>& nums) {
    unordered_map<int, int> cnt;
    for (int x : nums) cnt[x]++;
    for (auto& [x, c] : cnt) if (c == 1) return x;
    return -1;
}
```

## 解法二: 异或（O(1) 空间）

### 思路
利用异或的三大性质:① `a ^ a = 0`;② `a ^ 0 = a`;③ 交换律/结合律。把所有数逐个异或,成对出现的数彼此抵消为 0,最后剩下的就是那个只出现一次的数。
因为除了目标外每个数都出现两次,所以 `a ^ a ^ … ^ b ^ b ^ x = x`。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;
    return res;
}
```

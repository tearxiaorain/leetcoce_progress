# 236. 二叉树的最近公共祖先
## 题目描述
> 给定一个二叉树，找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先（Lowest Common Ancestor, LCA）。最近公共祖先定义为：对于有根树的两个节点 `p`、`q`，最近公共祖先是同时包含这两个节点的最深节点（一个节点也可以是它自己的祖先）。

## 解法一: 递归（自底向上分治）
**思路**：自底向上递归。对当前节点：
- 若为空、或等于 `p`、或等于 `q`，直接返回当前节点；
- 否则分别在左右子树中递归查找 `p`、`q`；
- 若左右子树都返回非空，说明 `p`、`q` 分居两侧，当前节点即为 LCA；
- 若只有一侧非空，说明 `p`、`q` 都在那一侧，返回该侧结果。

**复杂度**：
- 时间复杂度：O(n)，每个节点最多访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏（链状树）为 O(n)。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 * };
 */
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) return root;
        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        if (left && right) return root;      // p、q 分居两侧，当前节点即 LCA
        return left ? left : right;          // 都在一侧，返回该侧结果
    }
};
```

## 解法二: 存储父节点（哈希表 + 祖先标记）
**思路**：先遍历整棵树，用哈希表记录每个节点的父节点；然后从 `p` 出发沿父指针向上，把所有祖先放入集合；再从 `q` 出发向上走，第一个出现在祖先集合中的节点即为 LCA。

**复杂度**：
- 时间复杂度：O(n)，遍历 + 两次向上回溯均为 O(n)。
- 空间复杂度：O(n)，父指针哈希表 + 祖先集合。

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        unordered_map<TreeNode*, TreeNode*> parent;
        parent[root] = nullptr;
        stack<TreeNode*> stk;
        stk.push(root);
        // 记录所有节点父指针（直到 p、q 都入表）
        while (!parent.count(p) || !parent.count(q)) {
            TreeNode* node = stk.top(); stk.pop();
            if (node->left)  { parent[node->left]  = node; stk.push(node->left);  }
            if (node->right) { parent[node->right] = node; stk.push(node->right); }
        }
        // p 的祖先集合
        unordered_set<TreeNode*> ancestors;
        while (p) { ancestors.insert(p); p = parent[p]; }
        // q 向上找第一个公共祖先
        while (!ancestors.count(q)) q = parent[q];
        return q;
    }
};
```

## 解法三: 记录根到目标节点的路径
**思路**：分别求出「根 → p」和「根 → q」的两条路径（用回溯法），两条路径从根开始的最长公共前缀的最后一个节点即为 LCA。

**复杂度**：
- 时间复杂度：O(n)，两次路径查找各 O(n)。
- 空间复杂度：O(n)，两条路径 + 递归栈。

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        vector<TreeNode*> pathP, pathQ;
        findPath(root, p, pathP);
        findPath(root, q, pathQ);
        TreeNode* ans = nullptr;
        int n = min(pathP.size(), pathQ.size());
        for (int i = 0; i < n && pathP[i] == pathQ[i]; i++) ans = pathP[i];
        return ans;
    }

    bool findPath(TreeNode* node, TreeNode* target, vector<TreeNode*>& path) {
        if (node == nullptr) return false;
        path.push_back(node);
        if (node == target) return true;
        if (findPath(node->left, target, path) || findPath(node->right, target, path))
            return true;
        path.pop_back();  // 回溯
        return false;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归分治 | O(n) | O(h) | 自底向上，分居两侧则当前为 LCA |
| 父指针哈希表 | O(n) | O(n) | 祖先标记，q 向上找交集 |
| 记录路径 | O(n) | O(n) | 两条路径最长公共前缀 |

> 推荐解法一（递归分治），是二叉树 LCA 最经典的模板，代码极简且空间只与树高相关。解法二/三思路直观但需要 O(n) 额外空间，适合迭代化需求或需要多次查询的场景。

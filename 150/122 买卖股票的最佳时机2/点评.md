# 122. 买卖股票的最佳时机 II — 代码点评

## 测试数据

`prices = [3, 2, 6, 5, 0, 3]`（main 中仅 push 了前 6 个元素）

期望输出：`7`（(6-2) + (3-0) = 4 + 3）

## 代码分析

### 算法思路

用户采用了一种**类状态机**的贪心策略：

- `flag=0`（空仓状态）：寻找买入点。若价格下跌，记录新低点 `ind` 并进入持仓状态；若价格上涨，直接累加差价。
- `flag=1`（持仓状态）：寻找卖出点。若当前价高于持仓成本 `prices[ind]`，卖出并重置为 `flag=0`；否则更新持仓成本为更低价。

本质上这是"峰谷法"的变体，思路正确，可以 AC。

### 代码问题

**1. 逻辑冗余，可读性差**

`flag` + `ind` 的状态机不如直接累加正差价简洁。标准贪心一行 `if (prices[i] > prices[i-1]) profit += prices[i] - prices[i-1];` 即可完成。当前代码 28 行 vs 标准 5 行。

**2. 不必要的头文件**

```cpp
#include <stack>
#include <map>
#include <set>
#include <string>
```
四个头文件完全未使用，应删除。

**3. 变量命名不规范**

- `count` 应命名为 `profit`
- `ind` 应命名为 `buyIndex` 或 `minPriceIdx`
- `flag` 不如用 `bool holding` 更直观

**4. 测试代码不一致**

```cpp
int arr[9] = {3,2,6,5,0,3, 5, 6};  // 声明了 9 个元素但只用了 6 个
for (int i = 0; i < 6; i++)         // 硬编码 6
```
数组大小 9 但只使用 6 个，剩余元素浪费且容易误导。

**5. `vector<int> n(0)`**

应写作 `vector<int> n;`，`(0)` 构造零大小 vector 虽合法但不规范。

## 改进建议

```cpp
int maxProfit(vector<int>& prices) {
    int profit = 0;
    for (int i = 1; i < prices.size(); ++i) {
        if (prices[i] > prices[i - 1]) {
            profit += prices[i] - prices[i - 1];
        }
    }
    return profit;
}
```

## 点评

| 维度 | 评价 |

# 122. 买卖股票的最佳时机 II

## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候**最多只能持有一股**股票。你也可以先购买，然后在**同一天**出售。

返回你能获得的**最大利润**。

## 解法一：贪心算法

### 思路

核心观察：所有的上涨区间都可以被捕获。只要今天的价格比昨天高，就在昨天买入、今天卖出。由于同一天可以同时买卖，所有正利润的日间差价之和就等于最大总利润。

换句话说，对于任意一个上升段 `[i, j]`，`prices[j] - prices[i] = (prices[i+1] - prices[i]) + (prices[i+2] - prices[i+1]) + ... + (prices[j] - prices[j-1])`。

因此只需遍历一次，累加所有 `prices[i] - prices[i-1] > 0` 的差值即可。

### C++ 代码

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;
        for (int i = 1; i < prices.size(); ++i) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，仅需一次遍历。
- **空间复杂度**：O(1)，只使用常数级额外空间。

## 解法二：动态规划

### 思路

定义状态：
- `dp[i][0]`：第 `i` 天结束时，手中**没有**股票的最大利润。
- `dp[i][1]`：第 `i` 天结束时，手中**持有**股票的最大利润。

状态转移：
- 第 `i` 天不持有股票：可能是前一天就不持有（`dp[i-1][0]`），或者是前一天持有但在今天卖出（`dp[i-1][1] + prices[i]`）。
- 第 `i` 天持有股票：可能是前一天就持有（`dp[i-1][1]`），或者是前一天不持有但在今天买入（`dp[i-1][0] - prices[i]`）。

```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
```

由于每天的状态只依赖前一天，可用两个变量进行空间优化。

### C++ 代码

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        // dp0: 当天不持有股票, dp1: 当天持有股票
        int dp0 = 0, dp1 = -prices[0];
        for (int i = 1; i < n; ++i) {
            int new_dp0 = max(dp0, dp1 + prices[i]);
            int new_dp1 = max(dp1, dp0 - prices[i]);
            dp0 = new_dp0;
            dp1 = new_dp1;
        }
        return dp0;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，一次遍历。
- **空间复杂度**：O(1)，使用两个变量替代整个 DP 表。

## 解法三：峰谷法

### 思路

将价格序列看作折线图，在谷底买入、在峰顶卖出，重复此操作即可获得最大利润。这等价于捕捉每一段连续上升的差价。

### C++ 代码

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        int i = 0;
        int valley = prices[0];
        int peak   = prices[0];
        int profit = 0;

        while (i < n - 1) {
            // 找谷底
            while (i < n - 1 && prices[i] >= prices[i + 1]) ++i;
            valley = prices[i];
            // 找峰顶
            while (i < n - 1 && prices[i] <= prices[i + 1]) ++i;
            peak = prices[i];
            profit += peak - valley;
        }
        return profit;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，每个元素最多被访问两次。
- **空间复杂度**：O(1)。

---

## 总结

| 解法 | 核心思想 | 时间 | 空间 |
|------|---------|------|------|
| 贪心 | 累加所有正日间差价 | O(n) | O(1) |
| 动态规划 | 每天持有/不持有的最优状态 | O(n) | O(1) |
| 峰谷法 | 在每段上升的谷底买、峰顶卖 | O(n) | O(1) |

贪心法是最简洁、最直观的解法，也是实际中最推荐使用的。

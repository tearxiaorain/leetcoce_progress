# 80. 删除有序数组重复项2

## 题目描述
> 给定一个有序数组 nums，原地删除重复出现的元素，使得每个元素最多出现两次，返回删除后数组的新长度。不要使用额外的数组空间，必须原地修改输入数组并在 O(1) 额外空间条件下完成。

## 解法一: 双指针计数法
### 思路
使用快慢双指针。慢指针 `slow` 指向下一个要填入的位置，快指针 `fast` 遍历数组。同时维护一个计数器 `count` 记录当前元素出现的次数：
- 当 `fast` 指向的元素等于前一个元素时，`count++`；否则 `count = 1`。
- 仅当 `count <= 2` 时，才将 `nums[fast]` 复制到 `nums[slow]`，`slow++`。
- 最终 `slow` 即为新数组的长度。

### 复杂度
- 时间复杂度: O(n)，只需遍历一次数组
- 空间复杂度: O(1)，只使用了常数额外空间

### 代码
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int n = nums.size();
        if (n <= 2) return n;
        
        int slow = 0;
        int count = 1;
        
        for (int fast = 1; fast < n; fast++) {
            if (nums[fast] == nums[fast - 1]) {
                count++;
            } else {
                count = 1;
            }
            
            if (count <= 2) {
                slow++;
                nums[slow] = nums[fast];
            }
        }
        
        return slow + 1;
    }
};
```

## 解法二: 双指针直接比较法
### 思路
更简洁的双指针写法。慢指针 `slow` 表示已处理区间的末尾，初始值为 0。对于从下标 2 开始的每个元素，检查其是否等于 `nums[slow - 1]`（即已处理区间倒数第二个元素）：
- 如果 `nums[fast] != nums[slow - 1]`，说明该元素出现次数未超过 2 次，将其放入 `nums[slow + 1]`，`slow++`。
- 最终返回 `slow + 1`。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int n = nums.size();
        if (n <= 2) return n;
        
        int slow = 2;
        for (int fast = 2; fast < n; fast++) {
            if (nums[fast] != nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        
        return slow;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n) | O(1) | 双指针 + 计数控制 |
| 解法二 | O(n) | O(1) | 双指针直接比较 slow-2 |

解法二更为简洁优雅，利用了"最多保留两个重复项"等价于"当前元素与 slow-2 位置的元素不同"这一性质。

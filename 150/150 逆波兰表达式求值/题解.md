# 150. 逆波兰表达式求值

## 题目描述
> 给定一个字符串数组 tokens，表示逆波兰表达式（后缀表达式）。计算该表达式的值并返回。有效的运算符为 `+`、`-`、`*`、`/`。除法只保留整数部分。题目保证给定的表达式总是有效的。

## 解法一: 栈模拟法
### 思路
使用栈来模拟逆波兰表达式的计算过程：
1. 遍历 tokens 中的每个元素。
2. 如果是数字，直接压入栈中。
3. 如果是运算符，从栈顶弹出两个操作数（先弹出的是右操作数，后弹出的是左操作数），执行运算后将结果压回栈中。
4. 最终栈中只剩一个元素，即为表达式的结果。

### 复杂度
- 时间复杂度: O(n)，遍历一次 tokens
- 空间复杂度: O(n)，栈最多存储 n/2 个元素

### 代码
```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> st;
        
        for (const string& token : tokens) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                int b = st.top(); st.pop();  // 右操作数
                int a = st.top(); st.pop();  // 左操作数
                
                if (token == "+")      st.push(a + b);
                else if (token == "-") st.push(a - b);
                else if (token == "*") st.push(a * b);
                else if (token == "/") st.push(a / b);
            } else {
                st.push(stoi(token));
            }
        }
        
        return st.top();
    }
};
```

## 解法二: 递归法（不推荐，仅作了解）
### 思路
从表达式末尾开始递归求值。每次遇到操作符，递归求解其左边两个子表达式。此方法本质是栈的递归版本，但存在栈溢出风险和实现复杂的问题。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(n)，递归调用栈

### 代码
```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        int pos = tokens.size() - 1;
        return eval(tokens, pos);
    }
    
    int eval(vector<string>& tokens, int& pos) {
        string token = tokens[pos--];
        
        if (token == "+") {
            int b = eval(tokens, pos);
            int a = eval(tokens, pos);
            return a + b;
        } else if (token == "-") {
            int b = eval(tokens, pos);
            int a = eval(tokens, pos);
            return a - b;
        } else if (token == "*") {
            int b = eval(tokens, pos);
            int a = eval(tokens, pos);
            return a * b;
        } else if (token == "/") {
            int b = eval(tokens, pos);
            int a = eval(tokens, pos);
            return a / b;
        } else {
            return stoi(token);
        }
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n) | O(n) | 栈模拟后缀表达式求值 |
| 解法二 | O(n) | O(n) | 递归从后向前解析 |

栈模拟法是最标准、最直观的解法，也是面试中首选。需要注意操作数的弹出顺序（先弹出的是右操作数），以及除法向零截断（C++ 的 `/` 对于正负数已有此行为）。

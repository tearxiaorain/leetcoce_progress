# 104. 二叉树的最大深度
## 题目描述
> 给定一个二叉树 root，返回其最大深度。二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

## 解法一: 递归 DFS（后序遍历）
**思路**：一棵树的最大深度 = max(左子树最大深度, 右子树最大深度) + 1。空树深度为 0。采用后序遍历：先递归求左右子树的深度，再取最大值加一返回。

**复杂度**：
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，最坏情况下（链状树）h = n。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);
        return max(leftDepth, rightDepth) + 1;
    }
};
```

## 解法二: 迭代 BFS（层序遍历）
**思路**：使用队列进行层序遍历，每遍历完一层，深度加一。队列中存储当前层的所有节点，处理完一层后进入下一层。

**复杂度**：
- 时间复杂度：O(n)，每个节点入队出队一次。
- 空间复杂度：O(n)，队列最大存储一层的最多节点数，最坏情况为 O(n)。

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        queue<TreeNode*> que;
        que.push(root);
        int depth = 0;
        while (!que.empty()) {
            int levelSize = que.size();
            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = que.front();
                que.pop();
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
            ++depth;
        }
        return depth;
    }
};
```

## 解法三: 迭代 DFS（栈 + pair）
**思路**：使用栈模拟递归，每个栈元素同时存储节点和当前深度。遍历过程中不断更新最大深度。

**复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(h)，栈深度取决于树高

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, 1});
        int maxDep = 0;
        while (!stk.empty()) {
            auto [node, depth] = stk.top();
            stk.pop();
            maxDep = max(maxDep, depth);
            if (node->right) stk.push({node->right, depth + 1});
            if (node->left) stk.push({node->left, depth + 1});
        }
        return maxDep;
    }
};
```

## 总结
| 解法 | 时间复杂度 | 空间复杂度 | 思路 |
|------|-----------|-----------|------|
| 递归 DFS | O(n) | O(h) | 后序遍历，max(左,右)+1 |
| 迭代 BFS | O(n) | O(n) | 层序遍历，逐层计数 |
| 迭代 DFS | O(n) | O(h) | 栈模拟递归，携带深度信息 |

> 推荐解法一（递归），最简洁。BFS 的层序遍历思路自然，适合需要按层处理的场景。迭代 DFS 可以避免递归爆栈。

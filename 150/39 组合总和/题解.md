# 39. 组合总和

## 题目描述

> 给你一个**无重复元素**的整数数组 `candidates` 和一个目标整数 `target`，找出 candidates 中可以使数字和为目标数 `target` 的所有**不同组合**，并以列表形式返回。
> `candidates` 中的同一个数字可以**无限制重复被选取**。如果至少一个数字的被选数量不同，则两种组合不同。
> 示例：`candidates = [2,3,6,7], target = 7` → `[[2,2,3],[7]]`

要点：① 元素可重复选，但组合（不是排列）**不能有顺序重复**；② 去重靠**限制每次只能从当前位置及之后开始取**（不回头），而不是对结果去重。

## 解法一：回溯（可重复选取 + 起始下标防重）

### 思路

DFS 三要素：
- **选择**：`candidates[start]` 到结尾都可以作为当前元素，因为可重复选，所以取了 `i` 之后**下一次仍从 `i` 开始**（不是 `i+1`），这是"无限取用"的关键
- **递归**：累加 `sum`，`start = i`
- **终止**：`sum == target` 收集；`sum > target` 剪枝返回

`start` 保证组合内下标非递减 → 天然避免 `[2,3]` 与 `[3,2]` 这种重复。

### 复杂度
- 时间复杂度: O(S)，S 为所有可行组合的长度之和（回溯本质是枚举解空间）
- 空间复杂度: O(target / min(c))，递归深度（取决于能取多少个最小元素）+ 路径

### 代码
```cpp
class Solution {
public:
    void dfs(vector<int>& c, int start, int target, vector<int>& path, vector<vector<int>>& res) {
        if (target == 0) { res.push_back(path); return; }
        for (int i = start; i < c.size(); ++i) {
            if (c[i] > target) continue;      // 剪枝：当前值已超
            path.push_back(c[i]);
            dfs(c, i, target - c[i], path, res);  // 可重复取，i 不 +1
            path.pop_back();
        }
    }
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<vector<int>> res;
        vector<int> path;
        dfs(candidates, 0, target, path, res);
        return res;
    }
};
```

## 解法二：回溯 + 先排序剪枝

### 思路

先把 `candidates` **升序排序**。这样在 `for` 循环里一旦发现 `c[i] > target`，因为后面更大，**后面全部可以 break**（不必 continue 逐个跳过），剪枝效率更高。其余逻辑与解法一相同。

### 复杂度
- 时间复杂度: O(S)，排序 O(n log n) 额外
- 空间复杂度: O(target / min(c))

### 代码
```cpp
class Solution {
public:
    void dfs(vector<int>& c, int start, int target, vector<int>& path, vector<vector<int>>& res) {
        if (target == 0) { res.push_back(path); return; }
        for (int i = start; i < c.size(); ++i) {
            if (c[i] > target) break;         // 已排序：更大的值都超了，直接停
            path.push_back(c[i]);
            dfs(c, i, target - c[i], path, res);
            path.pop_back();
        }
    }
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());   // 关键：升序
        vector<vector<int>> res;
        vector<int> path;
        dfs(candidates, 0, target, path, res);
        return res;
    }
};
```

## 总结

- "组合"用**起始下标不回头**去重，"可重复选"让递归参数 `start = i`（而非 `i+1`）—— 对比 77 组合（不可重复选，用 `i+1`）。
- 排序 + `break` 的剪枝在数据量大时收益明显。
- 用 `target - c[i]` 递减代替维护 `sum`，少一个累加变量。

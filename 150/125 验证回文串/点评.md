# 125. 验证回文串 — 代码点评

## 使用的方法
先过滤（只保留字母和数字，大写转小写），再使用双指针从两端向中间比较的混合方法。

## 复杂度分析
- 时间复杂度: O(n)，遍历一次过滤 + 一次双指针比较
- 空间复杂度: O(n)，额外字符串存储过滤后的结果

## 代码评价
- 优点: 思路正确，先统一格式再比较回文，逻辑清晰；手动判断字符范围（`>='a'&&<='z'` 等）避免了依赖 C 标准库函数。
- 可改进之处:
  1. 空间复杂度为 O(n)，可以优化为 O(1)：直接在原字符串上用双指针跳过非字母数字字符，无需新建过滤字符串。
  2. `flag` 变量设计冗余——在发现不匹配时已经 `return false`，后续 `if(!flag)` 的检查实际上总是通过，`flag` 失去了意义，可以删除。
  3. 可以使用 `isalnum()` 和 `tolower()` 简化字符判断逻辑，代码更简洁。
  4. main 函数中测试数据与回文串题目无关（包含字母异位词和无序数组），建议清理。
- 代码风格: 缩进基本规范，但包含了多个未使用的头文件（`<vector>`, `<stack>`, `<map>`），应清理。

## 总结
> 算法正确，过滤+双指针的混合方式可行，但可优化为 O(1) 空间的纯双指针版本。

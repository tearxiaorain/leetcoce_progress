# 125. 验证回文串

## 题目描述
> 给定一个字符串 s，验证它是否是回文串。只考虑字母和数字字符，忽略字母的大小写。返回 true 或 false。

## 解法一: 预处理 + 双指针反转比较
### 思路
先将字符串中所有字母和数字字符提取出来，并统一转换为小写，形成一个新的字符串。然后将新字符串与它的反转进行比较，如果相同则是回文串。

### 复杂度
- 时间复杂度: O(n)，遍历一次字符串进行预处理，再反转比较
- 空间复杂度: O(n)，需要额外字符串存储过滤后的结果

### 代码
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        string filtered;
        for (char c : s) {
            if (isalnum(c)) {
                filtered += tolower(c);
            }
        }
        string rev = filtered;
        reverse(rev.begin(), rev.end());
        return filtered == rev;
    }
};
```

## 解法二: 双指针原地判断
### 思路
使用左右双指针，跳过非字母数字字符，直接在原字符串上进行比较：
- 左指针 `l` 从 0 开始，右指针 `r` 从 `s.size() - 1` 开始。
- 当 `l < r` 时，跳过左右的非字母数字字符。
- 将左右字符统一为小写后比较，如果不相等则返回 false。
- 相等则两指针向中间移动。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int l = 0, r = s.size() - 1;
        
        while (l < r) {
            // 跳过非字母数字
            while (l < r && !isalnum(s[l])) l++;
            while (l < r && !isalnum(s[r])) r--;
            
            if (tolower(s[l]) != tolower(s[r])) {
                return false;
            }
            l++;
            r--;
        }
        
        return true;
    }
};
```

## 总结

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|---------|
| 解法一 | O(n) | O(n) | 过滤后反转比较 |
| 解法二 | O(n) | O(1) | 双指针跳过非字母数字原地判断 |

解法二更优，不需要额外空间，直接在原字符串上操作。但需注意 `isalnum` 和 `tolower` 的使用以及双指针移动时防止越界。

# 82. 删除排序链表中的重复元素 II

## 题目描述

> 给定一个**已按升序排序**的链表头 `head`，删除链表中**所有**数字有重复出现的节点，只保留原始链表中**没有重复出现**的数字。返回重排后的链表头。
> 与 83 题不同：83 保留一个副本，本题重复值一个都不留。输入输出示意：`head = [1,2,3,3,4,4,5]` → `[1,2,5]`。

## 解法一: 哑节点 + 一次遍历（边扫边删）

### 思路
用哑节点 `dummy` 指向头（头也可能被删，必须有前驱锚点），维护 `pre` 指向「已确认保留」链的末尾，`cur` 为扫描指针。
每轮以 `cur->val` 为基准向后数连续相同段：
- 若 `cur->next` 存在且值相等，就一路 `cur = cur->next` 跳过整段，再令 `pre->next = cur->next` 把整段重复节点从链中摘除（重复值一个不留）；
- 若 `cur` 无相等后继（该值唯一），`pre = cur` 把它收进保留链，`cur` 前进。
注意：重复段摘除后 `pre` **不**随之后移，因为摘除后的下一节点可能仍与前段不连续、需要再次判断。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* deleteDuplicates(ListNode* head) {
    ListNode dummy(0, head);
    ListNode* pre = &dummy;
    ListNode* cur = head;
    while (cur) {
        if (cur->next && cur->next->val == cur->val) {
            int v = cur->val;
            while (cur && cur->val == v) cur = cur->next;  // 跳过整段重复
            pre->next = cur;                                // 摘除
        } else {
            pre = cur;                                      // 唯一值，保留
            cur = cur->next;
        }
    }
    return dummy.next;
}
```

## 解法二: 快慢指针（slow 收链，fast 探界）

### 思路
`slow` 永远指向「保留链」的链尾，`fast` 用于探测下一段不重复的值：
`fast` 从 `slow->next` 出发，只要 `fast->next` 值与 `fast` 相同就前移，探出连续段的末节点。
- 若 `fast == slow->next`（该值只出现一次，无重复）→ `slow = fast`，保留；
- 否则 `slow->next = fast->next`，丢弃整段。

把「判重复」和「接链」分离，逻辑比边扫边删更直观。

### 复杂度
- 时间复杂度: O(n)
- 空间复杂度: O(1)

### 代码
```cpp
ListNode* deleteDuplicates(ListNode* head) {
    ListNode dummy(0, head);
    ListNode* slow = &dummy;
    while (slow->next) {
        ListNode* fast = slow->next;
        while (fast->next && fast->next->val == fast->val)
            fast = fast->next;                 // 探到连续段末
        if (fast == slow->next) slow = slow->next;   // 值唯一，保留
        else slow->next = fast->next;                 // 整段重复，摘除
    }
    return dummy.next;
}
```

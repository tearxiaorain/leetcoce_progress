# 36. 有效的数独

## 题目描述
> 判断一个 9x9 的数独初始局面是否有效。数字 1-9 在每一行、每一列、每一个 3x3 宫内只能出现一次。空位用 '.' 表示，不需要判断是否可解，只需验证已填数字是否违反规则。

## 解法一: 三次遍历法
### 思路
分三次独立遍历：先检查所有行，再检查所有列，最后检查所有 3x3 宫。每次遍历用一个哈希集合记录已出现的数字，遇到重复则返回 false。

### 复杂度
- 时间复杂度: O(9*9*3) = O(1)，棋盘大小固定
- 空间复杂度: O(9) = O(1)

### 代码
```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        // 检查每一行
        for (int i = 0; i < 9; i++) {
            unordered_set<char> seen;
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                if (seen.count(board[i][j])) return false;
                seen.insert(board[i][j]);
            }
        }
        // 检查每一列
        for (int j = 0; j < 9; j++) {
            unordered_set<char> seen;
            for (int i = 0; i < 9; i++) {
                if (board[i][j] == '.') continue;
                if (seen.count(board[i][j])) return false;
                seen.insert(board[i][j]);
            }
        }
        // 检查每一个 3x3 宫
        for (int box = 0; box < 9; box++) {
            unordered_set<char> seen;
            int r0 = (box / 3) * 3, c0 = (box % 3) * 3;
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 3; j++) {
                    char c = board[r0 + i][c0 + j];
                    if (c == '.') continue;
                    if (seen.count(c)) return false;
                    seen.insert(c);
                }
            }
        }
        return true;
    }
};
```

## 解法二: 一次遍历 + 三维数组标记
### 思路
只遍历一次棋盘，用三个二维数组分别记录每行、每列、每宫中某个数字是否已出现：
- `row[i][num]` 表示第 i 行数字 num 是否出现过
- `col[j][num]` 表示第 j 列数字 num 是否出现过
- `box[k][num]` 表示第 k 个宫数字 num 是否出现过，其中 `k = (i/3)*3 + j/3`

遇到数字时检查三个数组，若任一已标记则返回 false，否则同时标记三者。

### 复杂度
- 时间复杂度: O(81) = O(1)，单次遍历
- 空间复杂度: O(3*9*10) = O(1)

### 代码
```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        bool row[9][10] = {false};
        bool col[9][10] = {false};
        bool box[9][10] = {false};
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                int num = board[i][j] - '0';
                int k = (i / 3) * 3 + j / 3;
                if (row[i][num] || col[j][num] || box[k][num])
                    return false;
                row[i][num] = col[j][num] = box[k][num] = true;
            }
        }
        return true;
    }
};
```

## 总结
| 解法 | 遍历次数 | 空间 | 优点 | 缺点 |
|------|---------|------|------|------|
| 三次遍历法 | 3 次 | O(1) 使用集合 | 逻辑清晰，分步验证 | 遍历三次，常数较大 |
| 一次遍历+三维数组 | 1 次 | O(1) 使用数组 | 一次遍历，代码简洁 | 需理解宫编号映射 |

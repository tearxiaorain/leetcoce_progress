# 36. 有效的数独 — 代码点评

## 使用的方法
在一次遍历中同时检查第 i 行、第 i 列和第 i 个 3x3 宫。使用三个 `vector<int>(9,0)` 作为访问标记数组，用 `flag` 计数器追踪是否发现重复。

具体技巧：
- 外层 `i` 代表"组号"（第 i 行 = 第 i 列 = 第 i 个宫）
- 内层 `j` 遍历该组的 9 个单元格
- 行坐标: `(i, j)`，列坐标: `(j, i)`，宫坐标: `(i/3*3 + j/3, i%3*3 + j%3)`

## 复杂度分析
- 时间复杂度: O(81) = O(1)，单次遍历棋盘
- 空间复杂度: O(27) = O(1)，每次外层循环新建 3 个长度为 9 的 vector

## 代码评价
- 优点: 巧妙地将行、列、宫的遍历统一在一组循环中，常数较小；避免了使用 unordered_set，直接用 vector<int> 做标记更轻量
- 可改进之处:
  1. `flag` 用 int 做累加不如直接用 bool 或提前 return false 直观
  2. 内层 break 只跳出 j 循环，配合外层 `if(flag) break` 退出，不如直接 `return false` 简洁
  3. 宫坐标映射 `board[i/3*3+j/3][i%3*3+j%3]` 可读性较差，建议用变量名说明
  4. 每次外层循环重建 3 个 vector 产生重复分配开销；可改用静态大小的 bool 数组并复用
- 代码风格: 缩进不一致（2空格/4空格混用），部分 header 未使用（`<stack>`, `<map>`, `<set>`, `<algorithm>`）

## 总结
> 一次遍历同时校验行、列、宫，思路巧妙但实现细节可优化，使用 flag 计数器而非直返略显迂回。
